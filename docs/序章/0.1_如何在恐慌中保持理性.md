# 0.1 如何在恐慌中保持理性

海水把我冲上沙滩的时候，我以为自己已经死了。

嘴里全是苦咸的沙子。我剧烈地咳嗽起来，趴在沙滩上，吐出几口带血沫的水。水落在粗糙的黑沙地上，很快渗了进去，只留下一小片暗色的湿印子。

太阳已经升起来了。阳光照在我的后颈上，很烫。

我吃力地把身子翻过来，仰面躺着。四下里很空旷，也很安静，只有远处海浪拍打暗礁的声音。轰隆，轰隆。海浪很重，但节奏很慢，像是大海自己在喘气。

我朝四周望了望。没有船，没有机舱的残片，也没有别的人。只有一片灰黑色的沙滩，和沙滩后面黑黝黝的林子。

我抬起左手。

手背被礁石划破了，皮肉翻卷着，沾满了沙粒。更要命的是，我的手指在剧烈地颤抖。整只手抖得像一条刚被扔上甲板的鱼，完全不受控制。

“别抖了。”我对自己的左手轻声说。

但它停不下来。

恐惧就是在这个时候找上门来的。它不是轰轰烈烈来的，它来得很冷，很轻，像一条游在深水里的黑影，一下子从胸口咬住了你的心脏。

我的心跳骤然变快了，在单薄的肋骨后面猛烈地撞击。呼吸也变得又急又浅，每一次吸气都像是在吞咽干燥的灰尘，胸口憋得生疼。两只眼睛周围开始发黑，眼前的阳光和大海仿佛都在往后退，只剩下一个狭窄的黑洞。

那是身体里的古老本能在作祟。几万年前，森林里的祖先遇到野兽时，也是这么心跳和喘气的。本能催促着你站起来逃跑，催促着你大喊大叫。

可是，在这片空无一人的沙滩上，逃跑救不了你，大喊大叫也救不了你。在自然界面前发狂，只会白白耗光你血液里的最后一点糖分和水分。

“冷静点，老伙计。”我对自己说。

我闭上眼睛，深深吸了一口气。空气很潮，带着海藻腐烂的味道。气吸到顶端时，我又短促地补吸了一小口，让干瘪的肺叶彻底张开。然后，我收紧嘴唇，把这口气慢慢地、极慢地吐出去。

就像以前在实验室里看一支精密的滴定管，让液体一滴一滴均匀地漏下。

再吸一口。补吸一口。再慢慢吐尽。

我把右手粗糙的食指和中指，压在脖子右侧的脉搏上。那里的跳动很狂暴，像一头困在笼子里的野兽。但随着一次又一次缓慢的吐气，野兽的撞击声渐渐放缓了。

一百四十下。一百二十下。九十下。

它终于像一只老旧但耐用的座钟一样，平稳、沉重地跳动起来。

“这就对了。”我想。

视野边缘的黑圈慢慢散去，手指也不再像垂死的鱼一样痉挛。我重新拿回了这具身躯的支配权。

潮水涨上来了，冰冷的水沫舔湿了我的裤腿。

我撑着沙地，慢慢站起身来。膝盖在隐隐作痛，肚子空得发慌，但我站得很直。

大海就在眼前。它很大，很冷，浩瀚无边。它不恨我，也不可怜我。它只遵守太阳、重力和潮汐的规矩。

人不是生来要给打败的。你可以被海浪卷走，被礁石划破皮肤，但不能被恐惧击垮。

荒岛上的规则很简单，甚至比文明世界还要简单。水往低处流，太阳会带走水分，伤口感染会发热，木头摩擦会产生火星。所有的这一切，都写在物理学、化学和生物学的定律里，从不撒谎。

只要这些定律还在，只要我还能思考，我就还没有输。

我用袖口擦了擦脸上的盐渍，转过身，背对着涨起的潮水，一步一步朝岸上的高处走去。
