# 0.3 荒岛生存的三大死亡陷阱：失温、脱水、感染

海风吹过林梢的时候，我冷不丁打了个寒战。

那股冷是从骨头缝里钻出来的。天上的太阳还挂着，金晃晃的，甚至有些刺眼，但我身上的湿衣服却像是一层浸了冰水的铅皮，死死裹在皮肉上。

许多没在荒野里待过的人，总以为热带海岛是温暖的天堂。他们觉得只有在北方的雪原上，人才会被冻死。

那是致命的无知。

水导热的速度，比静止的空气快二十多倍。只要身上是湿的，一阵三四级的小风吹过来，水分蒸发带走的热量，就足够把你体内的火炉一点一点抽空。

核心体温只要从三十七度跌到三十五度，你的两排牙齿就会不由自主地打架；跌到三十三度，你的手指就会僵得像木头，连一根火柴都捏不住；再往下掉一点，你的脑子就会变得像灌了铅的浆糊，甚至会产生浑身燥热的幻觉，脱光衣服微笑着死在黑夜里。

大自然杀人的第一把刀子，名字叫失温。它最阴险，因为在它动手的时候，你往往感觉不到疼痛，只会觉得困。

“把衣服脱了，拧干。”我对自己命令道。

我解开黏糊糊的衬衫扣子，把衣服脱下来，使出吃奶的力气死命拧转。黄灰色的水滴哗哗地落在沙地上。我把拧得发皱的布料抖开，搭在被太阳晒得滚烫的玄武岩上。

没有干衣服之前，我得靠这块石头上残留的热量活着。

第二把刀子，在大海里漂着。

喉咙里的干渴越来越重了，像有一把粗锉刀在喉管里来回拉扯。嘴唇已经干裂出细小的口子，舌头舔上去，满是粗糙的死皮和咸味。

眼前是大海。无边无际、蓝得发亮的大海。水多得能淹没世界上所有的陆地，但只要你低头喝上三口，你就死定了。

海水的含盐量大约是百分之三点五，而人体血液里的盐分只有百分之零点九。只要这水咽进肚子里，高渗透压就会像一台疯狂的抽水机，把你细胞里原本就不多的纯水全吸出来，去稀释肠道里的盐分。越喝越渴，越渴越喝，最后你的脑细胞会萎缩，肾脏会衰竭，在极度的癫狂和抽搐里咽气。

干渴是缓慢的绞刑。在热带的日光下，人每小时通过呼吸和出汗要损失将近一升的水。七十二小时，这是死神给我的最后宽限。

我低头看了看自己的左手。

第三把刀子，已经在我身上划开了口子。

手背上那道被珊瑚礁划破的伤口，浸泡过海水后变得惨白，皮肉外翻着，边缘已经开始微微泛红、发肿。伤口里在突突地跳痛，每一次脉搏跳动，都带来一阵细微的酸胀。

在城里，这不过是一针破伤风和两粒阿莫西林的事。但在这里，没有抗生素，没有无菌纱布，空气里全是温热潮湿的霉菌和细菌，海浪里漂浮着无数看不见的弧菌。

一根小小的木刺，一道不起眼的珊瑚划伤，只要细菌顺着淋巴管钻进血液，引发全身感染，高烧、化脓、败血症就会在四十八小时内把一个壮汉彻底放倒。

失温、脱水、感染。

这三样东西，才是荒岛上真正的死神。它们没有利齿，也没有爪子，但它们就守在每一个遇难者的影子后面，只要你走错一步，它们就会悄无声息地扑上来，把你的骨头啃得干干净净。

“别看了，手。”我用右手搓了搓脸，“只要我还活着，就不能让你烂掉。”

我撕下衬衫内侧相对干净的一条布料，用牙齿咬住一头，单手把伤口紧紧勒住，暂时挡住空气里的脏东西。

太阳又低了一截。海风越来越凉了。

失温这第一把刀子已经架在脖子上了。我必须在天黑前生起一堆火，或者搭一个能挡风的草棚。我没有时间坐着发愁了。
