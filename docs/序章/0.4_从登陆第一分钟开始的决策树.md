# 0.4 从登陆第一分钟开始的决策树

太阳歪到了西南边，颜色从刺眼的白变成了沉甸甸的金黄。

树林的影子被拉得又细又长，像是一排倾斜的黑色长矛，斜斜地刺在沙滩上。

在赤道附近，黄昏很短。只要太阳的下沿一挨到海平面，天黑起来就像把一桶墨汁迎头倒下来一样快，前后不会超过半个小时。

我得给自己定下规矩。

以前在大学的实验室里，我带学生做项目，黑板上画满了各种复杂的决策树。方框连着箭头，箭头分出岔路，每一个“是”或者“否”，都决定着程序的走向。

那些是写在纸上的逻辑。但现在，面对这座未知的荒岛，我的第一张决策树，得用手指划在这片黑砂地上。

我蹲下身，折了一截坚硬的枯树枝，在平整的沙地上戳下第一个点。

第一根分叉：留在开阔的海滩上，还是立刻钻进密林深处？

密林里有木材，有藤蔓，也许还有甘甜的泉水。但密林是个瞎子。在太阳快要落山的时候闯进未知的原始林，那些纠缠的藤条和尖利的断木会撕烂你的裤子。踩上一条毒蛇，或者在乱石沟里扭断脚踝，你连今晚的月亮都看不见。

而海滩视野开阔，如果有船只或者飞机经过，这里是唯一的信号窗口。但海滩没有遮挡，夜风会像皮鞭一样抽打你的骨头。

树枝在沙地上划出一条果断的折线：我不留在潮湿的滩头，也绝不贸然深入内陆。我选择林缘线——就是高潮线上方五米、树林与沙滩交界的灌木带。背靠坚硬的岩石，面朝大海，进可以退入林中取木，退可以冲上海滩求救。

第二根分叉：找水，还是搭窝？

距离天黑还有大概两个小时。在这两个小时里，靠两条腿在陌生地形里找到淡水泉眼的概率，不会超过百分之二十。如果把仅有的体力消耗在徒劳的寻找上，黑夜降临的时候，我将既没有水，也没有避风的庇护所。

树枝重重地顿在沙地上：水可以等到明早。今晚的目标只有一个，搭一个最简易的单坡避风棚，隔绝潮气和风。

第三根分叉：快，还是慢？

本能在心里催促我：快跑！快搬石头！快折树枝！时间不够了！

“慢下来，林深。”我对自己的两条腿说。

在荒野里，匆忙是死神的帮凶。跑得太快，汗水会湿透刚刚晾干的衣服，加速夜间的失温；动作太猛，尖锐的木刺会扎进掌心，碎石会割破脚底。在这里，哪怕只是轻微的肌肉拉伤，都会让你明天失去觅食和生火的能力。

每一次弯腰都要稳，每一步落地都要看清脚下的石头。用脑子计算好每一卡路里的热量消耗，绝不做任何多余的动作。

树枝停下了。

沙滩上留下了一张粗糙而简陋的树状图。几个箭头，几道凹痕，没有复杂的公式，只有冰冷而清醒的选择。

风吹了过来，细碎的干沙慢慢滑落，把刚画好的线条掩埋了一半。

“不用留着了，”我想，“这些规矩已经刻在脑子里了。”

我抬起脚，用脚底把沙地上的图纹抹得平平整整。

恐惧退去了，饥饿暂时被按住了，身体的机能正在一点一点恢复。第一分钟的慌乱已经成了过去，接下来的七十二小时，才是真正的硬仗。

我扔掉枯树枝，拍了拍掌心的灰土，转过身，迈着沉稳而缓慢的步子，朝那片黑色的林缘岩壁走去。
