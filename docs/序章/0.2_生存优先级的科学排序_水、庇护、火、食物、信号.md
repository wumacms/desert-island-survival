# 0.2 生存优先级的科学排序：水、庇护、火、食物、信号

我离开了那片湿沙滩，朝岸上走。

脚底下慢慢变得干燥、坚硬。我在一根被海水泡得发白的大漂木旁坐了下来。木头很粗，不知道在大海里漂了多少年，树皮全没了，摸上去像晒干的石头一样硬。

我靠着漂木，长长地出了一口气。

肚子就在这个时候叫了起来。声音很响，咕噜噜地响成一片，像是有一只饿疯了的小耗子在胃壁上死命抓挠。

身体在向我抗议。它想要吃的。

我的眼睛不由自主地往旁边的林子里瞟。绿油油的树叶里好像藏着什么果子，海滩边缘的潮洼里似乎有小螃蟹在爬。嘴里开始分泌唾沫，两条腿甚至想站起来，走过去抓两只塞进嘴里，嚼碎了咽下去。

“坐着别动，肚子。”我对自己的胃说，“你现在最不配得到满足。”

这是绝大多数遇难者都会犯的头号错误：把饥饿当成最要命的事。

人在饿极了的时候，脑子里除了食物什么都装不下。你会冒冒失失地闯进未知的林子，去追一只根本抓不到的鸟，或者把一颗颜色鲜艳但有剧毒的浆果吞进肚里。又或者，你在烈日下跑得满身大汗，只为了抓几只连塞牙缝都不够的小毛蟹。

那是在慢性自杀。

作为一个跟生物学打了半辈子交道的人，我很清楚这具身体的底细。一个健康的成年男子，体重就算被海水折腾掉了几斤，皮下脂肪和肌肉里的糖原加起来，也至少存着十万千卡的能量。

不吃东西，人能活三个星期，甚至更久。胃里的抓挠只是荷尔蒙在闹脾气，它死不了人。

但是，大自然有它自己的倒计时，那个钟走得比饥饿快得多。

我抬起头，看了看头顶的太阳。太阳偏西了，海风吹在身上，原本凉爽的感觉开始变成了隐隐的寒意。身上的湿衬衫紧紧贴在胸口，正贪婪地抽走我体内的热量。

在恶劣的天气里，没有遮蔽所，一个人失温只要三个小时就会丧命。

如果找不到淡水，在热带海岛的高温脱水下，血液里的盐分三天就会把你的肾脏和大脑彻底烧干。

这就是铁一样的生存排序。它不是我编出来的，是人类这具脆弱肉体的生理极限写出来的。

第一位是庇护。在太阳彻底落下去之前，我必须找到一个能挡风、避雨、离开冰冷地面的地方。风会带走温度，夜里的露水会带走温度，只要核心体温跌破三十五度，我的脑子就会再次变蠢。

第二位是水。我的喉咙已经在发干了。每一次呼吸，肺部都在往外带走水蒸气。我得在七十二小时之内找到没有盐分的活水，或者自己造出淡水来。

第三位是火。火能把湿衣服烘干，能把水里的细菌和寄生虫煮死，能在野兽的眼睛里投下恐惧，还能在深夜给一个人活下去的胆量。

至于食物，排在最末尾。只要有水，哪怕我这几天一口东西都不吃，身体也能靠着消耗自身的脂肪硬撑过去。

至于求救信号，它重要，但它得建立在你还能喘气的前提下。一个死在沙滩上的人，就算手里攥着信号枪，也没有力气扣动扳机。

“听懂了吗，老伙计？”我拍了拍自己干瘪的肚子。

肚子没有再叫，它似乎默认了这笔账。

太阳在往下沉，时间在一分一秒地流走。我得在天黑前搭个窝，让自己不至于在第一个夜晚被冻死在海风里。

我撑着漂木站了起来。去找几根结实的树枝，天黑前还有仗要打。
