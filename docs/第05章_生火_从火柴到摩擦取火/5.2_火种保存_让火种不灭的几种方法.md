# 5.2 火种保存：让火种不灭的几种方法

在远古时代，任何一个部落里地位最高的人，往往不是力气最大的猎手，而是那个负责看管火种的老人。

在荒野里，生火是一场极其沉重的体力支出。

拉动一次弓钻，手臂、背部和膝盖要承受持续几分钟的高频重压，消耗掉两百到三百千卡的热量。鞋带会磨损，手掌会磨出水泡，而在连绵不断的阴雨天里，空气湿度会把生火的难度放大十倍。

如果每天早晨都要重新钻木取火，哪怕是一个壮汉，也会在几天之内被活活累垮。

傻子才天天生火，真正的老手只生一次火，然后像守着亲生骨肉一样，让那颗火种永远活着。

在火堆真正烧旺之前，我就在岩洞的死角里，清理出了保存火种的石槽。

让火种不熄灭的学问，在于对氧气和温度的精确控制。

木炭的无焰阴燃，需要两个互相矛盾的条件：它必须把核心温度维持在两百度以上，不能散失；同时，它又不能呼吸到太多的氧气。

如果通风太好，热量虽然高，但火炭会在半小时内燃尽成灰；如果彻底闷死不透气，窒息的二氧化碳会瞬间把热量扑灭。

最古老也最完美的保存法，是覆灰。

睡前的时候，不要往火堆里扔容易爆燃的细树枝，而是要塞进两块拳头大小、质地极其致密的硬木粗树根。

等到硬木被完全烧透，变成两块通红通红、没有明火的炭核时，就可以开始封火了。

我把通红的硬木炭核拢在一起，推到避风岩洞最深处的干石凹里。

然后，我用两块扁平的石头做铲子，把火堆边缘那些早先烧出来的雪白、细腻的草木灰扒了过来。

我把厚厚的一层白灰，严严实实地盖在红炭的上方。

厚度要刚好四到五公分。

这层看似冰冷的白灰，是世界上最好的天然保温绝热层。草木灰极其蓬松，细微的粉末里包裹着无数死空气囊，导热系数极低，能把滚烫的热量死死锁在底下几寸深的内部。

更巧妙的是，松散的灰粉具有微观的透气性。它阻挡了狂风的吹拂，却允许极微量的氧气像游丝一样慢慢渗透进去，维持着最微弱的阴燃反应。

在这层白灰底下，那颗炭核不会熄灭，也不会化成飞灰。它会像一只在母腹里沉睡的幼兽一样，安静地潜伏十到十二个小时。

等到第二天清晨醒来，不需要再拿弓钻去死命摩擦。

只需要用树枝轻轻扒开表面那层发凉的白灰。

在灰烬最深处，那颗被焐了一整夜的暗红炭核就会骤然露出来，像一只火红的眼睛在黑暗中微微眨动。

扔上一小撮干燥的引火绒，把嘴凑过去，轻轻吹上一口长气。

呼——

氧气灌入，沉睡的火核瞬间苏醒，微弱的红光变成炽热的金黄，火苗轰的一声就会重新腾空而起。

除了覆灰，如果要在白天长途跋涉，一截两端打通小孔的鲜竹筒，里面塞满阴燃的干燥朽木粉末，就是一支可以别在腰间的移动火炬。它会以每小时一公分的速度极其缓慢地暗燃，跟着你翻山越岭。

火是一头野兽，但只要懂得它的呼吸，它就能变成最温顺的家奴。

看着石槽里那层被我拍平的厚厚白灰，感受着从灰下透出来的微弱暖意，我放下了手里的石块。

今晚，整座海岛都在狂风暴雨中瑟瑟发抖，但在这个小小的岩洞深处，人类赖以生存的火种，已经安稳地睡下了。
