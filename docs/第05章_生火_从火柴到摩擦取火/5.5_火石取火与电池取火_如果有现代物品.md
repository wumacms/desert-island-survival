# 5.5 火石取火与电池取火：如果有现代物品

弓钻是纯粹的力气活。

如果有一天我的右臂骨折了，或者暴雨把所有的林木淋透了整整一个星期，在体能枯竭的绝境里，依靠拉弓钻木取火，可能会要了一个虚弱者的命。

在那种时刻，你必须动用随身携带的工业文明遗物。

那两把挂在钥匙圈上的高碳钢门钥匙，以及口袋里那部报废的手机，是两根随时可以拉响的现代导火索。

坐在温暖的火堆旁，我把这两样东西拿在手里，仔细打量。

第一种手段，是敲击火石。

很多人以为火石取火，是两块石头互砸砸出来的火星。那是彻头彻尾的误解。两块石头互砸产生的亮光，绝大多数是压电发光或者摩擦碎屑，温度极低，根本点不燃任何东西。

真正的火石取火，是一场铁与石的微观剥离。

我手里拿着那把带有锋利钢齿的门钥匙，另一只手握着一块在冲沟里捡来的致密白色石英石。

石英的摩氏硬度是七，而普通的钢材硬度只有五点五。

当我把钥匙的钢刃，以三十度的倾斜角，狠狠切向石英石锋利的边缘时，坚硬的石头像一把微观的刨刀，从相对较软的钢质表面上，猛地削落了一排微米级的铁微粒。

剧烈的摩擦剪切和塑性形变，在短短百分之一秒内把微小的铁屑加热到了几百摄氏度。

在空气中氧气的剧烈氧化下，这些飞溅出来的金属碎屑发生自燃，化作了一阵耀眼的雪白火星。

火星的温度高达八百到一千摄氏度。

只要在石英石的下边缘贴上一小块用竹筒闷烧出来的炭化棉布，那阵白亮的火星一旦落在黑色的碳布上，不需要吹气，碳布上就会瞬间亮起一颗滚烫的红点。

第二种手段，更加狂暴，也更加危险。

手机里的锂电池。

很多人把废电池当成垃圾，但在物理学家的眼里，那是一包被绝缘隔膜紧紧束缚住的高能化学键。

电池里虽然已经没有足够的电压点亮屏幕，但内部残存的锂离子和有机碳酸酯电解液，依然蕴含着巨大的化学势能。

如果遇到了命悬一线的暴风雨，连炭化布都湿透了，这就是最后的终极底牌。

取火的办法有两种。

第一种，是受控外短路。

用一根极细的导线，或者从口香糖包装纸上撕下来的铝箔细条，两端直接连通电池的正负极。

电流会在一瞬间达到十几甚至几十安培。根据焦耳定律，热量与电流的平方成正比。在最细的瓶颈处，金属丝会在零点一秒内被烧得通红，甚至直接熔断，爆发出刺目的电弧，瞬间引燃包裹在周围的干燥棉绒。

第二种，则是更野蛮的热失控刺穿。

找一根削尖的干硬木棍，把电池放在下风向的石头上。

用木棍狠狠砸穿电池铝箔外壳的中心。

当绝缘隔膜被外力撕裂的瞬间，正负极材料直接大面积接触，内部短路会引发剧烈放热。放热又会加速电解液分解，形成毁灭性的恶性链条。

短短两秒钟，电池就会像一只被激怒的毒蛇一样剧烈鼓胀、喷出刺鼻的白烟，随后喷射出温度高达六百度以上的炽热火舌。

但这也是最凶险的赌博。

锂电池燃烧时喷出的白色烟雾里，含有剧毒的氟化氢和有机磷化物气体，吸上一口就会严重灼伤呼吸道。

你必须戴着手套，站在绝对的上风向，把引火的干柴绑在长木棍顶端去迎击那道火舌，并在点着柴火后立刻把冒烟的电池残骸踢进深水里。

我把钥匙重新扣回腰间，把手机用防水的阔树叶层层包好，塞回裤兜的最深处。

懂得这些原理，是为了在最极端的绝境里握有一把底牌。

但在普通的荒岛岁月里，我宁可去挥汗如雨地拉动弓钻。因为真正的生存智慧，永远不是靠挥霍不可再生的工业遗产，而是学会在大自然自身的骨架上，建立起可以永续运转的循环。

我往火堆里扔了一根粗木头。火星噼啪升腾，照亮了洞穴深处那张平静而坚毅的面庞。
