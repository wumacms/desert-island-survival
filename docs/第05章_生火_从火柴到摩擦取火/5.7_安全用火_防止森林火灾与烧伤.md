# 5.7 安全用火：防止森林火灾与烧伤

火是一个极其忠诚的奴仆，但也是一个极其冷血的暴君。

在只有二十平方公里的孤岛上，用火不仅是手艺，更是一场提心吊胆的自律。

只要有一颗被风吹走的微小火星落在干透的灌木丛里，大火就会在二十分钟内借着海风撕碎整座山头。

那种灾难是不可逆的。

树林烧光了，山谷里的清泉会被厚厚的有毒草木灰彻底污染；所有的果树、鸟巢和水藤会被烧成焦炭；而你，会被漫山遍野的烈火一路逼进大海里，最后像一只烤焦的蚂蚁一样，趴在冒着滚滚浓烟的黑石头上活活渴死。

在点燃第一根柴火之前，必须先修筑囚禁火魔的牢笼。

第一道防线，是彻底铲除地面的隐形火线。

热带树林底下的地面是骗人的。表面上看是一层薄薄的干落叶，但落叶底下，是几十公分厚、风化腐败的泥炭层和错综复杂的枯树根网。

很多人把表面的落叶扫开，以为这就安全了。

那是致命的无知。

火会顺着地下的枯树根和松散的泥炭，在泥土深处以无焰阴燃的方式慢慢向前爬。它能在地下爬过三四米远，在你睡得正香的时候，悄悄从你身后的窝棚草垫底下猛然窜出地表，把你连人带窝烧成一堆火炬。

我用硬木棍把火塘四周直径三米范围内的地皮，全部一寸一寸铲了个底朝天。

所有的落叶、腐殖土、细树根，全部被我刮得干干净净，直到露出底下冰冷、致密、不含任何有机物的坚硬玄武岩母岩。

第二道防线，是提防那些会爆炸的石头。

许多人在野外垒火灶，喜欢顺手从海滩边或者小水沟里捞几块圆滚滚的大鹅卵石。

那是把炸药包直接扔进了灶膛里。

长年泡在水里的多孔岩石或者沉积页岩，内部布满了肉眼看不见的微观毛细孔，里面吸饱了水分。

一旦火堆的高温烤热了石头，被困在岩石深处的死水会瞬间汽化。水变成水蒸气，体积会在一瞬间暴胀一千六百倍。

无法释放的高压蒸汽，会在千分之一秒内把整块坚硬的石头炸得粉碎。

崩裂出来的碎石片锋利如剃刀，初速比子弹还快，会在几米之内直接切开人的喉咙，或者打瞎你的眼睛。

围火堆的石头，只能挑高处悬崖上、被烈日晒得干燥透顶的纯致密玄武岩。

最后，是对自身的绝对保护。

在这座没有抗生素和无菌纱布的孤岛上，大面积的二级烧伤等于宣判死刑。

失去表皮保护的真皮层，会疯狂渗出体液，引发不可逆的严重脱水；而空气里的霉菌会在二十四小时内爬满伤口，败血症会夺走一切。

烧火的时候，永远挽起袖口，永远备好两筒清凉的淡水和一堆干细沙在手边。

一旦不慎被烫伤，绝不能听信什么草木灰抹伤口的偏方。

唯一的物理原则，是用冰凉的清水持续冲洗浸泡二十分钟，强行打断热量向皮肤深层组织的传导；然后用最干净、煮沸消毒过的棉布轻轻遮盖，让身体的免疫系统去缓慢自愈。

火塘里的火焰渐渐暗淡了下去，红炭在石壁前静静地吐纳着微弱的热量。

我蹲下身，把四周散落的几星碎炭用脚底板一一踩死。

水在竹筒里，火在石灶里。

自然界两头最凶猛、最难以捉摸的巨兽，在这个夜晚终于被人类的双手套上了笼头，安分守己地趴在了我的脚边。

生存的基石奠定了。

明天早晨，风暴将会过去。有了安全的水，有了不灭的火，我将真正走出这个狭窄的避风岩洞，向整座海岛索取属于我的第一间真正的庇护所，以及维持长久生命的蛋白质。

我靠在微温的石壁上，闭上了疲惫但平静的双眼。
