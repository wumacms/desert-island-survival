# 5.4 弓钻取火：材料选择、制作与操作要点

洞外的暴风雨越来越近了，远处的雷声在海面上沉闷地滚动。

我坐在避风岩洞前干燥的平石上，把削好的四样零件排在眼前。

弓钻，这是旧石器时代人类机械力学的巅峰之作。它把手臂笨拙的往复直线运动，通过一根张紧的弦，转化为木钻每分钟上千转的超高速单向旋转。

选木头是一门严苛的学问。

太硬的铁木不行，摩擦半天除了把木头磨得像镜子一样光滑，根本刮不下木屑；太软的轻木也不行，一转就化成了一堆松散的烂木头渣。

我用大拇指的指甲，狠狠掐了掐手里的一根干透的黄槿死木棍。

木头上留下了一道清晰、坚硬但不粉碎的指甲印。

“就是你了。”我想。

软硬适中，不含油树脂，纤维细密，这是最好的钻木。

木钻有大拇指粗细，长约二十公分。顶端被我削成了一个极细、极尖的圆锥形，用来最大限度地减小顶部的接触面积；而底端，则削成了一个滚圆的钝头，用来增大底部的摩擦接触面。

底板是一块两公分厚的同种干木板，表面被我用黑曜石刮得平平整整。

第三样是握头。

我用的是半块极坚硬、内壁光滑的死椰子壳。在顶部的凹坑里，我用手指抹了厚厚一层自己鼻翼和额头上分泌出来的天然油脂。

物理原则非常残酷：上端必须润滑到近乎零摩擦，而下端必须粗糙到摩擦力的极限。

最后是弓。

一根小臂长、微弯而富有韧性的硬木枝，两端牢牢拴着我的尼龙鞋带。鞋带在木钻上紧紧缠绕了一圈。

在开钻前，还有一个绝不能省去的几何细节：切口。

我先用木钻在底板上慢慢旋转了几十圈，在木板上磨出了一个浅浅的圆形凹坑。

然后我停下来，用黑曜石在凹坑的边缘，切出了一个四十五度的“V”形排屑槽。

槽口的尖端正对着凹坑的正中心，底下垫着一片干燥的阔树叶。

很多人死命拉弓却不出火，就是缺了这个槽。没有这个开口，摩擦产生的木屑会被压死在坑底散发热量；有了这个倾斜的槽口，发烫的木屑就会像黑色的火山灰一样，自动滚落并紧紧聚拢在垫叶上。

聚热，是点火的唯一秘密。

我摆好了姿势。

左脚死死踩在底板上，左手抓着椰壳握头，将左手手腕紧紧抵在自己的左小腿迎面骨上。

手腕锁定在骨头上，形成了一个绝对不会晃动的刚性三角支架。整条木钻必须与地面保持绝对垂直的九十度角。

右手握住弓柄。

“吸一口气，老伙计，”我对自己的两条胳膊说，“力道要匀。”

拉动开始了。

拉第一阶段：轻柔、漫长、平稳。弓要拉满整根弦的长边，不能在中间短促地抽搐。

木钻发出嗡嗡的低吼声。摩擦产生的热量在把木料表面残留的微量水分子迅速烘干。

转了三十几下，底板开始冒出一缕极细、发白、带着木香的轻烟。

第二阶段：加压。

我把上半身的重力，通过左手掌心慢慢压向钻头，同时右手猛然加快了推拉的频率。

木钻发出了尖锐的吱吱声，像是一只被踩了尾巴的野兽。

白烟骤然变浓，从细缕变成了滚滚翻涌的青灰色浓烟。焦糊的气味刺得鼻腔发酸，细密滚烫的黑色木粉像沙漏一样，沿着V形槽口噗噗地掉落在底下的干叶片上，堆成了一个黑色的小金字塔。

手臂上的肱二头肌开始发酸、发胀，乳酸在剧烈堆积。胸口像拉风象一样喘气。

“别停！最后二十下！”

我咬紧牙关，爆发出了这具身体里的最后爆发力。

右手疯狂抽拉，木钻在黑暗中疯狂旋转成了一团残影。浓烟浓得几乎呛得我睁不开眼。

“停！”

我扔掉木弓，轻轻移开握头和木钻。

底板的V形槽下方，那堆黑色的小碳粉堆正静静地躺在树叶上。

它没有明火，但它自己在往外冒着一丝极细的青烟。

我没有急着用嘴去吹，而是用手掌在半空中轻轻扇动。微风带走了表面的浮灰，在那堆黑木粉的核心深处，骤然亮起了一颗针尖大小、暗红色的红炭。

热量突破了三百五十度。化学链条被彻底点燃了。

我小心翼翼地捧起那片树叶，把滚烫的黑木粉缓缓倾倒进早先准备好的鸟巢中心。

两只手掌把鸟巢轻轻合拢，留出一个通风的孔洞。

我将鸟巢举到与嘴唇齐平的高度，迎着洞外吹来的海风，鼓起腮帮子，极长、极缓、极其平稳地向中心吹气。

呼——

红光在鸟巢深处猛烈地扩散开来，照亮了我的指缝。白烟像狼烟一样从草叶间喷涌而出。

再吹一口气。

“轰！”

一声沉闷的爆燃声在手心里炸响。

金黄色的火苗像一头破壳而出的烈鸟，猛地穿透了椰棕和芭蕉叶，腾起半米多高，瞬间照亮了整个阴暗的玄武岩石洞。

火来了。

灼热的温度舔舐着我的睫毛，在黑漆漆的洞壁上投下了一个巨大而狂乱的人影。

我把燃烧的鸟巢稳稳放进火塘里，在上面压上了两根细干柴。

干柴噼啪作响，火苗贪婪地咬住了木头。

我跌坐在地上，满手黑灰，两条手臂酸痛得几乎抬不起来，汗水混着雨水从下巴滴落。

但在火光的映照下，我咧开嘴，笑了。

几百万年前，直立人就是用这种方式战胜了黑夜和严冬；几百万年后，在这座狂风肆虐的荒岛上，自然科学再一次从石头和木头里，把光明抢了回来。
