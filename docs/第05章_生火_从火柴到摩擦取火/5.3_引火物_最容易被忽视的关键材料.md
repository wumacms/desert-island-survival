# 5.3 引火物：最容易被忽视的关键材料

在所有失败的求生尝试中，有九成的人不是倒在没有火星上，而是倒在引火物上。

许多人以为只要搓出一颗火星，往地上的枯树叶堆里一扔，大火就会自己烧起来。

那是小孩子的幻想。

一颗刚刚从木头摩擦或者打火石上掉落的火炭，小得像一粒芝麻，里面蕴含的热量微弱得可怜。

如果直接把它丢在一根小木棍或者一片死树叶上，致密的木质纤维会像海绵吸水一样，在一瞬间把这粒微小火炭上的热量全部吸走、散失。

火星闪烁一下，然后悄无声息地死在黑夜里。

引火物的核心，在于微观的物理结构：比表面积。

一根粗木头的质量很大，表面积很小；而如果你把同一块木头撕碎成比头发丝还细的万千根微小纤维，它的表面积会瞬间放大几千倍。

极细的纤维几乎没有质量，导热能力极差。火星一旦落在这种纤维上，微弱的热量无法向周围散失，只能死死积聚在那个微米级的接触点上，瞬间突破两百五十度的燃点，引燃整根纤维。

在热带荒岛上，寻找合格的引火物是一门精细的手艺。

地上的枯树枝绝对不能要。地表有土壤的毛细返潮，落叶摸上去干燥，内部的含水率往往超过百分之三十。

要找，就得抬头看。

那些挂在高处树冠上、被风吹死却不落地的“悬空枯枝”，以及那些被暴晒在高处岩石缝里的死植物，才是真正干透的干柴。

我在洞口坐下，开始构筑我的第一只“鸟巢”。

最外层，我用的是撕成细条的干野芭蕉叶。

这些粗纤维很有韧性，能搭起一个透气的中空骨架，像一只厚实的大鸟巢，挡住外面狂暴的冷风，却允许氧气顺畅流通。

中层，是干透的椰棕纤维。

我从一只暴晒了不知多少天的大死椰子上，把外壳的厚皮一层层撕下来。用两块石头使劲捶打，把硬皮打碎，挑出里面像麻丝一样柔软金黄的细丝。再把这些细丝放在掌心使劲揉搓，直到它们变得像一团蓬松的金发。

最里层，也就是鸟巢最核心的温床，是最致命的关键。

我从破衬衫的袖口抽出了几十根纯棉的白线，用黑曜石刀刃在棉线上反复横向刮削，刮出了一小团像柳絮一样轻柔细腻的纯棉白绒。

不仅如此，我还从一截朽木最干燥的死芯里，抠出了一小撮像面粉一样细的红褐色木粉。

把棉绒和朽木粉混合在一起，轻轻放在鸟巢的正中央。

这只鸟巢不大，刚好能被两只手掌合拢包裹在手心里。

外粗、中细、内极绒。

最里面的细绒负责用极低的热量捕捉第一缕火星，中间的蓬松椰棕负责把微弱的红光放大成红热的炭块，最外层的粗纤维负责在狂吸氧气后猛烈爆燃成冲天的明火。

层次分明，环环相扣。

我用手指轻轻戳了戳鸟巢的中心，那里松软、温热、干燥得像晒透的羽毛。

引火物备齐了。

这是一只准备迎接火神的精致产床。只要有一颗火星掉进这个中心，它就不会熄灭，它必须在十秒钟之内，被这层层递进的物理结构逼成一场熊熊烈火。

我把鸟巢放在避风石板的最深处，擦了擦满是木屑的手掌。

舞台搭好了，引线拉好了，接下来，该让主角登场了。
