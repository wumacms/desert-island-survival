# 5.1 火的三要素与荒岛上的火源选择

第一滴冰冷的雨点砸在我的手背上时，我打了个哆嗦。

天彻底黑透了。海风带着大洋深处的寒气，像刀子一样割在湿冷的皮肉上。黑暗从四面八方压过来，把整座孤岛吞进了一片深不见底的墨汁里。

在荒野里，没有火，人就只是一只褪了毛的猴子。

你会失温，会被黑暗里的未知声响折磨得神经衰弱，会被生肉里的寄生虫咬烂肠胃。

只有当第一簇火苗跳跃起来的时候，黑夜才会被逼退到三米开外，冰冷的洞穴才会变成人类的家园。

火不是凭空降临的奇迹，它是一场严格遵循化学反应动力学的氧化放热。

在燃烧化学里，点燃一堆火必须同时凑齐三个角：可燃物、助燃物，以及达到临界值的活化能。

这就是经典的火三角。

在这座岛上，助燃物是无穷无尽的——海风里有充足的氧气；可燃物也到处都是——林缘里堆满了枯木和落叶。

真正卡住人类喉咙的，是第三个角：点火温度。

木材的主要成分是纤维素和木质素，它们的燃点在两百五十到三百摄氏度之间。

很多在荒野里被冻死的人，并不是找不到木头，而是他们根本不懂热量的收支平衡。

摩擦生热、撞击生热、电火花引燃，无论用什么方法，产生的微弱热量必须大于散失到冷空气中的热量。

如果木头是潮湿的，水的高汽化潜热会在一瞬间把所有的摩擦热全部吸收蒸发，温度永远跨不过两百五十度这道生死线。

我坐在岩洞干燥的石板上，借着外海风暴闪电的微光，在脑海里盘点着手头的起火手段。

火柴？没有。打火机？没有。

但文明并没有把我的退路彻底堵死。

第一种选择，是那部报废的手机。

手机里那块密封的锂聚合物电池，是一座微型的化学火药库。只要小心刺穿它的外壳，内部短路引发的热失控，能在几秒钟内释放出五百度以上的高温，点燃周围的引火物。

但那是最后的救命底牌。电池只能烧一次，一旦烧光了，我就再也没有第二块现代电池了。

第二种选择，是物理撞击。

钥匙圈上的高碳钢钥匙，配上这片火山岩里偶尔能找到的坚硬石英石或者致密燧石。用钢刃以斜角刮削硬石，剥离出来的铁微粒在空气中自燃，能产生极细微但温度极高的火星。

第三种，也是最古老、最取之不尽的手段：摩擦。

弓钻取火。

几万年前，当古人类第一次把一根木棍按在干燥的木板上飞速旋转的时候，人类文明的黎明就在那一缕青烟里升起来了。

机械能转化成内能，旋转摩擦剥离出细微的木质粉末，粉末在局部高温下积聚热量，达到阴燃的燃点，生成一颗比米粒还小的暗红火炭。

只要有一双手，一根鞋带，两截干燥的木头，这个过程就能无限次地重复下去。

“别碰电池，林深。”我对自己说，“把现代文明的底牌留到快要冻死的时候。”

雷声在外海滚滚作响，暴雨就要倾盆而下了。

我摸了摸口袋里那根结实的尼龙鞋带，又摸了摸放在避风棚内侧干燥石缝里的一小捆干透的引火绒。

今晚，我要用最纯粹的人类肌肉和古代机械力学，去跟这片湿冷的天地借第一团火。
