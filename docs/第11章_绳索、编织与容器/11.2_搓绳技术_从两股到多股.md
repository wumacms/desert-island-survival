# 11.2 搓绳技术：从两股到多股

两股的细麻绳是用来捆柴火和绑箭头的。

如果你想把一根重达两百公斤的原木吊上房顶，或者想把一艘满载猎物的小木筏在汹涌的大浪里牢牢拴在礁石上，两股绳子的抗拉极限会在瞬间被撕得粉碎。

在材料力学里，绳索的强度绝不是把几根细绳随随便便并排绑在一起。

没有几何学的咬合，并排的纤维只会各拉各的，受力不均的结果，就是一根一根依次崩断。

真正的重型缆绳，必须依靠三股对称螺旋结构。

下午的阳光洒在门廊前，我坐在平整的石阶上，身旁放着三大捆处理干净、雪白细腻的黄槿韧皮长纤维。

为什么必须是三股？

在几何学里，两股绳子的横截面是一个扁平的椭圆，受力时极易发生横向扭转；

四股绳子的正中央会留出一个空心的圆洞，受压时内部会凹陷坍塌，除非在中心硬塞进一根中轴填充芯；

只有三股绳子，在空间里以一百二十度的对称角相互咬合，每一股都严丝合缝地嵌入另外两股旋转形成的螺旋沟槽里。

它的横截面是一个最饱满、最致密的圆形，摩擦接触面积达到了最大化。

更深层的奥秘，是扭矩的绝对抵消。

很多人搓出来的麻绳，一松手就会像弹簧一样疯狂打结、自发拧成一团死疙瘩。在航海术语里，那叫“打结扭绞”。

那是内应力失衡的标志。

要制造一根在任何拉力下都绝不自发旋转、笔直温顺的重型缆绳，必须遵循“反向平衡加捻”的铁律。

第一步，制造三根单股绳。

我把纤维分成三等份。

每一份纤维在搓捻的时候，双手全部顺着统一的顺时针方向快速搓紧，行话叫“Z捻”。

纤维在顺时针扭紧的过程中，储存了强大的向左旋转弹性势能。

第二步，三股合一的逆向锁死。

我把三根已经蓄满了顺时针扭矩的单股绳并排挂在门廊的硬木桩上。

在三根绳子相交的节点上，我卡进了一个用硬木削出来的三角形“分绳器”。

木分绳器的三个角，把三根绳子牢牢隔开一百二十度的夹角。

右手握住分绳器向后缓慢移动，左手则抓住三根绳子的汇合端，逆着刚才的方向，以强烈的逆时针方向（S捻）把它们死死绞合在一起。

奇妙的力学平衡在这一刻发生了。

单股纤维内部原本试图向左释放的顺时针扭力，与整体逆时针绞缠产生的向右扭力，在空间里形成了极其精密的矢量对冲。

正负相加，净扭矩归零。

绞出来的缆绳沉甸甸的，粗如大拇指。

表面布满了紧密、对称、像铁链一样优雅的斜向螺旋纹理。

松开双手。

整根粗缆绳安静地垂挂在木桩上，笔直、温顺、没有半点自发的蜷曲和翻滚。

当外部的拉力猛烈作用在绳索两端时，三股相互咬合的螺旋纤维会自动向中心收缩、挤压。拉力越大，三股纤维之间的法向正压力就成倍暴涨，摩擦力死死锁住了每一丝纤维，绝不打滑。

我用这套手艺，整整搓制出了一根长达十五米的大拇指粗重型三股黄槿缆绳。

我把绳子的一头挂在崖壁伸出的天然石梁上，底下捆住了一块重达一百多公斤的巨大玄武岩压舱石。

双手发力，借着杠杆原理，把整块巨石悬空吊离地面半米高。

粗缆绳在重压下发出了一声极沉闷的微弱呻吟，纤维被拉扯得笔直发紧，微小的木质素粉末随之掉落。

但它稳稳当当地承受住了全部重力。

纹丝不动。

我松开双手，擦去额头上滚落的汗珠，抚摸着那根在巨石重压下依然坚如钢铁的粗绳索。

自然界的植物原本只是散落在大地上的杂乱细丝；

但人类的理性给它们注入了反向加捻的几何密码，散落的草木便化作了连巨兽和顽石都无法挣脱的工业锁链。

有了这根重型缆绳，我知道，我终于拥有了向深海和巨木发起正面冲锋的底气。
