# 11.3 编织篮子、垫子、鱼篓

两只空空如也的手掌，是野兽的配置。

在林子里挖到了二十公斤肥硕的野芋头，如果只能靠两只手抱着，你一次顶多搬运两块；

在海滩上捕到了满满一滩贝壳和海鱼，如果没有东西盛放，你只能看着大半猎物在涨潮里被大浪重新冲走。

编织不仅是手艺，编织是人类把大自然脆弱的零散草叶，通过空间拓扑学重组为受力外骨骼的伟大跨越。

有了篮子和背篓，人类的单次负重搬运能力，能瞬间暴增十倍。

第十三天的上午，我把营地门廊前清理干净，脚边堆满了剥好的细竹篾和晒到半干的韧皮露兜叶条。

编织的第一道门槛，在于结构的拓扑选择。

最普通的一上一下平纹编织，虽然简单，但结构太脆。一旦受到集中的点载荷冲撞，经纬线很容易在交错点断裂，整只篮子会从中间撕开。

我要造的是一只能够承受三十公斤乱石与硬块根的重型双肩背篓。

我选择的是古代工匠最信赖的“二上二下斜纹编织”。

第一步：搭建承重底盘。

在重力场中，篮子的底盘承受着百分之百的垂直下压力。

我挑了八根筷子粗细、极其坚韧的硬生藤条，两两垂直交错，用细麻绳扎成一个坚硬的井字形底骨架。

然后，以井字骨架为核心，十六根削得极薄、富有绝佳弹性的青竹蔑，像车轮的辐条一样，从中心向外放射性展开。

这些竹篾是整只背篓的垂直立骨。

第二步：斜纹爬升。

我抓起长长的露兜叶条，作为横向缠绕的纬线。

纬线在十六根竹篾立骨之间穿梭，严格按照“压过两根、挑起两根”的交错节律向前游走。

随着一圈又一圈的编织，表面自然浮现出一条条倾斜四十五度的优美对角螺旋纹路。

在力学上，这种四十五度的斜纹是最高明的减震结构。

当几十斤重的野芋头砸进背篓底部时，冲击力不会生硬地卡在单根纤维上，而是顺着斜向的对角纹路，被均匀地分流、吸收到了整只背篓的圆弧形侧壁上。

不仅如此，斜纹编织赋予了篮子极佳的柔韧弹性。

背在后背上，背篓会自然根据脊柱和背部肌肉的运动微微变形贴合，绝不会像硬木箱子那样生硬地磨烂后背的皮肉。

第三步：封口与提带。

编到半米高的时候，十六根竹篾立骨被我对折弯曲，塞回编织层的缝隙深处。

在篮口边缘，我套上了一根手指粗、烤弯成椭圆形的厚青藤圈，用细麻绳采用密集的连续马鞍缠绕，把口部死死包边扎紧。

最后，是至关重要的负重系统。

很多人编好了背篓，随随便便找两根细麻绳当背带。两根细绳勒在锁骨上，背上十公斤走不了一百米，就会把肩膀勒出两道青紫发黑的淤血印。

我裁下了两条十公分宽、双层加厚的打制构树树皮布。

这种纯天然的麂皮状树皮布柔软而宽厚，把重力均匀地分散在整个肩膀斜方肌的表面。

背带下端牢牢固定在底部的井字骨架上，上端用结实的缆绳系在背篓后壁上沿。

背篓完工了。

整只背篓高六十公分，上宽下窄，呈现出一个极其流畅的微弧椭圆锥体。

自重不过两斤多，但结构致密坚固，没有一处晃荡的虚缝。

我把它背在肩膀上。

宽厚的树皮布软软地贴在锁骨前，背篓的重心紧紧贴在后背中下部，两只手臂在身前完全释放了出来。

除了背篓，我还用整张露兜树叶编织了一张两米长、一米半宽的双层平整大草席，铺在高架竹床上，彻底隔绝了缝隙里的细小竹屑；

还用大孔隙的“六角眼编织法”，造了一只水下阻力极小、结实耐冲撞的深海虾笼。

看着石台上立着的深绿色大背篓，抚摸着光滑致密的侧壁，我感到胸膛深处升起了一股踏实的充实感。

双手不再被搬运的笨拙所困，双肩接管了重物的负荷。

从这一刻起，荒岛深处的大山和丛林，不再是我难以搬运的遥远宝库。

只要我的两条腿还能迈动步子，这只坚固的背篓，就能把几十公斤的生活资源，一次又一次稳稳当当背回属于我的营地。
