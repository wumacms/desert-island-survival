# 11.1 天然纤维来源：树皮、棕榈叶、藤蔓

有了固定的房子和吃不完的干肉，工匠的心思才真正从身体里醒了过来。

在最初的十几天里，我手头所有的绳子都是凑合的。

鞋带、撕开的裤腰布条，还有几根胡乱扯下来的带刺野藤。

那些临时的碎料能解燃眉之急，但如果你想捆绑一柄能劈开硬木的重石斧，想编织一只放进深海大浪里的巨型鱼篓，或者想搭一座跨越溪流的悬空木桥，那些粗糙的烂藤条会在几天之内全线崩溃。

材料是一切技术的地基。

在自然界里，植物把强度藏在不同的细胞壁里。选错了植物，你的所有编织劳动不过是在做无用功。

我背着空篓子，顺着山谷的水系和林缘重新进行了一场严密的植物学普查。

第一种纤维，是来自韧皮部的“抗拉王者”。

在小溪边的潮湿平地上，生长着大片的野海滨黄槿和野构树。

这两类树木的秘密，藏在树皮最里面的白色内韧皮里。

在植物显微结构下，内韧皮是由无数根细长的纤维素管胞紧密交织而成的。这些管胞具有极高的聚合度和微纤丝取向度。

剥下来的内韧皮，在经过水浸脱胶去除果胶后，纤维柔软如丝，抗拉强度接近普通的工业黄麻，而且天然具有极佳的耐盐水腐蚀性。

这是制造精细绳索、弓弦、鱼线和高级衣服的首选原料。

第二种纤维，是来自叶片的“抗磨硬甲”。

在海滩与岩石交界的干旱沙地上，一株株带刺的野生露兜树和剑麻状的百合科植物拔地而起。

把这种坚硬肥厚的叶片割下来，用贝壳边缘把叶片正反两面的绿色叶肉死死刮掉。

剩下的，是一排排雪白、硬挺、像钢丝一样的叶脉厚壁纤维。

叶纤维的木质素含量比树皮纤维高得多。

它们不如黄槿柔韧，但它们具有不可思议的硬度和抗磨损性能。被海水反复浸泡，或者在粗糙的玄武岩上反复拖拽，它们表面那层致密的天然角质蜡层，能把机械磨损化解于无形。

这是编织踩在脚底的草鞋底、盛放重石头的粗背篓、以及扫帚的最佳材料。

第三种纤维，是森林上空悬挂的“天然钢梁”。

在原始热带雨林里，许多粗壮的木质省藤和水藤，顺着高大的乔木树干攀爬几十米高。

在植物解剖学里，这些藤条是纯粹的木质化管束集合体。

砍下一根两指粗的坚硬老藤。

用锋利的黑曜石刀尖从正中剖开，再顺着纤维纹理撕成几毫米宽的均匀长藤蔑。

藤蔑不需要搓捻，它天生就具备极强的抗拉和抗扭强度，而且湿润时极其柔软，一旦干燥脱水，就会像钢丝一样收缩变硬，死死咬合住被它捆绑的任何物体。

这是捆绑粗大承重梁柱、制作大型石斧木柄锁扣的终极连接件。

树皮取其柔韧高拉力，叶脉取其耐磨抗腐蚀，老藤取其坚硬抗扭曲。

三种完全不同的植物纤维，被我整整齐齐地码在门廊前的干燥石板上。

大自然没有为我冶炼出一根铜丝，也没有制造出一盘尼龙塑料带。

但在这个闷热的午后，当这三堆带着泥土与阳光香气的天然聚合物材料排开在眼前时，我知道，属于这个孤岛的机械与编织时代，已经在我的手心里拉开了序幕。
