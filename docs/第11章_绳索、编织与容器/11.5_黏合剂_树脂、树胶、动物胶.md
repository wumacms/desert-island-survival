# 11.5 黏合剂：树脂、树胶、动物胶

单纯靠绳索捆绑的工具，是一件会说话的残次品。

无论你把麻绳勒得多紧，在反复剧烈的砍伐撞击下，木柄与石头之间的微观缝隙，必然会产生高频的微动摩擦。

要不了一个下午，绳圈就会被震松，石斧的斧头会在猛烈的挥击中脱手飞出，砸断自己的脚趾。

绳索只能提供单向的拉力，只有黏合剂，才能在分子层面上填满所有的微观粗糙面，把两种完全不同的材料焊死成一个刚性整体。

在没有现代环氧树脂和502胶水的荒岛上，大自然的有机高分子化学，早就准备好了最顶级的粘合配方。

夜幕降临的时候，我在火塘边缘摆开了两只大鲍螺壳。

第一种胶，是耐冲击的复合热熔胶：松香炭黑胶。

在山坡受伤的针叶树和老野树干上，我刮下了足足半碗金黄色、半透明的天然硬树脂。

纯树脂在加热到八十度时会融化成滚烫的液体，冷却后硬如玻璃。

但很多外行直接用纯树脂粘工具，往往一锤子砸下去，脆硬的树脂就会像冰块一样当场震得粉碎。

在高分子材料学里，纯树脂缺乏断裂韧性。

必须进行复合改性。

我把树脂放进一只厚鲍螺壳里，架在红炭上方慢慢加热，直到它完全融化成翻滚着微弱气泡的金黄色油液。

接着，我端来了一小堆在石臼里研磨得像面粉一样细的干木炭粉，以及一小块指甲盖大小的熟野禽油脂。

调配的黄金比例是七比二比一。

七成融化的纯树脂，作为提供黏附力的主要基体；

两成微细的炭黑粉末，充当微观的强化阻裂填料。炭黑颗粒极其细小，它散布在树脂分子链之间，能像一道道微型的防波堤一样，死死阻断冲击裂纹的瞬间扩展；

最后一成动物油脂，则是必不可少的增塑剂。微量的甘油三酯穿插在硬高分子之间，赋予了胶体在冷凝后极其珍贵的微弹韧性，彻底消除了低温脆性。

用小木棍在贝壳里顺时针疯狂搅拌，直到金黄色的液体变成了一锅乌黑、油亮、像融化沥青一样浓稠的黑胶。

我把一根干木棍的一端反复浸入热胶里，一层层包裹、冷却，最后凝固成了一根像棒棒糖一样的便携式黑色热熔胶棒。

只要用火苗轻轻一烤，黑胶就会融化滴落；

趁热把它抹在石斧与木柄交接的槽口里，再用麻绳狠狠扎紧。

黑胶冷却只需要两分钟。

凝固之后的复合胶，硬得像一块黑色的工业赛璐珞塑料，彻底渗进了石头的每一处微孔和麻绳的每一根缝隙里，把整柄石斧浇铸成了一块浑然天成的实心铁疙瘩。

第二种胶，是强度甚至超过木材本身的终极武器：动物皮骨胶。

把昨天宰杀野鸟留下的一小堆坚硬碎骨头、鸟皮边角料和硬鸟爪上的筋腱收集起来。

在动物解剖学里，这些坚硬结缔组织的主要成分，是极其强韧的三螺旋胶原蛋白。

我把骨头用石锤狠狠砸成碎渣，放进一口盛满半锅清水的粗竹筒里。

架在微弱的炭火上，开始了一场漫长的大分子水解反应。

必须严格控制火候，绝不能大火滚沸。

温度要维持在八十到八十五度之间，大火会把长链胶原蛋白彻底烧断成毫无粘性的短肽链。

整整文火熬煮了六个小时。

水分子在持续的温热下，慢慢切断了胶原蛋白分子间坚固的共价交联，原本坚硬的三螺旋结构在水中解旋、水解，化作了高浓度的水溶性明胶多肽链。

捞出竹筒里已经酥烂如泥的白骨头渣子。

把剩下的那半筒浑浊浓汤，倒在另一块平整石板上，用微火慢慢收汁、脱水。

水分蒸发殆尽，原本泛白的肉汤，最后浓缩成了一层半透明、金黄发亮、像琥珀一样坚硬的胶皮。

用刀切成小方块，放进干燥的葫芦罐里，这是能保存几十年不坏的干固皮胶。

只要在木工制作时，挑出一小块干胶，加几滴水在小贝壳里微微加热融化。

把它抹在两块木头的接缝处，用夹子死死夹住。

随着水分在木质纤维里被吸收蒸发，明胶分子链会像无数只看不见的分子爪，深深扎进两边木头的导管孔隙里，产生恐怖的机械互锁效应。

一旦完全固化，两块木头接缝处的抗剪切强度，甚至远远超过了木头本身的横向抗拉强度。

如果用力砸断，木头会在完好的部位断开，而这道胶缝依然完好无损。

便携抗震的松香沥青热熔胶棒，坚韧逾铁的琥珀动物骨皮胶块。

我熄灭了火塘里的微火，把这两样凝固了人类材料力学智慧的黑色与金色药块，整整齐齐地收进了石壁最干燥的储物架上。

第十一章在这一夜，终于圆满画上了句号。

从细丝到缆绳，从草叶到背篓，从空竹到器皿，从松香到强胶。

人类的双手不再是赤裸虚弱的肉体。

通过解构大自然的植物大分子与动物胶原蛋白，我为自己打造出了一整套坚实耐用的工具制造母机。

门廊外的风暴已经变成了温顺的夜风。

在火光的照耀下，我的目光投向了营地角落里那一堆堆冰冷坚硬的玄武岩、黑曜石与洁白兽骨。

材料备齐了，连接件有了，胶水干透了。

明天，该是让这具坚硬的石头世界，正式吐出真正的战斧、石刀与利刃的时候了。
