# 后记 当文明退去，科学是你最后的行李

海风吹拂着山脊上的长草，发出一种沉稳而沙哑的声响，像是一个老人在漫长的远行后，坐在岩石上轻轻吐出的一口气。

正午的阳光透过石屋的窗棂，在平整的玄武岩石桌上切出一道明亮的金边。

桌面上整齐陈列着我的全部家当：

一叠装订成册、用没食子酸铁墨水密密麻麻写满气象数据与植物解剖图的中性皮纸日志；

一柄在火炉余烬中历经五次折叠锻打、淬火研磨出的中碳钢猎刀；

一块用木薯淀粉与植物油反复抛光、能在阳光下放大八倍微观世界的双凸硅酸盐光学玻璃镜；

还有那具用贝壳宝石轴承托举着、在封闭竹筒中静静下倾三十五度、死死锁住地球磁极轴线的干式罗盘。

门外，引水渠里的山泉正哗啦啦地流入蓄水池；梯田里的野生木薯在微风中舒展着肥厚的深绿掌状叶片；鸡舍里的母鸡正在阴凉处悠闲地啄食着拌了贝壳粉的碎炭屑；远方海峡口处，萨沃纽斯垂直轴风机正如同一尊沉默的钢铁雕塑，以每分钟三十转的恒定节律，不知疲倦地旋转着。

这里不再是一片将遇难者生吞活剥的死亡陷阱。

这里是一座被人类的理性与汗水彻底驯服的孤岛绿洲。

远方的海平面尽头，出现了一道极细微的铅灰色烟迹。

那不是变幻莫测的积雨云，也不是鲸鱼喷出的水柱。那是重油柴油机在八百转高速巡航时，从排气烟囱中喷涌出的现代工业黑烟。

十分钟后，一艘涂装成深灰色与亮橙色相间的现代远洋搜救巡逻艇，切开了外海那道咆哮了千万年的白色碎浪带，放下了一艘黑色的重型充气突击艇。

大马力舷外挂机发出了刺耳、尖锐、粗暴的轰鸣声，撕碎了这片环礁长久以来的宁静。

我没有奔跑，没有像疯子一样在沙滩上挥舞手臂，也没有发出那种被拯救者常有的撕心裂肺的嚎哭。

我只是站起身，把那柄伴随我走过漫长黑夜的钢刀平稳地插回腰间的硬皮鞘里，将那本沉甸甸的手写日志抱在臂弯中，迈开步子，以一种极其匀速、沉稳的步伐，缓缓走下山坡，穿过防风林，走到了那片我最初被海浪抛弃的黑沙滩上。

突击艇冲上了沙滩。

四名全副武装的搜救队员从艇上一跃而下，他们穿着昂贵防水透气的特种面料制服，胸前挂着大功率卫星通信电台、战术急救止血带与工程破拆工具。

他们端着望远镜，原本做好了在这座孤岛上寻找一具发臭的白骨、或者一个骨瘦如柴、精神失常、在污泥与排泄物中苟延残喘的野人的准备。

但当他们的军靴踏在沙滩上，看清从椰林深处缓缓走出的我时，四名年轻健壮的军人彻底僵在了海风中。

站在他们面前的，是一个皮肤被赤道烈日晒成深铜色、四肢精瘦如铁、眼神明亮如鹰隼的男人。

我身上穿着一套用野生竹麻纤维与构树内皮精细纺织缝合的浅灰布衣，脚上踩着一双用野猪皮革与加固麻线鞣制缝缀的防刺工装短靴；我的头发用骨簪整齐地束在脑后，下巴上的胡须被锋利的钢刀刮得干干净净。

在我的身后，不是野兽的巢穴。

那是一排排整齐的石砌坚固房屋、一座高耸的烟囱陶窑、一道横跨山谷的竹引水桥、以及一面在微风中静静闪烁着光芒的太阳能聚光反射镜。

年轻的突击艇长摘下了防风护目镜，喉结剧烈上下滚动了一下。他环顾着这座秩序井然的营地，又看了看我平静的面庞，说话的声音甚至有些结巴：

“先生……上帝啊……这整整十四个月，您一个人……究竟是怎么活下来的？”

我看着他年轻而困惑的眼睛，低下头，用满是老茧的手指轻轻摩挲了一下怀中冰凉沉重的皮纸日志，微微笑了笑。

“我从来不是一个人。”我说，声音平静得如同身后深沉的海浪，“阿基米德在这里。拉瓦锡在这里。法拉第、达尔文和麦克斯韦都在这里。”

“当现代文明的游轮沉入大洋深处，当狂暴的风浪把我身上所有的衣服、金钱、证件和机器剥夺得一干二净的时候，他们，是我脑子里唯一带走的行李。”

现代人生活在一个巨大而脆弱的温室幻觉之中。

我们习惯了拧开龙头就有清澈甘甜的自来水，习惯了按下开关就有照亮黑夜的电流，习惯了从超市货架上抓起真空包装的牛肉，习惯了在发热咽痛时随手吞下一粒阿莫西林。

我们太习惯这一切了，以至于我们误以为这些由钢铁、混凝土、光纤与物流网络构筑的便利，就是我们自身生物学意义上的力量。

我们沉迷于银行账户里跳动的数字，焦虑于社交网络上闪烁的红点，为了虚无缥缈的名利与琐碎的人际关系筋疲力尽。

我们以为自己拥有了全世界。

但只有当一场突如其来的海难、地震、战争或瘟疫，像一只冰冷无情的巨手，把那层薄如蝉翼的工业防护网彻底撕碎时，你才会猛然惊醒：

如果切断了电网，你是否知道如何从泥土中提取出让伤口不化脓的强碱与单宁？

如果断绝了供水，你是否懂得利用露点温度与相变潜热，在灼热的沙滩上蒸馏出第一滴救命的甘泉？

如果关闭了全球定位系统（GPS），你是否能仅凭夜空中三颗恒星的赤纬与一枚下倾三十五度的缝衣针，在狂暴的西风漂流中找到回家的航线？

在那一刻，你银行卡里的七位数存款只是一串毫无意义的死电荷；

你精美的名牌西装只是一堆易燃却无法抵御夜间湿冷的脆弱化纤；

你曾经引以为傲的所有社会身份、人脉关系与虚荣头衔，在热力学第二定律无情的熵增铁拳面前，脆弱得如同一捧被风吹散的飞灰。

在文明退去的那一刻，真正能够保护你、拯救你、让你在死神的注视下昂首站立的，只有那些被你真正内化进神经突触与血液深处的客观科学知识。

科学从来不是大学课堂里为了应付考试而背诵的枯燥定理；

科学是人类在这个冷酷、荒谬、物质守恒的物理宇宙中，历经千百万年的流血与摸索，唯一找到的通往自由的破壁工具。

热力学第一定律告诉你，能量不会凭空产生，所以你必须计算好每一把力气的消耗，绝不能在毫无意义的恐慌中暴走；

金属活动性顺序表告诉你，锌和铜的电位差永远是一点一伏特，只要你把它们插进酸液里，即使全世界的电厂全部瘫痪，电荷依然会跨越微观空间，在你的指尖绽放出理性的火花；

细胞膜的流动镶嵌模型告诉你，肥皂的双亲性分子结构能够撕碎病毒的脂质包膜，所以一块用草木灰和海鸟油脂熬出的硬肥皂，就是你阻隔败血症最坚固的物理盾牌；

天体力学告诉你，地球自转轴在二十三点五度的倾斜角上年复一年地稳定摆动，所以哪怕狂风抹平了所有的地标，天顶正午那道最短的阴影，永远指向正北。

这些定律是永恒的。

它们不在乎你是达官贵人还是破产落魄的流浪汉，不在乎你是身处繁华的纽约曼哈顿，还是被孤立在南纬三十度的无名死火山环礁。

只要你尊重它们、理解它们、运用它们，这些冰冷无情的物理法则就会化作你手中最锋利的重剑，替你劈开眼前的荆棘与绝望。

水手们帮我把那几箱手稿、矿石标本和自制的透镜小心翼翼地抬上了突击艇。

我站在艇尾，最后一次回头凝视着这座庇护了我四百多个日夜的荒岛。

在海蚀洞高出海面三十米的黑色玄武岩石壁上，我亲手用石英凿刻下的那座“终极罗塞塔碑”，在正午的烈日下闪烁着深红色的矿浆光芒。

石壁上的公式、地图与坐标，足以抵御两万年的雨水剥蚀与海风侵袭。

我没有拆毁我的陶窑，没有拆除我的引水渠，没有毁掉我苦心开垦出的黑土梯田，甚至在石屋的木桌上，整整齐齐地留下了三盒蜡封的种子、两陶罐提纯的白盐、一包干燥的燧石火种，以及一套崭新的羽毛笔与竹麻纸。

在石屋正门上方，我用钢刀深深刻下了一行字：

“致后来的遇难者：屋里有水，有盐，有火种。不要哭泣，不要绝望。坐下来，喝一口水，然后用你的脑子去思考。人类已经走出过一次荒野，你也一样可以。”

大马力引擎发出了低沉的咆哮，突击艇缓缓调头，切碎了白色的浪花，向着停泊在外海的钢铁巡逻舰全速驶去。

小岛在视野中渐渐变小，最终化作了深蓝大洋边缘一道模糊的翠绿剪影。

海水很蓝，天很宽阔，海鸥在舰艉的白浪上方欢快地盘旋啼鸣。

我伸出右手，紧紧按在胸前那本厚重的羊皮纸日志上，感受着自己胸膛内那颗强健、沉稳、充满力量的心跳。

我活下来了。

我不仅活着离开了那片绝境，而且，在赤手空拳与蛮荒对峙的整整十四个月里，我没有一天沦为依靠本能苟活的野兽。

我以一个现代科学家的全部尊严，在一片荒芜的死地上，亲手重建了一座微型的人类文明。

合上这本手册吧，朋友。

当你合上它的时候，你也许正坐在宽敞明亮的写字楼里，空调吹着舒适的凉风，咖啡机里飘出安详的香气；

但请永远不要忘记，文明是一场漫长而脆弱的接力，而不是永恒不变的温床。

珍视你所学到的每一个物理公式，搞懂你所见到的每一个化学反应，敬畏你脚下踩着的每一寸岩石与泥土，去理解生命演化的宏伟脉络。

不要让你的大脑成为信息垃圾的垃圾桶，让它成为一座装满真理与逻辑的坚固武器库。

因为，谁也无法预料，时代的风暴会在哪一个清晨骤然降临；

而当一切文明的浮华退去，当所有的机器停止轰鸣、所有的霓虹熄灭在无边的黑暗中时；

你唯一能够随身携带、并且永远不会被任何风浪夺走的最后行李；

就是你大脑中的科学。

去战斗吧，永不屈服，永不盲从。

科学与你同在。

—— 全书完 ——
