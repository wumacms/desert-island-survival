# 21.3 驯养与畜牧的可能性

在生态学金字塔的能量流动定律中，食草动物与杂食动物是自然界最奇妙的生物转化器。

很多人在荒岛求生时，只知道一门心思扛着长矛去森林里狩猎。

但狩猎是一场极高风险的单向赌博：

一只成年野兽一旦被杀死，在热带三十度的高温湿热下，三十公斤鲜肉会在十二小时内开始不可逆地变质腐败；

即使你动用全部的盐巴与柴火进行熏腌，沉重的人工脱水消耗，依然会耗尽你有限的劳动时间。

野生动物活着的价值，远远大于它死去的价值。

畜牧与驯化，是人类文明在荒野中建立的“活体冷库与高能蛋白质转化站”。

一头活着的禽畜，相当于一间不需要任何电力维持的永久保鲜库：

它把人类无法直接消化利用的粗烂草叶、掉在地上的腐烂野果、白蚁穴里的微小幼虫与潮间带坚硬的微小碎螃蟹，在体内转化为极易吸收的完全蛋白质、必需氨基酸与浓缩脂肪；

并在你需要它的那一秒钟，为你提供最纯净、最新鲜的热量，而在这之前，它甚至每天都在为你生产宝贵的鸟蛋、皮毛与高氮农田肥料。

但你绝不能盲目地试图去驯养你在这座岛上见到的每一种活物。

第一道进化生物学法则：贾雷德·戴蒙德的“安娜·卡列尼娜原则”。

《枪炮、病菌与钢铁》的作者戴蒙德，借用托尔斯泰的名言揭示了驯化的终极铁律：

“可驯化的动物都是相似的；不可驯化的动物各有各的不可驯化之处。”

在动物行为学与生理学中，一种野生动物要想被人类成功驯化，必须同时无一例外地满足六大苛刻的黄金条件：

第一，食物转化率必须经济。它绝不能是纯肉食性动物（用十斤鱼去换一斤肉是绝对的亏本生意），它必须能把廉价粗糙的杂食或草料转化为肉体；

第二，生长周期必须极快。如果一种动物需要五年才能成年产肉，在荒岛上等待它的成年等同于慢性自杀；

第三，必须能在圈养狭窄环境中自发交配繁殖。许多野生鸟类在失去广阔天空后，神经内分泌系统会完全关闭生殖轴，终生绝育；

第四，性情必须温和，不具备神经质的致命攻击性；

第五，惊恐反应阈值必须极高！如果一种动物稍遇风吹草动就会陷入盲目狂奔，撞死在竹栅栏上，你永远无法把它关在笼子里；

最后，必须具备层级分明的群居社会结构，允许人类通过食物掌控，轻松取代它们种群中的“领头首领”地位。

用这六把手术刀，去剖析海岛上的所有野生动物，绝大多数物种在第一轮就被冷酷淘汰：

悬崖上的海鸟（白燕鸥、红脚鲣鸟）——它们是天空与大洋的专性滑翔者，一旦关进笼子里，两小时内就会因剧烈的应激性惊恐撞断颈椎，且它们只吃深海鲜鱼，完全不具备圈养经济性；

巨型果蝠与海鬣蜥——生长极慢，圈养环境下拒绝进食，饲养成本远超肉质收益。

唯一的奇迹，隐藏在海岛内陆次生林边缘的灌木丛中。

那是一群在数百年前，可能由古代波利尼西亚航海者带上岛屿并野化的古老家禽后代：野生原鸡（Feral Jungle Fowl）。

它们通体羽毛艳丽，体型比现代肉鸡略小，修长结实，奔跑如飞。

它们是天赐的完美驯化胚料：

杂食性，消化系统强大到能消化粗纤维、野生碎浆果、草籽与沙滩上的沙蚤跳虾；

生长迅速，四个月即可性成熟产蛋；

最关键的是，它们的神经回路深处，依然保留着数千年前被人类驯养过的隐性家畜基因烙印！

第二道工程：无伤活捕陷阱与防逃防天敌鸡舍。

驯养的第一步，是获得完好无损的活体。

如果用重石落电或者带倒刺的弓箭，你得到的只能是一具骨折流血的尸体。

我采用了古老而温和的“马尾多圈地面套索走廊（Run-Snare）”。

在原鸡经常出没觅食的密林兽道上，我用细枯枝在两侧插出了一道长达五米的狭窄强制通道。

在通道正中央的地面上，我密密麻麻地布置了十几个用细剑麻单丝编织出的微型活套圈；

在套圈四周的地面上，散落着一小堆压碎的烤椰子干碎屑与炒熟的面包果粒。

椰油的浓郁香气在森林底层扩散。

两只红冠绿尾的成年母原鸡，顺着狭窄的通道啄食而来。

当它们的细爪踏入隐藏在枯叶中的细麻圈的瞬间，弹力木桩猛然抬起！

绳圈瞬间锁死了它们的跗跖骨关节。

没有骨折，没有撕裂，两只活生生、羽毛完整的成年母原鸡在网袋中扑腾着翅膀。

紧接着，是建筑学与行为学的双重保障：

原鸡骨子里依然保留着鸟类的飞行本能，双腿弹跳能飞过两米多高的灌木。

在把它们带回营地后，我做的第一件事是极其专业的“单侧初级飞羽羽管修剪（Wing Clipping）”：

用锋利的黑曜石刀片，将母鸡右侧翅膀最外缘的十根初级飞羽的羽片，整整齐齐地剪去一半。

绝不能两边都剪！

剪去单侧飞羽，破坏了它双侧翅膀在空气动力学上的升力对称性。

当它试图拍打翅膀起飞时，不对称的升力力矩会瞬间迫使它在空中发生失速自旋，跌回地面，彻底剥夺了它的越狱飞行能力，却完全不伤及它的肌肉与血管。

鸡舍设立在主石屋下风向、排水良好的缓坡上：

用直径八厘米的粗坚硬毛竹，密密麻麻地砸入地下半米深，构筑成了一间三米乘三米、高两米的坚固竹木围栏；

围栏顶部用细编的露兜叶网严密覆盖，防止野鹰从高空俯冲偷袭；

而在围栏内部，我严格顺应鸡类的天性，用两根去皮的光滑竹竿，离地一米架设了高低错落的“夜间栖架”。

鸟类在地面过夜会引发致命的恐慌应激，只有双爪死死抓在离地的树枝上，它们的神经系统才能获得深度睡眠的安全感。

第三道行为学魔法：操作性条件反射与微量矿物供给。

刚被关进笼子里的野生原鸡，只要我一靠近，就会惊恐地撞击竹栅栏，发出尖锐刺耳的惨叫。

必须重新建立它对人类的信任连接。

我启动了斯金纳的“操作性条件反射（Operant Conditioning）”：

每天清晨与黄昏两次喂食，在踏入鸡舍前，我先用一根短木棍，有节奏地敲击三下鸡舍门前的干燥空竹筒。

笃！笃！笃！

声音清脆，穿透力极强。

敲击声刚落，我立刻将一碗富含油脂的温热椰子渣、煮熟的碎红薯，以及在烂树桩下挖出来的几十条肥嫩蠕动的白色甲虫天牛幼虫，倒在食槽里。

最初的两天，它们躲在栖架角落里不敢动弹；

到了第五天，只要这三声清脆的竹筒声响起，两只母鸡的胃酸与唾液腺便会在声音刺激下疯狂分泌；

到了第二周，当我提着食槽走入围栏时，它们不仅不再逃窜，反而扑棱着双翅，发出温顺欢快的“咯咯”低鸣，争先恐后地围拢在我的脚踝边，甚至敢直接从我的掌心里啄食高蛋白的白蚁幼虫。

它们把我的气味与身影，在神经回路深处彻底绑定成了“丰饶与安全”的终极符号。

更重要的营养学底牌：高产蛋必须的“钙与胃石循环”。

母鸡下蛋需要海量的碳酸钙来合成坚硬的蛋壳，如果食物缺钙，母鸡会患上严重的软骨病并停止产蛋；

同时，鸟类没有牙齿，食物全部依靠肌胃内部的坚硬沙粒进行机械研磨。

我在鸡舍的角落里，常年放置了两个特殊的陶槽：

一个盛满了从海滩捡来、砸碎成米粒大小的洁白煅烧贝壳碎片；

另一个盛满了颗粒圆润的细坚硬石英碎砂砾。

母鸡在本能的驱使下，每天大量啄食这些贝壳粉与砂砾。

贝壳粉在腺胃的胃酸中解离出高浓度的钙离子，直接输送进输卵管合成坚实的蛋壳；

而石英砂砾常驻在厚实的肌胃砂囊中，像一台永不停歇的微型球磨机，将所有吞下的粗糙草籽和坚硬虫壳磨成细腻的营养糜汁。

一个月后的一个清晨。

当第一缕晨光洒在整洁干燥的鸡舍里时，我照例敲响了竹筒。

在那个垫着厚厚干燥木棉花絮与细软干草的离地竹编产蛋窝深处，静静地躺着一枚只有土鸡蛋大小、通体呈现出温润浅赭石色、表面干干净净的椭圆形硬壳蛋。

我伸出颤抖而粗糙的大手，将它小心翼翼地捧在手心里。

蛋壳上还带着母鸡体温留下的余热，光滑、致密、沉甸甸的。

我快步走回石屋的火塘边，在烧沸的陶罐里盛出半碗清泉水。

轻轻在陶碗边缘一敲。

咔嚓。

金黄色、饱满挺拔如小太阳一般的浓稠蛋黄，包裹在晶莹剔透、毫无腥味的致密蛋白液中，滑入了滚烫的开水里。

一股纯正、高贵、浓郁到令人战栗的熟鸡蛋香气，瞬间在整个石屋中弥漫开来。

我闭上眼睛，小口咽下那团凝固成白玉般的嫩蛋白与浓郁流油的蛋黄。

热量在食道里燃烧，疲惫的细胞在完全蛋白质的灌溉下发出无声的欢呼。

大自然的循环，在这一枚小小的鸡蛋里，完成了最华丽的闭环。

海滩上的碎屑变成了鸡食，鸡食变成了活生生的鲜蛋，鸡蛋滋养了我的肌肉，而鸡粪则化作了黑土农田里茁壮成长的红薯与芋头。

这不再是野人有一顿没一顿的饥荒侥幸。

这是人类通过对动物行为学、空气动力学修剪与营养生物化学的精准干预，在这座荒岛的方寸之地，重建起的第一座微型家庭生态牧场。

我听着鸡舍里传来的悠闲打鸣声，看着窗外生机勃勃的菜园。

生活，在这一刻，拥有了属于它自己的尊严与秩序。
