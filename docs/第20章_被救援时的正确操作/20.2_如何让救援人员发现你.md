# 20.2 如何让救援人员发现你

在海难搜救的历史数据中，有一个令人毛骨悚然的统计事实：

超过百分之六十最终死于海上的遇难者，在其生前最后的一两天里，搜救飞机都曾直接从他们的头顶空域飞过。

很多人在死前都看到了飞机银白色的机翼，甚至看清了机舱舷窗的反光；

但飞机却在他们的注视下，毫无察觉地呼啸而去，消失在天际线上。

在开阔大洋上，“你看见他们”与“他们看见你”，在视光学和概率论上，相差了整整十万八千里。

一架搜救机在千米高空巡航，机组观测员要用肉眼扫描数千平方公里的茫茫海域。

海面上波涛翻滚，数以亿计的白色浪花碎屑在阳光下反射着刺目的眩光，洋面上的风寒水沫形成了一层微弱的雾状气溶胶。

在飞行员的眼帘中，一个漂浮在浪谷里的成年人类，其视觉像素甚至不足一个微米，完美地溶解在了大洋翻滚的白色高频背景噪声中。

如果你以为只要站在甲板上拼命大喊大叫、或者像疯子一样挥舞一件湿淋淋的小衣服，他们就能在几千米外注意到你，那是对视觉神经学最致命的误解。

要想从大洋的背景噪声中破茧而出，你必须动用三项具有压倒性信噪比的光学与身体工程武器。

第一项武器：高频持续定向光子压制。

反光镜不是玩具，它是一把精准的光学激光枪。

很多人在看到飞机的一瞬间，用反光镜照了一下，发现飞机没反应，就心灰意冷地放下了镜子。

在几何光学中，飞机的巡航速度高达每秒一百多米。

一次单薄的漫反射闪烁，在飞行员眼角的余光中可能只是被误判为某朵海浪的偶然反光。

你必须进行“不间断的高频连续光学锁定”。

右手紧握那块磨得如水银镜面般纯白的砗磲贝反光镜（或那块飞机舷窗镀铝碎片），贴近眼眶；

左手伸出，V字指缝准星死死咬住飞机的驾驶舱舷窗！

不要只晃动一次。

手腕以极高的微振频率，让刺目的太阳反射耀斑，以每秒三次的极快节奏，形成密集的“脉冲式光子风暴”，持续不断、毫不留情地直轰飞行员的挡风玻璃！

一次闪烁可能是浪花，但连续二十次、三十次有节奏的刺目强闪，会让飞行员的视觉皮层瞬间拉响警报：

哪怕他在低头检查仪表盘，眼角余光也会被这种异常的高频人造闪烁彻底激活。

保持高频闪烁，直到看见飞机的机翼发生清晰的左右摇晃为止！

而在黑夜，如果你手里拥有残存电量的手机LED闪光灯或手电筒，记住一条航空救生绝密铁律：

绝对禁止用强光持续直射飞行员的驾驶舱！

现代夜间搜救飞行员，全员佩戴高灵敏度的夜视仪（NVG）。

夜视仪的光电阴极能将微弱的光线放大数万倍。如果你用强光手电筒正对驾驶舱直射，夜视仪的荧光屏会在瞬间发生严重的“光晕饱和雪崩（Phosphor Bloom）”，导致飞行员瞬间陷入失明，甚至引发严重的低空操纵失控坠海灾难！

在夜间，将光束对准独木舟自身的风帆，或者对准水面进行间歇性扫射。

用光束点亮整面巨大的露兜叶蟹爪帆，将整艘小船化作一盏在黑暗中柔和发光的巨型灯笼；

或者将手电筒以莫尔斯电码的节奏（三短三长三短），向斜上方四十五度的空域进行离散频闪。

第二项武器：荧光素钠千平米海面染色剂（Sea Dye Marker）。

如果你的救生包里，或者从飞机残骸防水盒中捡到了那包仅有手掌大小、沉甸甸的黄色粉末包——海事救生荧光染色剂（Uranine，荧光素钠）。

请记住，这是大洋搜救中最昂贵的视觉核武器。

绝不能在看到飞机前盲目撕开！

荧光素钠在海水中的有效扩散与高浓度留存时间，只有区区两到三个小时。

过早撕开，洋流会在飞机到来前将它稀释得无影无踪。

最佳的投掷时机：

当你听到远方天际线上隐约传来了巡逻机那低沉沉稳的引擎轰鸣声、并且确信它的搜索航线正穿过你所在的海域时——

立刻解开荧光包的拉绳，将其狠狠抛入独木舟的迎风侧海水中！

奇迹在零点五秒内爆发了。

高水溶性的荧光素钠晶体在接触海水的一瞬间，爆发出一场分子层面的剧烈扩散。

它的分子结构具有极高量子产率的光致发光特性：

它疯狂吸收太阳光谱中穿透力最强的四百九十四纳米蓝光光子，并以绝对的效率，激发释放出波长为五百二十一纳米的耀眼翠绿色荧光！

不到十五分钟。

在洋流与波浪的搅动下，原本深邃幽暗的深蓝大海表面，被硬生生染出了一大片面积超过数千平方米、闪烁着刺目荧光翠绿色（如同亮绿色高光笔）的巨型液态地标！

这片巨大的绿色油画在深蓝色的海洋背景上，具有令人发指的视觉反差。

即使飞机在三千米的高空巡航，飞行员在十海里之外，一眼就能在单调的深蓝大洋中，看到这块如同外星印记般璀璨夺目的巨大亮绿色光斑！

小船可能看不清，但两千平方米的荧光绿毯，绝无被错过的可能。

第三项武器：国际民航空对地标准肢体语言。

当搜救机终于被你的镜光或绿斑吸引，压低机头向你俯冲盘旋而来时；

这是幸存者最容易犯下致命肢体语言错误的生死时刻。

很多人在这个时候，会慌乱地挥舞手里的某块破布，或者在甲板上单手乱挥、双脚跳跃。

在空中观测员的视野里，单手乱挥或者小布条的抖动，极易被气流颠簸和水花误读为普通的漂浮垃圾，甚至被误读为“我很好，我只是普通渔民，不需要救援”。

身体是大地上的最后一个字母。

必须摆出国际民用航空组织唯一法定认可的“绝对求救姿态”：

双脚微微分开，像大树一样稳稳踏死在甲板或沙滩上，保持绝对的身体重心稳定；

深吸一口气，将双臂笔直伸向天空正上方！

两臂完全伸直，指尖朝天，双臂与头颅在空中形成一个清晰、对称、刚劲的绝对几何字母：“V”（或“Y”）。

在国际航空救援法典里，这个双臂高举的几何符号只有一个唯一含义：

“是的！正是我！请立刻把我接走！（YES / PICK ME UP）”

保持这个姿态，双臂不要乱晃，以两秒钟为一个节律，缓缓将双臂从垂直状态，向两侧平展至水平位置，随后再次高高举过头顶。

动作要大、要慢、要沉稳、要充满绝对的几何对称性！

这种具有强烈人工韵律的大幅度机械式肢体开合，能让飞行员在千米高空瞬间完成模式识别（Pattern Recognition）。

严禁使用的禁忌动作：

绝对禁止单手挥舞（单手举起在航空代码中代表“不需要帮助/否定”）；

绝对禁止双手交叉在胸前静止不动（代表“拒绝援助”）；

更绝对禁止在小独木舟狭窄的甲板上疯狂跳跃（那会在救援力量到达前，直接导致独木舟失衡倾覆，让你在救生员眼前坠海溺亡）。

引擎的咆哮声越来越近，螺旋桨撕裂空气的剧烈低频震颤，让我的胸腔都在微微共鸣。

在那片翻滚着耀眼荧光翠绿色的深蓝海面上；

在迎风高高扬起的金色蟹爪帆旁；

我像一座青铜雕像一样直直地立在独木舟座舱的正中央。

双臂笔直指天，双眼迎着狂风，目光如火炬般炽热。

反光镜的光斑死死锁死驾驶舱，荧光绿毯在脚下延展千米，身体在长空中定格为那道永不屈服的呼救之矢。

银白色的巡逻机在数百米的高空掠过我的头顶。

遮蔽天日的巨大机翼，在海天之间猛烈地向左倾斜，随后又向右倾斜！

巨大的发动机在海风中爆发出震耳欲聋的欢呼咆哮。

他们看见我了！

他们看懂了我的每一个信号，看懂了我的每一个动作，看懂了我在这片荒海深处用全部的智慧与意志写下的人类图腾。

我缓缓放下酸痛的双臂，长长地吐出了一口滚烫的白汽。

信号战结束了。

接下来的挑战，将是那架即将呼啸降临的巨型钢铁旋翼怪物。
