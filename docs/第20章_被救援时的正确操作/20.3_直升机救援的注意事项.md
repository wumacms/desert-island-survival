# 20.3 直升机救援的注意事项

很多人在漫长的苦难中，把搜救直升机想象成一位轻盈降临的天使。

但当一架重达十吨、由两台三千轴马力涡轮轴发动机驱动的重型海上搜救直升机（如“黑鹰”或“超美洲豹”）真正悬停在你的头顶上方三十米处时，你才会明白：

这绝不是什么温情脉脉的天使，这是一头由金属、暴风与高压电构成的狂暴机械怪兽。

如果你不知道如何与这头怪兽协同配合，救援不仅不能拯救你，反而在最后几十秒内，以极其荒唐的方式将你撕得粉碎。

在大洋直升机救援的严酷现实中，有三大致命的物理陷阱，每一个都能在眨眼之间夺走一个生还者的性命。

第一大陷阱：七十节飓风般的旋翼下洗气流（Rotor Downwash）。

当直径达到十六米的巨大主旋翼以每秒数百米的高速旋转时，它每秒钟要将数十吨冷空气以极高的速度向下强暴推射。

在直升机正下方的海面上，会瞬间形成一片中心风力超过七十节（时速一百三十公里以上，相当于十二级暴风）的局地微型飓风！

原本平静的海面在下洗气流的轰击下，水沫被狂暴撕扯成一片白茫茫的狂暴气溶胶；

如果此时你依然将独木舟的蟹爪帆高高升起，下洗气流的下压力与剧烈乱流，会在两秒钟内将轻盈的竹桁帆骨生生折断，或者瞬间将整艘独木舟直接按入海底掀翻！

听到直升机呼啸迫近的最初三十秒内，第一道铁律是：

降帆！立刻彻底降帆！

解开主帆索，将整面巨大的露兜叶帆连同上下竹桁，迅速放倒在主船舱甲板上，用两条粗绳死死绑死在龙骨上；

把船舱里所有未固定的轻型物资、漂浮木片、衣物彻底用缆绳网死死网住——狂暴的下洗风压能将一块看似沉重的树皮席瞬间卷上半空，一旦这块飞舞的杂物被吸入直升机高速旋转的尾桨或进气道中，就会引爆整架直升机的空中解体与机毁人亡！

保护你自己：

伏低身体，双膝跪在主船舱底部，降低受风重心；

千万不要仰头直视直升机！

下洗气流卷起的海水飞沫，在一百多公里的时速下像无数颗细小的铅弹一样密集抽打在你的眼球和脸颊上，强烈的盐雾会在几秒内灼伤你的眼角膜，让你在救援的关键时刻彻底失明。

眯起眼睛，头颅微垂，用手臂遮挡眼睛上方，只透过指缝保持对上方吊索的余光观察。

第二大陷阱：致命的万伏高压静电释放（Static Electricity Shock）。

这是大洋直升机搜救中最隐蔽、也是最残忍的杀手。

在物理学中，直升机碳纤维旋翼与金属机身，在大洋饱含盐雾与微粒的对流层中以极高转速剧烈摩擦。

整架直升机化作了一台巨大的范德格拉夫静电起电机（Van de Graaff generator）。

机身表面蓄积的静电荷无处释放，使得悬停在半空中的直升机金属外壳，与下方的海面之间，产生了一个高达一万至三万伏特的恐怖静电高压电位差！

当直升机舱门打开，一根细长的钢丝绞车吊索带着巨大的金属救援吊钩，从空中缓缓垂落下来时；

很多遇难者在极度渴望获救的狂喜中，会本能地伸出双手，凌空去一把抓住那根还在半空中晃荡的金属挂钩——

啪！

一道肉眼可见的刺目蓝紫色高压电弧，会在接触的瞬间轰然击穿空气！

数万伏特的高压静电电流，会顺着受害者湿漉漉、饱含导电盐水的双臂，毫无阻碍地瞬间直穿心脏胸腔！

这种剧烈的电击虽然电流持续时间极短，但强大的电脉冲足以在零点一秒内诱发急性心室纤颤（Ventricular Fibrillation），或者引发剧烈的呼吸肌强直痉挛，让遇难者在被救援的那一秒当场心跳骤停，跌入海浪深处溺亡。

这道关卡的绝对铁律被称为“接地释放法则”：

任由那个金属吊钩在半空中晃荡！绝对不要伸手去凌空抓它！

必须耐心等待吊钩的金属头部，先接触到海水，或者重重砸在湿润的船舱甲板上！

一旦金属吊钩与海水接触的一刹那，微观层面的万伏高压静电荷便会顺着海水瞬间彻底释放泄入大洋这片无限的电荷库中。

完成了接地放电之后，金属吊钩彻底沦为一个无害的普通铁块。

此时，才能用双手稳稳抓握！

第三大陷阱：吊具穿戴姿态与“绝命拥抱”。

如果直升机空投下了搜救潜水员（Rescue Swimmer），你的大脑必须进入“绝对服从模式”。

潜水员拥有顶级的专业救援技能，不要在惊慌失措中扑上去抱住他的脖子——落水者的致命熊抱是淹死搜救员的第一原因。

双手摊开，放松身体，任由他接管你的体位。

如果直升机没有下放潜水员，而是直接垂下了一具“马蹄形腋下双吊带（Rescue Strop）”：

穿戴姿态是决定生死的最后一道考题。

很多人以为把它套在腰上，或者套在腿上。错！

把马蹄形的厚实软垫环，从头顶套下，两根吊带深深勒入自己的双侧腋窝下方！

让加厚的主受力软垫，紧紧贴在后背的肩胛骨下方位置；

用胸前的可调节金属卡环，在胸骨正前方用力拉紧收束，死死锁住吊带的开口，绝不让它松脱。

接下来的动作，是保命的核心：

“自卫拥抱姿态（The Protective Cross）”。

把你的双臂，在胸骨正前方紧紧交叉，双手死死抱住对侧的吊带！

头颅低下，下巴紧紧抵住自己的胸口。

在整个被钢丝绞车吊离水面、向空中几十米高处垂直提升的过程中，绝对禁止把双臂向上高高举起！

在高达七十节的下洗气流撕扯与悬空重力颠簸下，一旦你出于本能将双臂举过头顶，你的整个躯干就会像一条滑腻的泥鳅一样，瞬间从宽松的吊带中向下彻底滑脱！

你会在三十米的高空，笔直坠入海面摔死。

双手死死锁死在胸前，整个人化作一个坚硬的受力球体。

最后一条红线：绝对禁止将直升机缆绳固定在船上！

有些遇难者在恐惧中，试图把直升机的钢缆死死拴在自己的独木舟桅杆或横梁上，企图“把船一起吊走”。

那是彻底的疯子行径。

一艘吸饱了水分的硬木独木舟重达上千公斤，加上风浪的剧烈下拉力矩，其瞬态载荷会瞬间超越直升机救生绞车的剪切销极限。

为了保障整架直升机上机组人员的安全，飞行员会在两秒钟内毫不犹豫地按下紧急断缆炸药电钮，将钢缆彻底炸断；

更严重的后果是，一道突然打来的大洋巨浪会顺着死死捆绑的钢缆，把三十米高空的直升机硬生生拖拽侧翻、砸入海中，引发毁灭性的机毁人亡大灾难。

船是死物，命是活的。

舍弃船只，登上天梯！

巨大的下洗风暴将海面压出一道巨大的白色凹坑。

水沫在呼啸狂奔，狂风在耳边爆发出震耳欲聋的咆哮。

我单膝跪在甲板上，任由金属吊钩在海水中洗去万伏静电，随后稳稳一把抓住了湿润冰凉的钢环。

套过头顶，勒紧腋下，胸前收死卡环。

双手死死交叉在胸前，下巴抵住锁骨。

我抬起头，透过被狂风吹得几乎睁不开的眼角，向着上方三十米处大开的机舱门，做出了一个坚定、决绝、毫无犹疑的“大拇指朝上（Thumbs Up）”战术手势！

上升！

崩！

高强度钢丝绳在绞车的牵引下瞬间崩直，发出坚韧的金属嗡鸣。

一股巨大而平稳的拉力，瞬间勒紧了我的双侧腋下。

双脚彻底离开了摇晃数十天的独木舟甲板！

海水在我的脚下飞速倒退，狂暴的气流在耳边疯狂撕扯，但双手死死锁在胸前，身躯在半空中稳如磐石。

独木舟在脚下化作了一个越来越小、在深蓝墨浪中起伏的金色木壳。

它完成了它的全部使命。

而我，在这根细长的现代高强度钢丝绳拉扯下，正以每秒两米的垂直速度，脱离大洋的重力深渊，迎着那扇灯火通明的机舱，直奔文明的世界而去！
