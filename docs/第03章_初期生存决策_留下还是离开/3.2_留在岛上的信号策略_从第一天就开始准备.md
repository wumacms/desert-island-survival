# 3.2 留在岛上的信号策略：从第一天就开始准备

不指望救援，不等于放弃信号。

相反，在荒岛上，真正的信号绝不是听到飞机引擎轰鸣时才手忙脚乱去点的。

一架巡逻机或者一艘偶尔路过的渔船，从地平线的一端出现到彻底消失，通常只有两到三分钟的窗口期。

如果你那时候才去满地找枯枝、拔干草、擦火星，等你被浓烟呛得一把鼻涕一把泪的时候，天空中剩下的只有风声和那架早已飞过视界边缘的远去黑点。

信号不是一次性的冲动，它是一套二十四小时不睡觉的防空系统。

早晨的潮水刚退，我扛着从林缘拖来的粗木头，走上了黑色的开阔沙滩。

首先是被动信号。

在几千米的高空往下看，大自然最厌恶的东西，就是笔直的直线和精准的几何形状。大自然里有弯曲的海岸、参差的树冠、不规则的礁石，但绝不会自己长出平行的直角。

我找来了一批被海水冲刷得雪白的大珊瑚石，每一块都有人头那么大。

在黑褐色的火山砂滩上，这种雪白有着极高对比度。

我在平整的沙滩中央，用脚踩出一条深沟，然后把这些白珊瑚石一块挨着一块嵌进沙地里。我摆了一个巨大的国际通用求救符号：“V”。

在航空搜救代码里，“V”代表着“需要救援”。它比“SOS”好得多，只有两条笔直的斜线，笔画极粗，节省材料，而且在风沙的吹蚀下最不容易变形模糊。

每一条笔画长达十五米，宽一米半。

不仅如此，我还用粗木棍沿着石头的边缘，挖出了一条三十公分深、迎着正午阳光方向的阴影槽。当太阳升起来的时候，白色的珊瑚石会投下一道刀切般的浓黑阴影。一黑一白，对比度成倍放大，哪怕在高空巡航的高空侦察机，光学镜头也能一眼咬住这个绝对人造的几何线条。

接着是主动信号。

我在高潮线上方的平坦开阔处，清理出了三个直径两米的圆形干地。

三个圆圈排成一个边长三十米的等边三角形。这是国际公认的遇难信号阵型。

我把收集来的粗干柴架成三个两米高的圆锥形柴火堆。最底下是干燥的引火绒，上面是细枯枝，再外面是粗大的硬木。

最要紧的，是防水和产烟材料。

我用大张的棕榈树叶做成了三个像伞一样的雨篷，罩在柴堆顶上，确保哪怕连下三天大雨，里面的引火柴也是干的。

而在每一个柴堆旁边，我都堆了一大垛绿油油的湿海草、新鲜的蕨类植物和带油性的生灌木叶子。

科学的常识摆在那里：白天要浓烟，夜里要明火。

纯木头燃烧只产生少量的浅灰烟雾，在高空的大风里很快就被吹散了；但一旦把潮湿的绿色植物捂在已经烧旺的火堆上，不完全燃烧和大量水蒸气凝结，就会瞬间产生一根粗壮、雪白、冲上几百米高空的巨大烟柱。

而在晚上，只要把覆盖物掀开，充足的氧气会让干硬的硬木腾起三四米高的熊熊烈火，在几十海里外的大洋黑夜里像灯塔一样刺眼。

最后，是贴身携带的信标。

我把那面擦得雪亮的手表不锈钢后盖，用拆下来的鞋带穿好，牢牢挂在脖子前。

在正午的阳光下，只要把手指比成一个“V”字形瞄准远处的地平线，把反射的光斑投进指缝，这面小小的金属凸面就能把阳光反射到三十海里以外。那道刺眼的光芒，比一门大炮发射时的闪光还要显眼。

一幅巨大的地面石阵，三座随时可以点燃的烟火金字塔，一面贴在胸口的聚光镜。

这套系统做完了。它很沉默，静静地趴在海滩边缘。

我拍了拍手上的白石灰，长长地呼出一口气。

“躺着吧，哨兵们，”我看着那三堆覆盖着叶子的柴火，“希望你们永远别被点着；但如果真有那么一秒钟的机会，你们得给老子争口气。”

我转过身，回到了营地。

防空的网已经织好了，接下来，该彻底堵死脑子里那个盲目出海的自杀冲动了。
