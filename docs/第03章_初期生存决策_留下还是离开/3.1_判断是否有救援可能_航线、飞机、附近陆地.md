# 3.1 判断是否有救援可能：航线、飞机、附近陆地

第三天的黄昏来临的时候，我坐在玄武岩高台上，看着大海发呆。

夕阳把平静的海面染成了一大片暗红色的铅皮。海浪一下一下拍打着外礁，声音传得很远，很沉。

三天了。整整七十二个小时过去了。

在这三天里，我无数次抬头望向天空。晴天的时候，天顶蓝得发脆，但我连一条飞机拉出的白烟都没有见过。

现代的民航客机都在一万米以上的高空巡航。它们燃烧航空煤油，喷出的水蒸气在高空遇到零下四十度的低温，会瞬间凝结成一道道笔直、经久不散的白色尾迹。只要有一条航线从这座岛的上空经过，哪怕飞机小得像一只苍蝇，那道白色的尾迹也能在蓝天上挂上小半天。

但是天空中干干净净。什么也没有。

这说明这座岛彻底偏离了国际大圆航线的覆盖区。它孤零零地掉在某条航线走廊的盲区里，像被整个世界遗忘了一样。

我再看海面。

海平线上空空荡荡，没有轮船那根细细的桅杆，也没有柴油机喷出的黑烟。

现代的远洋货轮都有固定的水道。它们沿着大洋环流和最短的几何航线航行，就像火车在铁轨上跑一样准时。如果这里靠近主要航道，夜里远方的大海上，至少能看到十海里外货轮桅顶上的红绿导航灯。

但这三天的夜里，除了天上的星星，四周的大洋漆黑得像一桶墨水。

“别指望搜救队了，老伙计。”我对自己轻声说。

在大学的统计学课上，我给学生讲过贝叶斯概率和蒙特卡洛搜救模型。

一架飞机或者一艘船失事在大洋里，搜救范围会随着时间的推移，以搜救半径的平方呈几何级数向外爆炸式扩张。

第一天，搜索区域可能只有几百平方海里；到了第三天，洋流和风偏会把可能漂移的范围推散到几万平方海里。在缺乏应急无线电示位标信号的前提下，调动几架巡逻机在几万平方海里的汪洋里寻找一座不知名的小岛，难度比在撒哈拉沙漠里找一粒特定的沙子还要大。

搜救需要成本，需要燃料，更需要时间。

在文明世界的搜救手册里，七十二小时是一个坎。过了这三天，幸存者的生存概率曲线会从百分之八十急剧跌落到个位数。再过几天，搜救行动就会悄无声息地下调级别，从“搜救”变成“搜寻遗骸”，最后变成档案袋里的一张失踪报告。

风吹乱了我散乱的头发。

我深深吸了一口微咸的空气，把双手撑在粗糙的黑石头上。

承认现实是残酷的，但也是让人解脱的。

从今天这一刻起，我彻底掐死了心底深处那个等待被拯救的念头。等待只会滋生惰性，会让你把希望寄托在虚无缥缈的地平线上，会在每一次太阳落下时摧毁你的意志。

没有人知道我在这里。甚至没有人知道我还活着。

从现在开始，我不是一个在沙滩上眼巴巴盼着救生艇的遇难者。我是一个被命运扔回旧石器时代的开拓者。这座岛就是我余生的全部疆土。

太阳完全沉进了海里。海面变成了一片冰冷的青灰色。

我站起身，转过头去，看着身后那座巍峨黝黑的火山峰。

既然没人来接我，那我就得在这座岛上，替自己把日子长长久久地过下去。
