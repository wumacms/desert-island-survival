# 3.4 生存日志：记录日期、天气、资源与身体状态

下午晚些时候，我钻进了岩壁最深处的干燥石洞里。

这里有一面极其平整的垂直玄武岩石壁，风吹不着，雨淋不着。石面呈现出一种深沉的铁青色，干燥得像晒透了的砚台。

我从怀里掏出那块锋利的黑曜石碎块，又在地上捡起一块拳头大小、坚硬致密的玄武岩当作石锤。

我跪在地上，左手把黑曜石的锋刃顶在石壁上，右手挥起石锤，轻轻砸了下去。

“叮。”

一声清脆短促的撞击声在石洞里回荡。黑曜石在玄武岩表面崩下了一小撮细微的白石粉，留下了一道扎实深刻的凹痕。

古代的鲁滨逊在木桩上刻横道来计算日子。但对我来说，仅仅记录日期是远远不够的。

在与世隔绝的孤岛上，时间不是一个数字，而是一组关乎生死存亡的连续变量。如果放任大脑在空白的日子里漂流，记忆很快就会变得模糊，白天和黑夜会融成一团黏稠的绝望，焦虑和幻觉就会趁虚而入。

把客观现实刻在石头上，是守住理智底线的最好锚桩。

我刻下了第一栏：天文与历法。

一道横线代表一天，四道横线加一根斜杠代表五天。在第四道横线的旁边，我画了一只右侧鼓起的半圆，那是天上的盈凸月。

月亮的形状连着潮汐的大周期。距离满月还有两天，大潮的巅峰期就在这两天之内，那是海浪最凶、退潮最远的时刻。

我刻下了第二栏：气候与气象。

一个小小的向左倾斜的箭头，旁边画了一个代表低压的气旋漩涡，那是正从东北方压过来的暴风雨前锋。气压在持续走低，海浪的声音越来越沉闷，我给这场暴风雨的抵达倒计时划上了十八个小圆点。

十八个小时，这是留给我做最后加固的安全边界。

接着是第三栏：身体的物理参数。

这是最重要的生命监控板。

人对自身状态的直觉往往是不可靠的。发烧的时候你可能觉得冷，脱水的时候你可能反而感觉不到渴。

每天早晨睁开眼、身体还没坐起来的时候，我必须做的第一件事，就是伸出两根手指按在颈动脉上，数一分钟内的脉搏跳动次数。

正常的晨起静息心率应该在六十到七十下之间。

今天早晨，我的静息心率是七十八下。

这微弱升高的十来次心跳，是一道黄色的预警灯。它客观地告诉我：身体的有效循环血容量因为这两天的轻度脱水下降了，心脏必须加快泵血来维持脑部供氧。

紧接着是皮肤弹性测试。

我用两根手指死死揪起左手背上的皮肤，拉起来两公分，然后猛地松开。

被拉起的皮褶在一点五秒内平复了下去。如果平复的时间超过两秒，说明细胞内液已经到了极度匮乏的边缘。

左手背被珊瑚划伤的地方，红肿的范围没有扩大，皮温正常，没有化脓发烫。这证明免疫系统的白细胞暂时打赢了第一轮阻击战。

我把心率、皮褶平复时间和伤口状态，用简单的符号规规矩矩地刻在了岩壁的最下方。

每一个符号凿下去，都伴随着石粉的剥落和叮叮当当的脆响。

在这片没有人烟的蛮荒大地上，这些凿痕就像是一台运转中的心电监护仪，把一个活生生的人类的生命体征，冷静、严密地投射在亿万年前喷发的火山岩上。

它不带感情，不带祈求，只有冷冰冰的数据。

但我看着这排整齐的刻痕，心里却升起了一股巨大的安宁。

只要这些数据还在记录，逻辑就没有断裂；只要规律还在被严密追踪，我就没有沦为一个只知道凭借兽性苟延残喘的野人。

我放下石锤，吹掉了刻痕里的石粉。

天色渐晚，夜潮的声音又响起来了。而在岩洞深处，这个世界上最简陋也最坚硬的科学家工作台，已经正式立了起来。
