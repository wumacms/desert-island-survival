# 3.3 尝试离开的条件：竹筏、洋流、季风与风险计算

很多人在荒岛上待久了，脑子里就会冒出一个浪漫而致命的念头：

砍几根树，扎一只筏子，迎着风浪划向自由。

在电影和传奇小说里，主角总是能在几天之内砍倒几根大树，用藤条绑成一只小木排，扬起一块破布做的帆，然后在大洋上漂上几天，奇迹般地撞上一艘路过的货轮，或者回到文明社会的大陆。

那是纯粹的胡说八道。

只要你懂一点流体力学、材料力学和人体生理学，你就会明白：在没有做好万全准备之前，扎筏出海根本不是求生，而是体面地投海自尽。

正午最热的时候，我坐在玄武岩的阴影里，用一根削尖的硬木棍在沙地上列出这笔冰冷的账。

第一笔账，是材料力学。

活树砍下来，木材是绿的、湿的。生木头的密度通常在每立方厘米零点八到零点九五克之间，有的甚至比水还重。用这种生木头扎筏子，它本身浮在水面上就极其勉强。更可怕的是，未经风干的木纤维泡在海水里，会像海绵一样疯狂吸水，不出四十八小时，木头的自重就会超过浮力，整只木排会悄无声息地滑入海底。

要想拥有真正的浮力，必须用风干透了的死木，或者一截截两端密封的粗竹筒。竹节里的死空气，才是最可靠的浮力气囊。

就算找到了好木料，绑扎又是另一道鬼门关。

森林里的藤条和野树皮，含水量高，延伸率大。只要泡了海水，受到反复拉扯，它们的拉伸形变会达到百分之十五到二十。

而大洋上的波浪不是平静的湖水，那是两三米高、连绵不绝的重水涌浪。每一道波浪打过来，木排两端的原木都会承受完全不同方向的巨大扭转剪切力。这种持续不断的扭力，就像两把巨大的锯子，在不到两天的时间里就会把所有天然纤维绳索磨断、勒烂。

在浩瀚的大洋中央，你的筏子会像一副散了架的积木一样，一根一根木头各自漂走，把你光溜溜地扔进深不见底的深渊里。

第二笔账，是航海与洋流。

一只简陋的木筏没有龙骨，没有稳向板，也没有深舵。

在流体力学里，这意味着它完全无法逆风航行，甚至连侧风航行都做不到。它只能像一团毫无还手之力的浮萍，顺着下风向和表面洋流随波逐流。

而南半球的南赤道暖流，是向西奔流的。从这座岛往西，是几千海里空无一物的深洋。没有目的地的漂流，只是在用生命去跑一场必输的轮盘赌。

第三笔账，是人体的生理极限。

在无遮无拦的小木筏上，没有淡水泉，没有树荫。

赤道近乎暴烈的紫外线，会在三天内剥掉你全身的皮。海浪反复拍打，海水蒸发留下的高浓度盐霜会把皮肤腌得寸寸皲裂，引发大面积溃烂的海水皮疹。

更要命的是水。在海上暴晒的环境下，一个成年人一天至少需要两到三升的淡水来维持肾脏运转。

就算是一场最乐观的三十天漂流，你也必须在筏子上储备至少七十到九十升的淡水。

九十升水，就是将近两百斤的重量。你怎么在摇摇欲坠的木排上固定这重达两百斤的储水容器？用什么容器来确保它们在狂风暴雨中不被咸海水污染？

算到这里，沙滩上的数字已经不需要再算下去了。

“把心收回来吧，林深。”我把手里的木棍扔在地上。

离开这座岛是有条件的。

除非有一天，岛上的水源彻底枯竭，或者火山爆发把一切烧成了焦土；除非我用一两个月的时间，阴干了足够的竹木，编织出几百米高强度的三股防腐绳索；除非我造出一艘带有舷外支杆的真正双体航海皮筏，储存了上百升密封淡水和熏肉干；并且等到了季风转向的最安全窗口。

在那些严苛的条件全部满足之前，哪怕多看一眼远方的大海，都是对自己生命的背叛。

脚下这块坚实的火山岩，虽然粗粝、荒凉，但它不漏水，不散架，上面有能喝的淡水，有能吃的海贝，还能生起温暖的火堆。

这是我的要塞。

我拍拍屁股上的土，站了起来。出海的幻想被彻底埋葬了，我现在的唯一任务，是把这座要塞经营得像铁桶一样牢固。
