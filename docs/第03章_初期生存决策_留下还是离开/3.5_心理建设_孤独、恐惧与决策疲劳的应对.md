# 3.5 心理建设：孤独、恐惧与决策疲劳的应对

夜深了。

石洞外面的海风越刮越紧，吹过断崖的岩缝，发出一阵阵尖厉刺耳的呼啸声，像是有成百上千只冤魂在风里尖叫。

在文明社会里，一个人永远不会真正体会到什么是纯粹的孤独。

哪怕你把自己关在空无一人的房间里，窗外也总有汽车驶过的胎噪，墙壁里有自来水管道的流动声，头顶的灯泡在发出微弱的工频嗡鸣。那些人造的声音和细节，是一张巨大的无形安全网，把人包裹在文明的羊水里。

但在大洋深处的荒岛上，当一切人造的光亮和声音都被彻底抽空之后，那种死寂比海啸还要沉重。

它会像潮水一样压在你的耳膜上。

在头三天过去后，身体的剧痛和慌乱渐渐平息，真正的噬心之魔才悄悄从黑暗里爬了出来。

那是大脑的听觉空想症。

有好几次，当海浪猛烈撞击岩石、碎成一片白沫的时候，我分明听到了母亲在隔壁房间喊我的小名，听到了大学走廊里下课的铃声，甚至听到了搜救直升机旋翼转动的噗噗声。

我猛地坐直身子，冲到洞口，黑暗中除了一望无际的黑色波涛和狂乱摇晃的树冠，什么也没有。

“坐回去，林克，”我拍了拍自己的脸颊，感觉有些冰凉，“那是风声在大脑颞叶里搞出来的恶作剧。没有人在喊你。”

除了孤独，还有更隐蔽的杀手：决策疲劳。

在城市里，百分之九十的日常行为是不需要动脑子的。水龙头拧开就有水，电梯按一下就会下楼，饿了走到街角就能买到面包。

但在这里，每一个最微小的动作，都变成了高强度的生死计算。

踩哪块石头不会滑倒？折哪根树枝不会扎破手掌？现在咽下一口唾沫会不会加剧脱水？这片叶子到底能不能放进嘴里？

大脑的前额叶皮层每天在成千上万次的生死权衡中超负荷运转。

要不了几天，多巴胺就会彻底耗尽。人会陷入一种致命的倦怠和麻木：你不再想动弹，不再想捡柴，哪怕看着潮水漫过脚踝，你也只想闭上眼睛随它去。

那是心智在慢性猝死。

要战胜这种疲倦，唯一的办法，就是用严苛的纪律，给荒野生活套上一副铁打的日常规矩。

我给自己定下了雷打不动的作息表。

早晨六点，太阳一露头，必须立刻起身，检查颈动脉静息心率，收集叶片上的冷凝露水；

八点到十点，趁着天气还算凉爽，搜集柴火，加固防风掩体，绝不在沙滩上闲坐；

十一点到下午三点，太阳最暴烈的时刻，强迫自己在深阴处平躺休息，闭目养神，只做削木针、搓细绳这种不需要消耗体能的手工活；

下午四点半，大潮退去，雷打不动下到潮间带翻找贝类和岩蟹；

天黑前一刻钟，在玄武岩石壁上刻下一天的日志，吹熄杂念，钻进草棚睡觉。

把每一天切碎成一块块规整的积木，让所有动作变成机械的肌肉记忆。一旦生活有了秩序，大脑就不需要每分每秒都在做生死抉择，那种要把脑浆榨干的焦虑感，就会自然而然地退去。

还有，永远不要去想“我要在这座荒岛上被困一年还是十年”。

那种宏大而绝望的思考，能轻易压断任何硬汉的脊梁。

我只看眼前的四个小时。

这四个小时里，我的任务就是把避风棚顶上的棕榈叶多压上三根粗原木，防备即将到来的暴风雨。只要把这三根木头压好，我就赢了这一局。

人是一小步一小步活下来的，不是一下子活完整个人生的。

风暴在靠近，天边的雷声沉闷地滚过海面。

我把双手插在干燥的落叶堆里，深深地吸了一口气。

第一阶段结束了。这最凶险的前七十二小时，我从死神的水洼里爬了出来，摸清了小岛的经纬，摆好了防空的石阵，在石头上刻下了人类的文字，也给自己的心智筑起了一道坚硬的堤坝。

大自然可以狂暴，大海可以咆哮。

但只要我的理智还没有缴械，这具血肉之躯，就绝不会低头认输。
