# 9.5 海鱼处理：去毒、去刺、烹饪

抓到了鱼，只算赢了上半场。

在大洋里，许多海鱼的危险程度，甚至远远超过了陆地上的毒蛇。

一条长得肥美鲜艳的大海鱼，肉里可能藏着几百度高温都烧不毁的神经毒素；

而一条健康的鲭鱼，只要在热带的日光下多放两个小时，本身的鱼肉就会自发变质成引发严重过敏休克的毒药。

不懂海鱼病理学的人，在下锅的那一刻，就是在把死神请进自己的肚子里。

我坐在营地门廊前的大平石前，身边摆着洗净的粗竹筒和锋利如刀的黑曜石刮刀。

第一条必须绕开的死线，是雪卡毒素。

在热带珊瑚礁海域，这是最恶名昭彰的幽灵毒药。

它的源头，是附着在死珊瑚礁表面的一种微小甲藻。

草食性的小鱼吃下了甲藻，肉食性的大鱼吃下了小鱼，雪卡毒素顺着食物链的金字塔，一层一层在食物链顶端顶级掠食者的体内疯狂富集。

海鳝、巨型石斑鱼、大梭鱼、以及狗齿金枪鱼。

鱼的体型越大，寿命越长，体内的毒素累积就越惊人。

雪卡毒素是脂溶性的，耐热、耐酸，极度稳定。

不管是大火滚沸、炭火烧烤、还是用盐腌透，都根本无法破坏它的分子结构半点。

一旦中招，神经系统会发生极度诡异的逆转综合征：摸到冰块会觉得像被热铁烫伤，喝温水会觉得喉咙被冰刀刺穿；伴随而来的剧烈心动过缓和低血压，能在几天内让人的循环系统彻底衰竭。

避免雪卡毒素的法则极其冷酷：

第一，绝不吃任何在珊瑚礁区域钓上来的、体重大于两公斤的大型肉食性鱼类；

第二，绝不吃任何海鱼的肝脏、鱼卵、鱼肠和鱼头。

哪怕是轻度带毒的鱼，内脏里的毒素浓度也是普通鱼肉的五十到一百倍。

把鱼头剁掉，把内脏掏得干干净净，顺手撕掉附着在腹腔内壁上的那一层黑色腹膜。

第二条死线，是组胺中毒。

在钓到那些背部发青、肉质发红的鲻鱼或者金枪鱼时，必须在五分钟内动刀放血。

这类鱼的红肌里富含高浓度的游离组氨酸。

在热带三十度的高温下，只要死鱼在阳光下多晒两个小时，表皮的细菌就会大量繁殖，分泌组氨酸脱羧酶，把原本无害的氨基酸疯狂转化成剧毒的组胺。

吃下带组胺的鱼肉，哪怕煮得稀烂，几分钟内就会引发面部潮红、心动过速、哮喘窒息般的剧烈变态反应。

放血要狠。

割断两腮下方的动脉，沿着背脊正中央剖开，用刀尖把紧贴着脊椎骨的那条暗红色血线彻底刮除干净。

血放干净了，细菌就失去了繁殖的温床。

最后是烹饪。

经过严格去头、去脏、放血的海鱼，肉质雪白致密，散发着大海最纯粹的鲜香。

最好的烹饪方式，是用叶包蒸烤。

我摘来了一片宽大完好、洗得干干净净的野芭蕉叶，放在火苗上快速过了一下火。

受热的芭蕉叶瞬间变得极其柔软、坚韧，散发出一股温润的草木油脂香气。

把处理好的鱼肉片放在叶片中央，撒上一小撮洗干的海盐和压碎的野山姜末。

把芭蕉叶像包裹婴儿一样，四角紧紧对折包死，用细草绳绑成一个严实的包裹；

然后直接埋进达科他火坑边缘滚烫的草木灰和红炭堆里。

热灰的温度在一百二到一百五十度之间。

密闭的叶包把鱼肉自身的鲜美水分死死锁在内部，蒸汽在包裹里循环对流，像是一只天然的微型压力锅。

二十分钟后，扒开热灰，解开草绳。

芭蕉叶被烤成了焦黄色，但打开的瞬间，一股带着叶清香、熟鱼脂香的热气呼的一声扑面而来。

鱼肉白嫩得像蒜瓣一样，轻轻一抿就在舌尖上化开，鲜甜醇厚，油脂丰沛。

没有鱼腥，没有异味，每一口嚼下去，都是纯度极高的优质动物蛋白和救命的热量。

我靠在坚硬的石壁前，用竹筷把最后一片雪白的鱼肉挑进嘴里，嚼得很慢，咽得很深。

海洋的馈赠是慷慨的，但也是苛刻的。

它把最好的美味藏在毒刺和腐败的利刃之间，考验着每一个踏上它疆土的人类。

而只要你握稳手里的解剖刀，心怀敬畏，依理而行，那些藏在暗礁深处的凶险，就会化作滋养这具坚毅身躯的最强铠甲。
