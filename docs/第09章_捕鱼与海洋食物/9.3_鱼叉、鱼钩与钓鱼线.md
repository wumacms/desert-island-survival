# 9.3 鱼叉、鱼钩与钓鱼线

手握鱼叉站在礁石上的时候，你必须忘掉自己的眼睛。

水里的眼睛是一个骗子。

在阳光明媚的浅水礁盘旁，水清澈得像是一大块流动的绿水晶。你可以清清楚楚地看到一条两斤重的青衣鱼，正悬浮在两米外的浅水珊瑚旁缓慢摆尾。

许多人会把木矛的枪尖，笔直对准那条鱼的脊梁骨，用尽全力猛扎下去。

“哗啦！”

水花四溅，除了扎碎两块珊瑚石头，那条鱼早已轻蔑地一甩尾巴，钻进了深水里。

这不是因为你的速度不够快，而是因为你败给了斯涅尔折射定律。

空气的折射率是一点零，海水的折射率大约是一点三三。

当水下鱼身反射的光线穿透水面、射入人类的眼球时，光线在分界面上发生了折射，偏离了法线。

人类大脑的成像中枢习惯性地按照光线直线传播的逻辑进行投影。

你在水面上看到的，并不是真正的鱼，而是一个漂浮在真实鱼身斜上方的“虚像”。

真实的鱼，实际上停留在更深、更靠下的真实物理位置。

“往下扎，瞄准鱼腹下方十五公分。”我站在被浪花拍打的黑礁石上，在心里对自己反复默念。

不仅是瞄准，手里的武器也大有讲究。

单尖的木矛是一根极难命中的单兵武器，一旦刺中边缘，滑溜的鱼鳞会轻易让矛头打滑。

我砍下了一根两米半长、笔直坚韧的细青竹。

我用黑曜石刀刃，在竹竿的前端破开了一个十字交叉切口，深约二十公分。

在十字切口的中心，我硬塞进了一个用硬木削出来的十字支撑楔子，把原本聚拢在一起的四根竹条，强行向外撑开成一个十五度角的喇叭形。

每根竹条的尖端被削得极尖，并刻上了小小的倒钩；然后放进火塘的红炭上方慢慢烘烤。

不能烧焦。

微火烘烤会让青竹表面的水分迅速蒸发，木质素受热交联硬化，竹尖硬得像铁一样，耐磨耐磨。

最后，在十字切口的根部，用黄槿麻绳紧紧绑死，防止刺入时竹身向后开裂。

一把四叉弹性鱼叉制成了。

比起单头矛，它的打击面积瞬间扩大了四倍。

而且当四根竹尖同时刺中鱼身时，向内收缩的弹性竹条会像四根手指一样，牢牢把乱蹦的猎物锁在正中间，倒钩卡住皮肉，绝无挣脱的可能。

除了鱼叉，我还做了一根真正能钓大鱼的深水钓线。

那个碎了的手表里，拆出来了一根高碳钢的发条细丝。

我把它放进红炭里烧到微红退火，用指甲刀的铁锉小心翼翼地弯曲成一个完美的“J”形鱼钩，并在钩尖内侧刻出了锋利的倒刺；

然后再放进烈火里烧红，猛地扔进冰冷的淡水里淬火。

剧烈的温差让晶格重新排列，软铁瞬间变成了坚硬刚韧的高碳钢钩。

钓线是用最细的黄槿韧皮纤维搓出来的，只有缝衣线那么粗，表面涂满了防水的椰子油；底端拴着一块钻了孔的小玄武岩坠子。

挂上一块咬碎的肥嫩海胆肉，我把鱼线抛进了暗礁外缘十几米深的墨蓝色深渊里。

手里的细线在海流中轻轻震颤。

那是来自深海的电报。每一次轻微的拉扯，都代表着水底有游弋的生命在试探。

我屏住呼吸，两只脚像树根一样死死抓在潮湿的黑礁石上。

阳光照在平静的水面上，折射出耀眼的万千波光。

手里握着科学的法则，水下的虚实尽在心中。在这个瞬间，我不是一个仓皇逃生的遇难者，我是一个跨越了数万年时光、以天地为猎场的终极猎手。
