# 9.1 潮间带采集：贝类、螃蟹、海胆、章鱼

第十一天下午，大洋向后退出了整整一百多米。

满月的大潮把暗红色的海底礁盘彻底剥了个精光，露出一片片湿漉漉的黑色玄武岩石林。

海风里弥漫着一股浓重得化不开的咸腥味。

对于一个饥肠辘辘的人来说，这片广袤的潮间带是一座天然的露天海鲜仓库。

但在自然界里，没有哪顿大餐是不带机关的。

在这片看似平静的潮池和石缝之间，潜伏着大洋演化了上亿年的刺客。只要你的手指摸错了一块石头，或者踩错了一个水洼，死神就会在一瞬间咬住你的静脉。

我手里握着一根削尖的硬木棍，腰里别着藤条篓子，脚下踩着紧密的防刺草鞋，小心翼翼地踩进湿滑的浅水槽里。

第一样最好抓的，是那些贴在石壁上的笠螺和藤壶。

用木棍扁平的一端抵住贝壳的边缘，手掌猛地一发力。

“啪。”

强大的吸盘肌肉在瞬间被撬开，一只巴掌大、带着肥厚肉质的笠螺就滚落在了水里。

这种软体动物富含动物糖原和牛磺酸，生肉略带咸味，但嚼起来像厚实的橡皮糖一样有韧劲。

第二样，是藏在深水石凹里的紫海胆。

黑色的长刺在清澈的海水里缓慢摆动，像是一只长满了尖刺的黑色刺猬。

抓海胆不能用手抓。我用两根硬木棍像筷子一样，把它从石缝深处夹了出来，放在干燥的石头上。

海胆的尖刺带有微弱的神经毒素，被扎一下会红肿好几天。

我用一块带棱角的石头，对准海胆朝向地面的口器——也就是那圈白色质地的“亚里士多德提灯”——狠狠砸了下去。

脆硬的钙质外壳应声碎开。

倒掉里面的脏水，五瓣金黄油亮、像新鲜橘子瓣一样的海胆生殖腺，在黑色的壳内壁上闪闪发光。

我用手指挑起一瓣送进嘴里。

浓郁的油脂感和极度鲜甜的甘氨酸在舌尖上融化开来。

那是纯粹的优质蛋白质和Omega-3脂肪酸，它顺着食道滑下去，瞬间让发酸的大脑神经感到了一阵电流般的满足。

接着是章鱼。

在一处深不见底的狭窄玄武岩缝隙口，我注意到了一堆新鲜咬碎的白贝壳碎片。

那是章鱼的垃圾堆。

章鱼有极高的智商，吃完贝肉后会把碎壳堆在洞口掩人耳目。

我折下一根细长的软树枝，沾了一点带来的草木灰和高浓度苦海水，狠狠捅进了石缝的深处。

几秒钟后，石缝里泛起了一团浓黑如墨的墨汁。

紧接着，八条布满了吸盘、粗如小臂的暗红色触手，慌不择路地从石缝里倒退着爬了出来。

我眼疾手快，两只手一把钳住了它的头部肉囊。

光滑冰冷的软体肌肉在我的手臂上疯狂缠绕，几十个强力吸盘死死吸住我的皮肉，拔得皮肤生疼。

章鱼的中心有一副像鹦鹉喙一样坚硬锐利的角质齿，能轻易咬碎厚重的蟹壳。

在它回过头咬我之前，我狠狠一口咬在它两只眼睛正中央的神经中枢上。

或者，用手掌把它的整个外套膜狠狠向外翻转。

神经节被暴力破坏，刚刚还在疯狂扭动的八条触手瞬间瘫软了下来，变成了一团彻底任人宰割的软肉。

但在收获满满的时候，两道冷酷的杀人视线，就藏在我的脚踝旁。

第一道死符：织锦芋螺。

在水洼边的一块碎珊瑚堆里，躺着一只纺锤形、长约十公分的漂亮海螺。

螺壳上布满了像黄金织锦一样极其华丽、精密的三角形花纹。

那是自然界最致命的神经毒素制造者之一。

芋螺的腹部藏着一根中空的几丁质微型毒箭。

如果有人贪图漂亮伸手去捡，毒箭会在千分之一秒内像弩箭一样弹射出来，深深刺进皮肉，注入高浓度的复合芋螺毒素。

毒素会瞬间切断神经与肌肉之间的电压门控离子通道。

十五分钟之内，膈肌麻痹，全身瘫痪，人在神志极度清醒的情况下窒息而亡。现代医学至今没有解药。

第二道死符：蓝环章鱼。

在另一个清澈的浅潮池里，趴着一只只有高尔夫球大小的小章鱼。

黄褐色的体表上，正泛着一圈圈极其诡异、发出荧光电蓝色的耀眼圆环。

那是大自然的死神徽章。

它的唾液腺里分泌着高浓度的河豚毒素。哪怕只是被它不痛不痒地啄上一口，一毫克的毒素就足够在二十分钟内让一个成年人暴毙。

我用手里的长木棍，把这两只披着华美彩衣的魔鬼远远挑开，绝不让自己的皮肤靠近它们一寸。

娄子里沉甸甸的。

三只肥硕的大岩蟹、四颗海胆、一只两斤重的大章鱼，还有几十只紧实饱满的笠螺。

潮水在外礁边缘开始发出低沉的咆哮，涨潮的白线正缓缓逼近。

我提起篓子，踩着草鞋，迈开大步，踏上了回撤的高地。

海洋的餐桌丰盛得不可思议，但只有那些对毒素和陷阱怀着深沉敬畏的人，才配活着坐下来享用这顿丰盛的大餐。
