# 13.1 无锅烹饪：石煮法、竹筒煮、叶包蒸

在人类学的所有谜题里，最深刻的一道分水岭是火塘上的烹饪。

黑猩猩拥有和我们极其相似的消化系统，但它们必须每天咀嚼生肉和野果六到八个小时，把大部分血液都留给庞大肿胀的盲肠去发酵粗纤维。

只有人类，学会了用体外的热能去提前完成消化。

烹饪不是厨艺，烹饪是一场发生在餐盘之前的外源性生物化学预处理。

高温能彻底变性紧绷的三螺旋胶原蛋白，将其水解为娇嫩易溶的明胶；它能让植物细胞壁中坚硬的果胶与半纤维素融化脱水，让淀粉粒在水分子浸润下糊化膨胀，将人体对碳水与蛋白质的吸收代谢效率直接暴增三倍。

但当我蹲在自己的火山岩庇护所前时，一个赤裸裸的尴尬现实摆在眼前：

我没有一口现代的铁锅，甚至没有一个铝饭盒。

如果你以为没有金属锅具就只能啃烧焦的干肉，那是因为你低估了热力学在原始材料中的传导魔术。

没有锅，大自然到处都是锅。

第一种古老的流体热力学奇迹，叫做“石煮法”。

在我的火塘边，放着一只前几天用整段红树林枯木凿出的厚木槽，以及一只用细树皮绳紧密编织、外层涂抹了厚厚一层不溶性树脂的圆底大草篓。

这两个容器都滴水不漏，但它们都无法直接架在烈火上烧烤——木头会碳化，树脂会融化。

答案是把热源请进水里。

这叫内热式对流沸腾。

挑选石头是一场生死攸关的物理测试。

我绝不敢去海滩或溪流里捡那些被浪花常年浸泡的湿润鹅卵石。

水分子在数百万年的微观侵蚀下，早已渗入了鹅卵石内部肉眼看不见的毛细孔隙中。一旦直接丢进八百度的炭火里，封闭孔隙中的微量水分会在瞬间被加热成超临界蒸汽，体积暴增一千七百倍，岩石会像一颗高爆手片一样在火塘里轰然炸开，将锋利的碎石射入你的眼睛。

我选用的，是海蚀崖上方干燥通风处捡来的多孔玄武岩气孔石。

它们的孔隙完全开放，内部的水分早已在海风中蒸发殆尽，且玄武岩的比热容适中，热膨胀系数极低，经得起剧烈的冷热交替。

在火塘最核心的无烟白炭堆里，我埋入了六块拳头大小的玄武岩。

烧了整整一个小时，原本青黑的石头被烧得通体透红，散发着干燥而狂暴的热辐射。

木槽里已经盛满了半槽清冽的溪水，水里丢进了几大块处理干净的野鸟胸肉、切成薄片的野生葛根淀粉块，以及几把洗净的新鲜红藻。

我用两根长长的硬木火钳，从炭火深处稳稳夹出一块烧得通红发亮的玄武岩。

在半空中轻轻一抖，抖落掉表面附着的草木灰。

然后，噗通！

红石坠入冰凉水中的那一刹那，物理反应如同暴雷般炸裂。

嗤——！

一股浓烈的白色蒸汽呼啸着冲天而起，沉睡的水体瞬间爆发出剧烈的“核态沸腾”。

炽热石块表面的极高温度，在零点几秒内将周围薄层水分子瞬间气化，剧烈的气泡迅速脱离石面，带动整槽水形成剧烈的垂直湍流对流。

投入第二块、第三块。

不到两分钟，整槽原本平静的水彻底沸腾翻滚起来，咕嘟咕嘟冒出密集的白色水花。

肉块在沸水中迅速蜷缩变白，肌红蛋白与肌原纤维蛋白变性凝固，锁住了鲜美的肉汁；而野生葛根内部紧密的支链淀粉分子在九十度以上的水温中迅速吸水破裂，长链淀粉糊化，将原本清澈的溪水变成了一锅浓稠如玉、散发着微甜香气的浓汤。

石头降温后，用木钳夹出，再换入两块烧红的新石。

水沸而不熄。

石煮法让蛋白质在完全受控的温和对流中熟化，不仅绝无烤焦炭化的苦涩，更把骨髓与海藻中的矿物盐全盘逼进了浓汤之中。

喝下一口滚烫的肉汤，胃部在瞬间舒展痉挛，疲惫的细胞如同久旱逢甘霖。

第二种方法，是属于热带竹林的流体力学馈赠：“竹筒煮”。

在营地的储物架上，堆放着十几截刚砍下来的新鲜巨竹。

竹筒煮的物理玄机，隐藏在植物细胞那饱满的水分与稳态传热学之中。

新鲜的生竹，竹壁内部饱含天然水分，其自身燃点在三百摄氏度左右。

只要在竹筒内部注入水和食物，水的大比热容与蒸发相变潜热，会像一道坚不可摧的“热阱”，把竹筒内壁的温度死死压制在沸点的一百度整。

热量穿透湿润的竹纤维，持续传导进水里，而竹筒外壁哪怕被烈火烧得漆黑，只要内壁不烧穿、水分不干涸，竹筒就绝不会起火解体。

我挑选了一节直径足有十五厘米的新鲜生竹筒，保留底部的竹节，顶端削平。

把几条新鲜的小海鱼剖洗干净，塞进竹筒底部，中间层层叠放切块的面包果和新鲜姜叶，加入适量的清水，水面距离筒口留出五厘米的气室空间。

最后，用一团洗净的野芭蕉嫩叶将竹筒口轻轻塞住。

架设的方式极其讲究。

绝不能将竹筒垂直蹲在火焰正中央，那会烧裂底部的竹节。

必须倾斜四十五度。

我在火塘外围插了两根带叉的木桩，把竹筒斜斜地架在离炭火十厘米的高度上，让火苗只舔舐竹筒的中下部侧壁。

倾斜的竹筒让内部液体形成了自然的单向回流回路，受热的开水沿上壁上升，冷却的液体沿下壁下沉，形成高效的热循环；

同时，顶部塞着的叶片形成了一个微弱的自卸式减压阀，既不让蒸汽过度蓄积引发炸裂，又牢牢锁住了竹纤维受热析出的微量竹香香兰素与微量硅酸多糖。

四十分钟后，竹筒口开始噗噗地喷出一道道浓郁的乳白色蒸汽。

筒壁被烤得焦黑流油，但在芭蕉叶塞拔出的那一刻，一股混杂着竹子清甜与鲜鱼醇香的热浪扑面而来。

鱼肉已经脱骨软烂，鱼油与面包果的淀粉完美乳化成了一层奶白色的胶质，没有一滴汤汁洒漏，更没有任何草木灰的污染。

最后一种无锅烹饪，是人类征服重型肉类的终极核武器：“叶包蒸地坑炉”。

这在波利尼西亚群岛被称为“伊木”（Imu），在毛利人那里被称为“杭吉”（Hāngī）。

当你打到了一整只体型庞大的野山兽，或者收获了几十斤沉重的野生块茎时，任何石煮或竹筒都显得杯水车薪。

你需要的是一台地热蒸汽高压锅。

正午时分，我在干燥的高地上挖出了一个深半米、直径一米的圆形大土坑。

在坑底铺满干燥的粗硬木柴，上面密密麻麻码放了足足上百斤坚硬的玄武岩气孔石块。

引燃大火。

剧烈的大火在坑中整整燃烧了两个小时，直到所有的木柴全部化作炽热的白炭，而上方的上百块玄武岩被烧得通红耀眼，积蓄了数万大卡的热焓。

我用长木棍迅速拨平坑底的炭石，先在红石上覆盖一层厚达十厘米的新鲜芭蕉叶和多汁的野生杂草。

轰！

湿草与红石接触的一瞬间，白色的蒸汽像火山喷发一样爆发出来，青草不仅隔绝了肉类直接触石碳化的风险，更提供了取之不尽的纯净水蒸汽。

我迅速把处理好的大块猎物肉和整个的大芋头，用厚厚的野芭蕉叶层层包裹，用细藤条捆扎成一只只严丝合缝的“绿包袱”，整齐地码放在湿草层上方。

紧接着，在绿包袱上方再盖上更厚的一层湿芭蕉叶、几张湿透的棕榈编织席。

最后一步，是力挽狂澜的封土。

我抄起木铲，用最快的速度将挖出来的湿润泥土重新推回坑里，层层夯实，彻底封死坑口。

一丝蒸汽都不能漏出来。

这是一个密封的绝热恒温腔体。

泥土隔绝了所有的空气对流与热辐射外散，将巨大的热量牢牢封死在地下。

内部的物理状态是一场精密的水汽循环：

底部的红石将湿草的水分持续蒸发为一百多度的过热蒸汽；

高压蒸汽在密闭的地坑内循环穿透叶片，将肉类深层的粗硬结缔组织水解；

蒸汽上升触及冷土顶壁凝结成水滴，重新滴落回红石上，再度化为蒸汽。

长达五个小时的恒温慢蒸。

没有明火的焦灼，没有高温热解的致癌烟雾。

当夜幕笼罩整座荒岛时，我用木铲小心翼翼地刨开干燥焦黄的顶层封土，掀掉滚烫发黑的棕榈席。

一股混合着泥土芬芳、芭蕉叶多酚与浓烈熟肉油脂的蒸汽，在夜空中如蘑菇云般盛开。

剥开焦黄的芭蕉叶包裹。

原本韧如皮革的粗壮兽肉，此刻已经酥烂到了极致，轻轻用手一撕，肌肉纤维便顺着肌理自然分崩离析；骨髓化成了晶莹的油冻，连最粗粝难嚼的芋头块茎，也彻底转化成了软糯甜润的凝胶态。

双手捧着滚烫的叶包，油脂顺着指缝滑落。

在没有一口铁锅的原始荒野上，依靠岩石的比热、竹筒的热阱与大地的绝热循环，我重新登上了食物链的顶峰。

火降服了石头，石头降服了水，而水与蒸汽，最终驯服了这片蛮荒大地上所有顽固的生命。

我咽下一大口酥烂温热的熟肉，疲惫的肠胃开始平稳而高效地汲取生命的燃料。

文明，在这一刻于舌尖彻底苏醒。
