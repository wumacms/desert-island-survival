# 1.1 从水中上岸：离岸流、礁石与溺水自救

要弄明白我为什么会一身是伤地躺在这片滩头上，得回到上岸前半个小时的那片深水里。

在真正踩上干沙之前，大海在大浪里追了我整整两海里。

那时候我整个人浮在浪峰上，四周全是白花花的碎沫。视线里，那道黑色的海岛断崖就在眼前，大概只有三百米远，但无论我怎么拼命划水，岸上的树林非但没有变大，反而在离我越来越远。

有一股看不见的力量在拽着我的脚踝，把它往浩瀚的大洋深处拖。

那是离岸流。海难发生时，九成淹死在岸边的人，都是被这玩意儿要了命的。

海浪一波波涌向岸边，撞在珊瑚礁上，大量的水堆积在浅滩里，它们必须找个低洼的缺口退回深海。这就形成了一条狭窄、浑浊、流速极快的水道。它像是一根开足了马力的抽水管道，流速能达到每秒两米甚至三米。

人类最顶尖的游泳冠军，在静水里冲刺的速度也不过每秒两米。

“别跟它顶着干，蠢货。”在海水漫过嘴巴的瞬间，我在心里狠狠骂了自己一句。

最致命的错误，就是慌慌张张地迎着水流朝岸上游。在每秒两米半的对冲流里，即使你拼出吃奶的劲，也不过是在原地踏步。五分钟，只需要五分钟，你体内的肌糖原就会彻底耗干，乳酸堆满大腿，然后你就会在绝望中呛水、沉底。

水流在流体力学面前是讲规矩的。离岸流虽然猛，但它的宽度通常只有十几米到几十米。

我停止了朝向陆地的划水，把下巴微微扬起，让口鼻露出水面，顺着海浪的起伏轻轻踩水。

“往旁边游，往两侧游。”我想。

我转过身子，沿着与海岸线平行的方向，横着切向水流的边缘。我不去跟那股拖拽的巨力对抗，只是用均匀、缓慢的蛙泳动作，一下，一下，往侧向平移。

划了大概三十几下，身边的海水突然变了。原本浑浊、打着旋儿的白沫不见了，冰冷向外的吸力猛地一松。

我知道，我切出了水流的漏斗口。

但真正的要命关口还在后头。

横在我和沙滩之间的，是一道森白的暗礁。那是千百年来珊瑚虫骨骼堆积起来的石壁，边缘像碎玻璃一样锋利。深海的大涌浪撞在浅礁上，浪高瞬间被压缩抬升，两米多高的巨浪卷着白色水墙，轰隆一声砸向礁盘。

要是被这样的巨浪直接拍在礁石上，骨头会被当场砸断。

我吸饱了一大口气，把两条腿完全收拢、放平，像一截漂木一样浮在水面上。

“别把脚垂下去。”我警告自己。在浅水珊瑚区垂下双腿，锋利的鹿角珊瑚会像屠刀一样切断你的脚掌和脚筋。

一个巨大的涌浪从我身后隆起。水面像升降机一样把我托到了两米多高的半空中。

就是现在。

在浪头还没有彻底翻滚卷碎的一瞬间，我顺着水势拼尽全力往前冲刺了两下，让自己骑在浪涌的后背上。随着巨浪轰然崩塌，狂暴的白水把我向前狠狠推了出去。

哗啦！

礁石的尖齿刮到了我的膝盖和手背，皮肉被划开，一阵火辣辣的刺痛。但巨浪的冲力带着我滑过了那道最浅的刀山，把我重重地掼在了礁石后面的浅水滩上。

我趴在水里，双手死命抠住地下的粗砂。

退潮的拉力试图把我重新拽回去，但我像一只钉在水底的鲎一样，指甲深深抠进沙砾，死活不肯松开。

等那股回卷的浪退干净，我才连滚带爬地往前挪了三四米，最后脱力地倒在了被海水打湿的黑色沙地上。

肺里全是苦咸的泡沫，胸口剧烈地起伏着。

我活下来了。不是靠运气，而是靠着尊重水流的规矩。大洋可以轻易捏碎任何狂妄的挣扎，但只要你顺着它的力道走，它就会留下一个活命的缝隙。

我低头看了看淌着血的膝盖。伤口很深，混着黑砂，但是骨头没断。

这第一回合，是我赢了。
