# 1.2 上岸后的第一件事：清点身上所有物品

脱离了险境之后，人不能坐着发呆。

我靠在背风的大漂木旁，把湿透的裤脚往上卷了卷，然后把身上所有的口袋挨个翻了个底朝天。

在文明社会里，一件东西通常只有一个用处：钥匙用来开门，手表用来看时间，手机用来跟远方的人说话。但在荒岛上，你必须忘掉这些名字。你得把它们还原成铜、铁、玻璃、高分子纤维和硅片。

每一件现代工业的产物，无论破损成什么样，都是从文明世界里带出来的贵重遗产。

我把掏出来的东西，一件一件排在漂木平整干燥的树干上。

第一样，是那部报废的手机。

屏幕已经碎了，里面满是黄色的海水。它再也打不通任何电话，但它依然是一座微型的资源宝库。

只要小心地剥开外壳，里面的锂电池在干燥后可以通过短路或者受控刺穿释放化学能，产生高达几百摄氏度的高温火星；手机摄像头的微型凹凸镜片可以用作微距聚光；碎裂的强化玻璃边缘，比任何没有打磨过的石器都要锋利，能像手术刀一样切割藤条和兽皮；而扬声器后面的微型强磁铁，拔下来悬挂在水面上，就是现成的指南针。

“别急着拆它，”我看着这块黑塑料，“等到要生火或者需要刀刃的时候，你才是主角。”

第二样，是一串钥匙。

不锈钢钥匙圈上挂着三把门钥匙，还有一个不起眼的黄铜指甲刀。

指甲刀是纯钢造的，口子很硬，可以用来修剪坚韧的植物纤维，甚至当刮刀用。那三把钢钥匙，在玄武岩上反复摩擦可以打磨成小巧的雕刻刀和锥子；而把钥匙在坚硬的含硅石英石上快速撞击，坚硬的钢质能剥落微小的金属碎屑，在空气中氧化燃烧成火星——那是救命的火种工具。

第三样，是手腕上那块碎了的手表。

不锈钢后盖被我用指甲刀的挫条小心翼翼地撬了下来。后盖很亮，凹面打磨得像一面小镜子，只要角度合适，它能把刺眼的日光反射到十几海里外的海面上，充当求救的反光信标。

表壳里拆下来的发条是一根极好的高碳钢细丝，弹性十足，磨尖了就是一根鱼钩。

第四样，是裤腰上的皮带。

纯牛皮的带子，长一米二，宽三厘米。牛皮是极好的耐磨耗材料，可以用来磨刀，撕成细条就是坚韧的皮绳；而那个沉甸甸的锌合金皮带扣，边缘有直角，重量将近二两，绑在粗木棍上就是一柄趁手的敲砸石核的小手锤。

最后是身上的衣服。

鞋带是尼龙编织的，每一根都有一米长，拉力超过五十公斤。这是荒岛上最稀缺的成品绳索，在学会用树皮搓绳之前，这两根鞋带必须当成黄金一样省着用。

纯棉混纺的衬衫，下摆已经被我撕掉了一条包扎伤口。剩下的部分，在干燥之后可以撕成细细的棉绒纤维，那是最好的引火绒。

东西不多。全加在一起，装不满一个塑料袋。

但我看着漂木上排开的这一小堆杂物，心里踏实了许多。

“瞧瞧吧，老伙计，”我对自己的影子说，“我们不是赤手空拳来的。”

工业文明用了几千年才把铁矿石变成钢，把石油变成尼龙，把沙子炼成硅片。这些人类智慧的结晶现在就躺在我的手心里。它们不会说话，但只要你懂得它们的硬度、熔点和韧性，它们就能变成你的牙齿、爪子和铠甲。

我把钥匙和指甲刀贴身放好，把破手表和手机用干燥的阔叶裹紧，扎进裤腰深处。

清点完毕。接下来，该抬头看一看这座困住我的陆地到底长什么模样了。
