# 1.3 快速评估岛屿：面积、地形、淡水迹象、植被类型

我收好身上的零碎，手脚并用，爬上了沙滩后方一座凸起的玄武岩高台。

高台大概有四五米高，石头是黑色的，被风雨剥蚀出一道道纵向的裂槽。爬上去有些费劲，膝盖上的伤口碰到粗粝的石面，钻心地疼。但我必须站高一点。

一只被关在黑屋子里的老鼠，是活不长的。在荒野里，瞎子死得最快。

我直起腰，迎着略带咸味的海风，眯起眼睛把目光投向这片未知的陆地。

第一眼看的是地貌。

这是一座高岛。正中央耸立着一座像折断的兽齿一样陡峭的山峰，黑沉沉的山脊直插云霄。从岩石断面那种刀劈斧削般的柱状节理来看，这是一座死火山，而且喷发年代不会超过几万年。

火山岛对遇难者来说是个好消息，也是个坏消息。

好消息是，火山灰风化形成的土壤极其肥沃，植被茂密，能养活大量的鸟类、昆虫和小兽；坏消息是，这种地貌没有平缓的过渡，到处是深不见底的断崖和滑坡，一旦盲目钻进去，摔断脖子的概率比找到路高得多。

第二眼看的是面积。

海面在远处弯曲成一道弧线。我的眼睛距离海平面大约有七八米，地平线的视距顶多五六公里。我顺着两侧的海岸线看过去，两边的黑色沙滩在往内陆快速收拢、弯折。

“不是大岛，”我在心里盘算着，“周长大概在十到十五海里之间。总面积撑死了也就二十来平方公里。”

二十平方公里，这意味着它足够大，能留存雨水，形成独立的生态圈；但也足够小，只要顺着海岸线走，两三天就能把整座岛的外轮廓摸清楚。它不是那种能走上一个月都见不到海的大陆板块。

第三眼，也是最要紧的一眼，是看水。

没有淡水，前面所有的计算都是废纸。

我把目光从黑色的沙滩移开，投向中央那座黑沉沉的火山峰。在山顶大约三分之二的高度上，挂着一团像破棉絮一样的白云。

天很蓝，四周的海面上连一丝云彩都没有，唯独那座山峰顶部顶着一顶云帽子。

那是地形雨。海洋吹来的暖湿气流遇到高耸的玄武岩山体，被强行抬升、冷却，水蒸气在山头凝结成云。那团云在那里，就意味着山顶的玄武岩上每天都在落雨。

我把目光顺着山势往下移，寻找山体凹陷下去的深槽和冲沟。

在两个山脊夹紧的一条深谷里，树木的颜色明显变了。海滩边缘全都是灰扑扑的马鞍藤和耐盐的露兜树，叶子硬得像铁片。但那条深谷里，呈现出一种极其鲜嫩、近乎透明的翠绿色。那里长满了高大的野生芭蕉和阔叶树蕨。

只有在常年有流动淡水冲刷的地方，植物才敢长出那样娇嫩肥大的阔叶。

山谷上方，偶尔有几只灰白色的小海燕低低地掠过树梢，在谷口盘旋。淡水就在那条沟里。哪怕现在是旱季，在那片浓密的翡翠色深处，也一定有从岩缝里渗出来的泉水，或者积在石臼里的死水潭。

水是有的。只要顺着那条沟走，死神就掐不死我。

但是山谷距离我现在的滩头至少有一点五公里，而且必须穿过一片带刺的灌木密林。在太阳落山前的这一个多小时里，我不可能摸进去再活着摸出来。

“别急，林深，”我蹲下身，手掌贴在被太阳烤得温热的黑岩石上，“它在那里跑不了。明天一早，我们去把它取出来。”

地形摸清了，水源的位置心里有了底，岛屿的脾气我也大致摸到了脉搏。

太阳已经开始贴近海平面的边缘，天色变得一片金红。

风开始变冷了。我必须赶在白昼彻底熄灭之前，在这座高台的背风处，给自己搭起第一张挡风的床。
