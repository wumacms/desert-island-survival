# 1.4 建立临时避险点：不要在潮线附近过夜

太阳碰到了海平面。

那轮巨大的火球把半边天空烧成了紫红色，海浪像是涂了一层发亮的铅油。四周安静得可怕，只剩下一声声沉重的浪涛拍打声。

许多筋疲力尽的遇难者，在上岸后的第一个晚上，都会贪图省力，直接倒在柔软的平整沙滩上睡死过去。

那是死路一条。

沙滩是骗人的。白天的潮水退了，不代表夜里的潮水不会涨回来。在满月或者新月的时候，引潮力叠加，半夜的大潮位会比白天高出一米甚至两米。只要来一阵偏向岸边的狂风，涌浪就能像扫帚一样，把沙滩上几十米范围内的东西全部扫进大洋。

在睡梦中被海浪卷走，或者被冰冷的海水呛醒，你在黑暗中连方向都分不清。

更何况，湿沙子是热量的窃贼。沙粒之间的水分子连成一片，比热容极大，导热极快。直接睡在沙滩上，就像整夜躺在一块巨大的湿铁板上，它会像水蛭吸血一样，把你后背的体温彻底抽干。

我顺着玄武岩台地往下退，退到了距离最高潮线大约六米远的一处浅凹岩壁下。

这里的地面是干硬的碎石和风化土，岩壁高高耸立，正好替我挡住了从东南方向吹来的穿堂海风。头顶上方有一道微微突出的岩檐，就算夜里下点零星小雨，也能勉强遮一遮。

“先铺床，再挡风。”我对自己的胳膊说。

很多没有经验的人搭窝，总是先忙着搭个华而不实的屋顶。那是本末倒置。在热力学面前，空气对流带走的热量，远远比不上背部与地面传导带走的热量多。

地面才是最致命的散热孔。

我钻进林缘的枯木丛里，挑那些被太阳晒得干透了的落叶和干树枝。

露兜树枯死的叶子很长、很硬，两边长满了细小的倒刺。我的手指被扎破了好几处，血珠渗出来，在干土上滚成小泥丸。但我没有停。我一把一把地抱，把那些干叶子、干草，还有被海风吹干的马尾藻，死命往岩壁下的凹坑里填。

厚度不够，等于没铺。我足足铺了有半米厚，然后整个人压上去，用膝盖使劲把它踩瓷实。

踩实后的垫子大概还有二十公分厚。里面被挤压成无数层微小的死空气囊。干燥的静止空气是自然界里最便宜也最好的绝热材料，只要这层干垫子在，冰冷的地面就够不着我的骨头。

做完垫子，天色已经完全暗下来了，最后一点晚霞变成了灰蓝色。

我从高潮线拖过来三根两米来长的枯树干。一根横着架在岩石缝隙里，两根斜斜地支撑在地面上，搭成一个倾斜四十五度的最简单架子。

接着，我摸着黑，把几根带大叶片的棕榈枯枝斜靠在木架上，叶柄朝上，叶片朝下，一片叠着一片，像鱼鳞一样压死。

一个单坡的防风窝棚就成了。它很矮，甚至称不上是一座房子。人钻进去只能半躺着，连腰都直不起来。

但这足够了。

低矮的空间意味着较小的表面积，能最大限度地减少体温向周围冷空气的辐射；倾斜的叶片能把夜风顺着坡面引向天空，不让它直接刮到我的头脸上。

我手脚并用，像一只归巢的土拨鼠一样，慢慢退进了这个低矮狭窄的窝棚里。

躺上厚厚的落叶垫时，那种被干燥托住的感觉，让酸痛已久的脊椎长长地松了一口气。海风在棚子外面呼呼地刮着，棕榈叶在头顶噼啪作响，但窝棚里那一小团空气，很快就被我的体温焐得有了些许暖意。

黑暗彻底笼罩了整座荒岛。

我看着棚子外面那片闪烁着微弱冷光的漆黑大洋，肚子里依旧在隐隐作痛，口舌干得发苦。

但今晚，我有了自己的立足之地。失温这把刀子，暂时被我挡在这一堆干树叶外面了。
