# 6.4 屋顶防水：编织棕榈叶、树皮、苔藓

骨架搭得再结实，如果屋顶漏水，它依然只是一座漏雨的牢笼。

在热带，一场暴风雨能在半个小时之内往每平方米的地面倾倒上百升水。

只要屋顶漏下一道细流，你的干草垫就会在一夜之间变成冰冷的烂泥浆。失温会在天亮前找上门来，你辛辛苦苦收集的干引火绒会被泡烂，而潮湿的木头会在几天之内长满白色的霉菌。

屋顶不是塑料布，它防雨的秘密，不在于“滴水不漏”，而在于“引水归槽”。

在流体力学里，植物叶片搭建的屋顶靠的是重力引流速度与毛细渗透速度的赛跑。

雨水落在倾斜的叶片上，必须在它顺着缝隙慢慢渗进屋里之前，借着重力顺畅地滚出房檐。

要让重力跑赢毛细渗透，第一条法则就是坡度。

屋顶的倾角绝不能低于四十五度，最好能达到五十到五十五度。太缓的坡度会让水流速度放慢，水分子之间的表面张力会把雨水强行吸进两片叶子交叠的夹缝里，形成倒灌。

我拖来了上百根两米多长的野生野棕榈叶和厚实的露兜树叶。

直接把整根树叶往屋顶上扔，是外行才会犯的低级错误。整根叶子的叶轴太硬、太厚，叶片杂乱无章，风一吹就会露出巨大的空洞。

我坐在石头上，用锋利的黑曜石刀片，把每一根棕榈叶粗壮的叶轴，顺着中线一劈两半。

厚重的叶轴被削平了，剩下了一排排排列整齐、柔软的叶片。

我把同一侧的叶片，以两片为一组，斜斜地交叉编织在一起。原本杂乱飘散的细叶，被编成了一块块紧密、平整、像草席一样厚实的硬质“瓦排”。

铺设的顺序，是一条绝对不可逆的铁律：

必须从最底下的房檐开始，自下而上，一层压一层。

如果从上面往下铺，上层叶子的接缝就会暴露在下层叶子的下方，流淌的雨水会像走楼梯一样，一阶一阶全灌进屋里。

我先把第一排编织好的叶瓦，用细藤条牢牢绑在最底层的肋木上。

叶柄朝上，叶尖朝下，齐刷刷地伸出房檐二十公分，保证水滴落下时能远离地基。

然后是第二排。

第二排的叶尖，狠狠向下延伸，足足压住了第一排叶瓦的三分之二。

每一块叶瓦，只露出下边缘三分之一的长度。

层层叠叠，整整铺了七层。

雨水打在最上层，只能顺着叶片的倾斜纹路滑到叶尖；从叶尖滴落，正好砸在下一层叶瓦光滑的背面上；顺流而下，一直被导引出房檐外，落进岩石台地边缘预先挖好的排水沟里。

在两片屋顶交汇的最顶端，是整个屋顶最脆弱的命门：屋脊。

两条斜线在脊梁上切出的缝隙，任何编织叶片都压不住。

我从一棵倒毙的大纸皮树干上，完整剥下了几大块一米长、半米宽的厚树皮。

这些树皮富有油脂，防水性能极好。

我把厚树皮像马鞍一样，对折倒扣在主脊梁的最上方，严严实实地卡死了所有的接缝。

然后，我抱来了大团大团吸水膨胀的厚山苔藓，塞在树皮与石头缝隙的所有细小空角里，最后压上两根沉甸甸的死硬木和一排平整的大石头，防止强风把屋脊吹掀。

屋顶盖好了。

从外面看，整座A字棚像是一只披着厚厚绿色鳞甲的远古穿山甲。

倾角陡峭，鳞甲致密，屋脊稳固。

我弯着腰，钻进了这个刚刚完工的小庇护所。

里面很黑，也很安静。外面的白昼被完全隔绝在厚厚的棕榈叶外，鼻尖闻到的只有新鲜树叶和干燥木头的清香。

头顶上方，没有透进一丝光线。

在光学上能够完全阻挡光线透入的厚度，在流体力学上，就足以让自然界最暴虐的暴雨望洋兴叹。

我躺在刚架好的竹排床上，看着这片完全由自己双手编织出来的屋顶。

从今夜起，天上的雨水不管有多大，它都只能乖乖顺着我的屋檐滑落进水沟。

人类在这座蛮荒的海岛上，终于拥有了一片真正干燥的天空。
