# 6.1 选址科学：避风、避潮、避落石、近水源

第五天的早晨，暴风雨终于彻底过去了。

天空中被洗得瓦蓝瓦蓝，大洋上的白沫慢慢退去。

那座在大漂木旁边凑合了四天的简易单坡棚子，在一夜的狂风暴风里被撕扯得七零八落。棕榈叶被吹走了大半，湿漉漉的地面一片泥泞。

在最初的七十二小时里，一个能缩进去的狗窝就足够保命；但如果你想在这座岛上长久地活下去，你就必须为自己营建一个真正的基地。

建造基地，百分之八十的成败，在插下第一根木桩之前就已经注定了。

选址是一场严格的地质学与生态学推演。

在荒野里，选错地方，大自然有一百种办法在半夜里要了你的命。

我沿着海岸线和林缘线慢慢走着，脚下的硬底靴子在泥泞里踩出一个个坚实的脚印。

第一条铁律：绝对不把窝搭在干涸的冲沟和河道里。

很多缺乏常识的人，最喜欢在山谷底下干涸平整的沙石滩上扎营。那里地势平坦，两边有树荫，取水也近。

那是自寻死路。

热带海岛的山体极其陡峭，一旦深山里遭遇暴雨，几百万吨的雨水会在半小时内顺着山脊汇成狂暴的山洪和泥石流。那种山洪甚至不需要本地下雨，几海里外的山头下雨，洪峰就会像一堵两米高的黄泥墙一样，在睡梦中把营地连人带木头一起拍进大海。

第二条铁律：抬头看头顶，避开“寡妇制造者”。

在林子里扎营，很多人只顾低头看地面平不平，从不抬头看天。

在那些看似高大茂密的树冠顶上，往往挂着被狂风折断、却被藤蔓挂住的巨大死树枝。在林业术语里，它们叫“寡妇制造者”。

一根碗口粗的死树干，只要一陈微风吹断藤条，从十五米的高空垂直砸下来，动能足够砸烂任何人的头盖骨。

还有那些挂满重达两三公斤大椰子的老椰子树。成熟的椰子脱落，重力加速度带来的冲击力，相当于一颗从楼顶扔下来的保龄球。

第三条铁律：避开迎风坡的潮气与落石。

大海的方向是东南方，暴烈的海风常年从那边刮过来。直接暴露在迎风坡，空气里的高浓度盐雾会在几天内腐蚀掉所有的工具，让衣服永远带着黏糊糊的湿气。

同时，悬崖正下方的乱石滩绝对不能去。玄武岩在热带烈日的暴晒和夜间的骤冷下，剧烈的热胀冷缩会在垂直节理里产生极大的温差应力。热胀冷缩会让岩石风化崩塌，一块滚落的石头就能砸塌整个窝棚。

第四条：靠近水源，但绝不能贴着水边。

离接触泉太远，每天运水会累死人；但如果直接在泉水旁边扎营，死水潭边滋生的成千上万只按蚊，会在三天内把疟疾和登革热种进你的血液里，林子深处的野兽夜间出来饮水，更会把你当成挡路的障碍。

我停下了脚步。

在距离海滩大约一百五十米的一处山脚转弯处，地势突然抬升起一个平整的高台。

这是一个由远古熔岩流冷却形成的坚硬玄武岩天然阶地，海拔高出海平面八米。

台地的背后，是一道弧形的背风山梁，严严实实地挡住了从东南方吹来的穿堂海风；

头顶没有任何悬空的死树和椰子树，只有几株矮壮结实的野生灌木；

平整的石台距离山谷里的清泉大约有一百二十米，既能在一两分钟内走过去打水，又完全远离了谷底潮湿的蚊虫与山洪通道。

脚下的地面是平整坚硬的岩石，雨水落在上面会顺着石坡迅速排向低处，永远不会积水内涝。

“就是这里了。”我用手里的木棍重重顿在冰冷坚硬的石台上。

地基坚硬，背风向阳，居高临下，进退自如。

大自然没有造出一间现成的木屋，但它在这里留下了一张坚固的底座。

我扔下手里的木棍，挽起袖子。从今天开始，我要在这片黑色的岩石台地上，用双手为自己凿出一个真正的家。
