# 6.3 利用天然地形：岩洞、树根、倒木

在荒野里，一个聪明人永远不会赤手空拳去跟整座大自然对抗。

砍倒一棵碗口粗的活硬木，用石头斧头要敲上整整一个小时。手掌会磨烂，肌腱会发炎，体内的热量会像自来水一样哗哗流淌。

大自然在几千年、几万年的时间里，早就用风、水和树根在地表上雕刻出了无数现成的避难所。

善于利用这些天然的结构，能替你省下百分之八十的力气。

但我并没有直接住进附近最深的一个熔岩暗洞里。

很多没有任何野外经验的人，看到悬崖底下有个黑黝黝的天然深洞，会欣喜若狂地钻进去睡觉。

那是常常把活人变成尸体的黑陷阱。

火山岩的深洞里，往往隐藏着看不见的致命杀机。

第一种杀机是气体。

火山虽然休眠了，但深层地壳的缝隙依然在缓慢释放二氧化碳和硫化氢。二氧化碳的比重比空气大一点五倍，在没有空气对流的深坑死角里，无色无味的二氧化碳会像水一样沉淀在洞底。

你只要躺下去睡觉，头部进入那层看不见的沉积层，几分钟内就会在无声无息中窒息而死。

在进任何一个深洞之前，必须把一根点着明火的火把，死死压在离地十公分的最低处。

只要火苗变暗、发红，或者扑的一声熄灭了，哪怕外面下着冰雹，也绝不能迈进去一步。

更不用说洞穴深处的蝙蝠粪便里滋生的组织胞浆菌孢子，只要吸进肺里，就会引发致命的真菌性肺炎。

真正的天然礼物，在半明半暗的开阔地带。

在距离我的高台只有三十米的一处缓坡上，生长着一株巨大的野生热带高山榕。

那是一棵真正的巨兽。为了在浅薄多石的火山土壤里站稳脚跟，它的树干底部向外伸展出四片巨大的“板状根”。

那些板根每一片都有一米八高、十公分厚，笔直、坚硬地插进岩石缝隙里，像是一面面用实木打造的防爆盾牌。

两片板根之间形成了一个天然的一百二十度夹角。

如果有人想在森林里躲避风雨，根本不需要砍伐立柱。只需要在这两片巨大的木质屏风之间横搭几根树枝，铺上叶子，一座天然带有两面实木承重墙的坚固小木屋就成了。

而在我脚下的玄武岩高台上，大自然给我的赠礼是一道凹陷的天然岩石绝壁。

这道石壁有两米半高，微微向前倾斜，表面干燥得没有一丝苔藓。

它是一面纯天然的防风墙，坚硬得连炸药都炸不穿。

我没有把我的A字棚孤零零立在平地中央。

我把整个A字棚的后半截，直接嵌进了这道坚硬的玄武岩凹壁里。

石壁直接充当了营地的后背墙和屋顶的支点。

玄武岩巨大的热惰性，会在白天吸收太阳的余热，在冰冷的后半夜把温和的热量缓缓释放出来；而无论从哪个方向刮来的横风，遇到这道死硬的岩壁，都会被强制分流引向两侧。

借力打力。

人类永远不可能比高山更坚硬，也不可能比巨木更有力气。

但人类有眼睛，有脑子。只要懂得向大地借一面墙，向岩石借一个角，我们就能在最险恶的蛮荒中，用最少的力气，给自己撑起一片风雨不透的安全天地。
