# 8.3 根茎、果实、叶片的处理与烹饪

在自然界里，“能吃”和“直接吃”之间，隔着一条巨大的鸿沟。

大自然没有为人类量身定做任何一块免洗牛排。

哪怕是被证实无毒的野生植物，它们的细胞里也塞满了草酸钙晶体、水溶性单宁、植酸以及结晶硬淀粉。

如果直接拿来生嚼硬咽，轻则喉咙肿胀窒息，重则剧烈呕吐、肠胃出血。

烹饪不是文明人的虚荣，烹饪是人类用火与水进行的一场深度生物化学脱毒。

在营地的门廊前，我把挖回来的两根粗壮的野生山芋放在平整石板上。

这种野芋头长在山溪旁，根部沉甸甸的，富含极其饱满的碳水化合物。

但它的肉质里，藏着致命的微观暗器：草酸钙针晶。

野芋头的细胞里布满了细长如针的草酸钙晶体，两端带有倒刺，外面包裹着一层微薄的蛋白质鞘。

只要有人忍不住生咬上一口，几千万根微米级的毒针就会在咀嚼的瞬间喷射出来，深深刺进舌头、口腔黏膜和声带组织。

剧烈的灼痛会在几秒钟内爆发，咽喉黏膜会像充气气球一样疯狂水肿。在荒岛上，这种急性喉头水肿能在半小时内完全封死气管，把人活活憋死。

对付草酸钙，物理切削是没用的，必须动用热力学降解。

我戴着用树皮垫着的手套，用黑曜石刀刃把野芋头黑褐色的厚外皮剥得干干净净。

剥下来的皮直接扔进火塘深处烧掉。

我把白嫩的芋头切成薄薄的硬圆片，整齐地码进一节盛满清水的粗竹筒里。

在水里，我顺手扔进了一小捏极细的雪白草木灰。

草木灰里的弱碱性碳酸钾，能中和部分酸性物质，加速外层蛋白鞘的分解。

我把竹筒架在通红的炭火上，保持大火连续滚沸。

水温升到一百度。

持续的高温热力，像一把微观锤子，把包裹在针晶外面的蛋白质彻底破坏、变性。在长达四十五分钟的剧烈翻滚中，微小的草酸钙晶体在热水中崩解、溶解。

同时，生淀粉的致密结晶结构被滚烫的水分子强行冲开。

原本无法被人体消化的生淀粉颗粒，吸水膨胀、破裂，发生了不可逆的淀粉糊化反应。

白色的硬块在沸水里慢慢软化，最后变成了一锅浓稠、细腻、散发着清香的热芋泥。

我用削尖的竹筷挑起一小团芋泥，放进嘴里。

没有一丝针刺感，舌头没有发麻，口感软糯滑润，像一勺温热的甜奶油。

除了根茎，采来的野生木薯需要用流水浸漂。

木薯的细胞里含有亚麻苦苷。只要把木薯捣碎成泥，细胞破裂，自带的内源酶就会把它分解成剧毒的游离氢氰酸。

但氢氰酸的沸点只有二十六度，而且极易溶于水。

把捣碎的木薯泥装进透气的草包里，浸在奔流的小溪里冲刷整整一个晚上。流淌的活水会像洗衣服一样，把所有的水溶性氰化物全部冲进大洋。

第二天捞出来挤干水分，放在火塘上的热石板上一烤，毒气随热气挥发殆尽，剩下的就是雪白干香的木薯烘饼。

而在处理那些略带苦涩的野蕨菜嫩芽和深海石莼时，原理同样简单。

扔进滚水里焯水两分钟，倒掉第一道发绿发苦的苦水。

水分子带走了易溶于热水的苦涩单宁和游离草酸，保留下来的，是完好无损的植物纤维、维生素和叶绿素。

石锅里的芋泥在咕嘟咕嘟地冒着热气。

我端起温热的竹筒，用竹片舀着细腻的糊糊，一口一口送进胃里。

没有中毒，没有腹泻，温热的糖分被肠道平稳吸收，化作流淌在四肢百骸里的真实力气。

荒野是粗野的，它把宝贵的能量深锁在毒素和硬壳里；

但科学是冷静的。只要懂得相变、水解与热力变性的规矩，再凶险的植物，也只能乖乖卸下全部武装，化作滋养生命的温顺甘霖。
