# 8.4 有毒植物警示：哪些绝对不能碰

大自然最狠毒的陷阱，往往裹着最诱人的外衣。

在饥饿折磨着胃肠的时候，人的瞳孔会对任何圆润、饱满、色彩艳丽的东西产生贪婪的渴望。

但在这座热带海岛上，有些果实只要你咬破半口，就再也没有看明天日出的机会了。

它们不是食物，它们是进化史里最纯粹的生化毒剂。

走在海滩与林缘的交界处，我手里拿着一根结实的木棍，目光像鹰一样警惕地扫视着周围的灌木丛。

第一号绝对禁区：海杧果。

在海滩礁石上方大约十米的地方，生长着一株极为漂亮的常绿小乔木。

绿油油的叶子肥厚而油亮，枝头开着洁白的五瓣小花，花心带着一抹娇嫩的淡红色。在枝桠之间，挂着几颗拳头大小、表皮光滑、散发着淡淡清香的绿色果实。

它们长得太像文明社会里甘甜多汁的水果芒果了。

那是自杀之树。

海杧果的果肉和果仁里，含有一种极其致命的强心苷类毒素：海杧果毒素。

只要吃下半颗果仁，毒素分子就会在几分钟内强行锁死心肌细胞膜上的钠钾ATP酶泵。

心肌细胞内部的离子平衡在一瞬间彻底崩塌。心脏先是剧烈狂跳，随后心率骤降到每分钟三十次以下，传导阻滞，室颤，最后在极度的窒息和抽搐中彻底停摆。

现代急救中心面对这种毒素都束手无策，在荒岛上，它是一颗直接击碎心脏的死刑子弹。

第二号绝对禁区：相思子。

在低矮的沙生藤蔓里，我看到了一串裂开的褐色小豆荚。

豆荚里面，整整齐齐地镶嵌着几颗极其精致、光亮如漆的小圆豆。豆子的上半截是鲜艳欲滴的猩红色，下半截是一颗乌黑发亮的小圆帽。

在城里，人们把它串成手串，叫作“红豆”。

但在毒理学里，它是大自然合成的最致命的细胞毒蛋白之一：相思子毒素。

这种毒素的毒性，比臭名昭著的蓖麻毒素还要猛烈上百倍。

只要牙齿咬碎了哪怕一颗硬壳，吸收进体内的相思子毒蛋白，就会像一台冷酷的碎纸机，摧毁核糖体，在细胞水平上彻底关闭人体所有的蛋白质合成通路。

没有解药。

全身上下的毛细血管会在二十四小时内破裂出血，消化道大出血，肝肾组织成片坏死，人在清醒的极度痛苦中慢慢烂死。

第三号绝对禁区：大戟科与沙盒树的白色乳汁。

不管是高大的乔木还是伏地的小草，只要折断枝桠渗出浓稠的白色奶汁，立刻把手抽回来。

那些乳汁里充斥着极其强烈的佛波酯。

只要沾在眼睑上，半小时内就会引发急性化学性角膜灼伤，带来永久性的双目失明；

如果把这种木头当柴火扔进火堆里，燃烧释放出来的烟雾里充满了挥发性二萜类化合物，吸进肺里会引发严重的化学性肺炎和呼吸道黏膜脱落。

除了这几个恶魔，还有几条刻在骨头上的防毒警戒线：

绝不碰任何开着伞状白色碎花、长得像胡萝卜花的野生草类——那往往是毒芹的近亲，里面的毒芹碱能在二十分钟内麻痹膈肌神经；

绝不碰任何表面光滑、成熟后呈现出纯白或者苍黄色的小浆果；

绝不把任何放进嘴里泛着微苦杏仁味、或者金属腥味的根茎吞进肚里。

我用木棍把脚边的一串相思子豆荚狠狠挑开，远远地扔进了汹涌的外海浪头里。

大自然不全是母亲，有时候它是一个冷血的下毒者。

它在最娇嫩的果实里装满毒液，在最艳丽的花朵下藏着尖刺。

克制食欲，尊重界限。

在这座岛上，宁可忍着饥饿去啃干涩难咽的熟野芋头，也绝不要对那些诱人的剧毒珠宝多看上一眼。

我转过身，大步走回属于我的营地。

手里的木棍沉重地顿在地上，每一步，都踏在理智筑起的安全线以内。
