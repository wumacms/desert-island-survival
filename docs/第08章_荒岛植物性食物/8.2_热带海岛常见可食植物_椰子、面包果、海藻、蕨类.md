# 8.2 热带海岛常见可食植物：椰子、面包果、海藻、蕨类

八个小时过去了。

我的胃里很平静，没有抽搐，没有反酸，体温稳定在三十六度八。

那块野山药是无毒的。但在这座二十平方公里的海岛上，你不可能靠着一次次耗时八小时的试毒去填饱肚子。

大洋深处的海岛上，早就有几千年来被南岛先民反复验证过的四大生存植物。

只要认准它们，你根本不需要用性命去赌那些未知的有毒野果。

第一样，是无所不能的椰子。

在野外，椰子是名副其实的“生命之树”。但懂得吃椰子的人，绝不会只看那些掉在地上的老椰子。

椰子分为三个阶段，每一个阶段都是完全不同的补给品。

第一阶段是绿色的青椰。里面的椰汁是无菌的等渗液体，富含钾离子和葡萄糖，可以直接代替生理盐水补充体液；内壁那层半透明的胶状嫩椰肉，像果冻一样嫩滑，极易被衰弱的肠胃消化。

第二阶段是掉在地上的褐色老椰。椰肉变硬变厚，含油量飙升到百分之三十五以上。

那些脂肪是珍贵的中链甘油三酯。这种中链脂肪酸不需要经过胆汁的复杂乳化，能直接通过门静脉进入肝脏，快速分解转化成ATP能量。

一颗老椰子的椰肉，能提供上千大卡的纯净热量。

咬上一口硬椰肉，浓郁的白浆在嘴里化开，那是几天以来我尝到的第一抹扎扎实实的油脂香味。

第三阶段，则是最稀罕的“发芽椰”。

当老椰子长出绿芽的时候，内腔里的水会消失，取而代之的是一个海绵状的白色圆球。

那是椰胚吸收养分的吸器。口感松脆、微甜、多汁，像是一块浸透了椰奶的苹果，富含维生素C，能彻底阻断坏血病的阴影。

第二样，是真正的荒野面包树。

在山谷入口的一处避风平地上，我找到了三株两人合抱粗的高大乔木。

树冠上挂满了绿油油、排球大小、表皮布满细小凹凸钝刺的重果实。

面包果。

这是热带海岛上单位面积产热量最高的淀粉之王。一棵成熟的面包树，一年能结出几百颗沉甸甸的果实。

我用长木棍捅下两颗沉重的大果子。

这种果子不能生吃，里面的生淀粉颗粒紧密结晶，肠道根本无法吸收。

我把它直接扔进了达科他火坑通红的炭火堆里。

不需要剥皮，不需要清洗。

烈火在烤热果肉的同时，果皮里的水分会形成密闭的蒸汽室。整整烤了四十分钟，外皮被烧成了焦黑的炭壳，空气里散发出了一股烤面包和熟红薯交织的浓郁甜香。

我用木棍把滚烫的黑果子拨出火塘，用石片敲碎焦黑的外壳。

里面的果肉冒着滚烫的白色蒸汽，金黄、松软、细腻，像极了刚出炉的新鲜酵母面包。

我用手指掰下一块塞进嘴里。

软糯、香甜、滚烫。淀粉在唾液淀粉酶的分解下，迅速在舌尖上化成了甜丝丝的麦芽糖。

这是十天以来，我的身体吃下的第一顿真正意义上的碳水化合物大餐。

胃里沉甸甸的，那种抓心挠肝的饥饿感，在几口热气腾腾的面包果下肚之后，被彻底抚平了。

除了陆地上的大树，溪流边还有水嫩的野蕨菜。

那些像拳头一样紧紧卷曲的绿色嫩芽，采下来用滚水烫过，口感脆嫩如芦笋，富含铁元素和胡萝卜素；

在低潮退干的玄武岩浅水石凹里，还漂浮着大片大片薄如蝉翼的墨绿色石莼。

那是大海里的生菜。生吃有些微咸，但晒干之后搓碎撒在烤熟的面包果上，不仅补充了人体必需的碘元素和镁元素，更让寡淡的淀粉带上了一股鲜美的海味。

高热量的椰子脂肪，充沛的面包果淀粉，富含维生素的嫩蕨菜，以及带着矿物盐分的海藻。

四大基石作物在营地的石板上排开。

火光在门廊前静静地跳动着，我靠在竹床的软垫上，慢慢咀嚼着手里的温热食物。

身体深处的细胞在欢呼，疲惫不堪的肌肉在充血、修复。

大自然没有为我开一家超市，但只要你读得懂大地的食谱，这座岛屿上的每一座山头、每一片浪花，都在源源不断地为你端出维持生命的丰厚筵席。
