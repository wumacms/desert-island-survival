# 8.5 植物的非食用用途：药、绳、容器、染料

如果只把植物当成填饱肚子的食物，那是对整座森林最大的浪费。

在文明世界里，生病了去药店，装水用塑料瓶，洗油渍用洗洁精，修工具用强力胶水。

但在荒岛上，没有任何一家货架向你敞开。

这片绿色的丛林不仅是粮仓，它是一座天然的化学工厂、战地药房和工具五金店。

那些无法消化的粗纤维、苦涩的树皮和带有粘性的树胶，在懂科学的人手里，全能变成维系生命的精密器材。

我坐在门廊前的石阶上，把今天采集回来的植物材料在平石板上一一分类排开。

第一类，是战地外科药箱。

我手里握着一小捆刚从山谷采来的野生番石榴嫩叶和新鲜黄槿叶。

这两样东西嚼起来又涩又苦，根本咽不下去。

但这股浓烈的苦涩味，来自细胞里高浓度的天然单宁酸和黄酮类化合物。

我用洗净的圆石块，把这把嫩叶在石臼里使劲捣碎，直到它们变成一团墨绿色、带有浓稠汁液的药泥。

昨天右小腿被荆棘划破的一道长口子，伤口周围已经有些微微泛红。

我把这团黏稠的绿药泥，厚厚地敷在伤口上，再用剥好的树皮布绑紧。

单宁酸是天然的蛋白质凝固剂。

它在微观上能与渗出液中的血清蛋白快速交联，瞬间收缩局部毛细血管，形成一层坚固的生物保护膜，达到极佳的止血效果；同时，高浓度的多酚类物质能破坏金黄色葡萄球菌的细胞壁，阻断热带伤口最致命的化脓感染。

草药刚敷上去时有一阵短暂的微麻刺痛，但短短几分钟后，原本火烧火燎的肿胀感就慢慢平息了下去。

如果遇到头痛发烧，山溪旁野生榕属树木的嫩内皮，煮沸后是一碗绝佳的退烧汤。

内皮里富含水杨苷，进入人体肝脏后会水解氧化成水杨酸——那就是现代阿司匹林天然的化学老祖宗。

第二类，是天然表面活性剂。

吃了两天的海鲜和烤果子，手指和嘴唇上结了一层黏糊糊的油垢。海水洗不掉油脂，纯淡水也只能让油脂浮在表面。

我采来了一捧野生无患子的黄褐色皱皮果实，以及一大把野生海滨木槿的新鲜叶片。

把两颗果子放在水盆里用力揉搓。

短短十秒钟，冰凉的清水里就泛起了雪白、细腻、经久不散的丰富泡沫。

那是天然的三萜皂苷。

皂苷分子就像一把双头扳手，一端是亲油的非极性基团，死死咬住皮肤表面的油脂；另一端是亲水的极性基团，顺着水流被轻松冲走。

用这种天然肥皂洗手洗脸，不仅洗掉了恼人的海腥味和鱼油，更把可能滋生细菌的皮脂污垢清理得干干净净。

第三类，是储水与防腐容器。

在营地的木架上，整整齐齐地码着四个深绿色的大家伙。

那是两端带有完整竹节的粗毛竹，长达一米，中间用黑曜石凿开了一个平整的椭圆形开口，两头用木塞封死，做成了能背在身上的抗摔水壶；

旁边摆着几只从老椰子上切下来的坚硬黑壳，用草木灰彻底洗净油脂后，变成了可以盛放滚烫热汤的天然木碗；

而在最高处的干燥架子上，还挂着两只被阳光彻底晒干的硬壳野生葫芦。

葫芦木质化的外壳致密干燥，绝不透水，里面塞满了我用竹筒闷烧出来的干引火绒和细炭化布，哪怕外面倾盆大雨，里面的火种也绝不会受潮。

第四类，是古代的环氧树脂胶。

在修理石斧和木矛的时候，最头疼的就是绑绳容易打滑松动。

我从一棵受伤的老野树干上，刮下了一贝壳半透明、金黄色的黏稠天然树脂。

把树脂放在贝壳里，架在火塘边缘慢慢加热融化；然后倒进三分之一极细的黑色木炭粉末，用小树枝使劲搅拌均匀。

木炭粉充当了微观的增强填料，极大地提高了树脂固化后的韧性，防止它冷却后变脆碎裂。

趁热把这层黑色的沥青胶抹在石斧与木柄绑绳的缝隙里。

冷却之后，胶水硬得像一块黑色的塑料，把麻绳、石头和木柄死死浇铸在一起，哪怕用石锤狠狠敲打，也绝不会松动半毫米。

外敷的止血药膏，洗去污垢的皂苷泡沫，耐用的储水竹壶，硬化如铁的树脂黑胶。

我收拾好石板上的工具，把一罐刚熬好的单宁药泥放进了石洞的药架上。

在这座与世隔绝的孤岛上，大自然没有留下哪怕一颗螺丝钉，也没有留下一粒退烧药片。

但大自然的化学宝库是无限的。

只要你懂得分子间的结合、水解与沉淀，那些沉默的树木和杂草，就会在人类理智的调遣下，乖乖交出所有的秘密，为这场漫长的求生战役，铸造起一套永不枯竭的后勤补给线。
