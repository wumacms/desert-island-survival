# 8.1 可食用植物的识别原则：通用可食性测试

第十天的清晨，我感到身体里的能量见底了。

肚子空得像一口废弃的枯井，胃壁互相摩擦，带来一阵阵沉闷的抽痛。两腿有些发虚，站起来的时候，眼前闪过一片微弱的金星。

在最初的几天里，身体一直在燃烧皮下脂肪和肌肉里的糖原。

但体内的碳水化合物储备已经耗光了。没有糖分，脂肪无法进行完全的三羧酸循环氧化，血液里的酮体浓度开始上升，呼吸里带上了一股烂苹果般的丙酮气味。

大脑需要葡萄糖，红细胞需要葡萄糖。

我必须找到植物性淀粉。

走在热带雨林里，四周到处都是肥厚多汁的绿叶、粗壮膨大的块根和色彩鲜艳的野生浆果。

但在这片绿色的海洋里，百分之八十的植物，把自己的肉体武装成了生化武器库。

植物不会奔跑，也不会用尖牙利爪撕咬。

为了不被食草动物啃光，在几亿年的演化中，它们在细胞里合成了自然界最复杂的次生代谢产物：剧毒的生物碱、强心苷、皂苷、草酸钙针晶和生氰糖苷。

贸然把一种不认识的野草塞进嘴里大嚼，和在左轮手枪里塞进五颗子弹对准自己的太阳穴扣动扳机没有任何区别。

在没有任何植物图鉴的荒岛上，要确定一种植物能不能吃，唯一的武器就是“通用可食性测试”。

这是一场长达整整八个小时的严酷试毒协议。

我在山坡的向阳灌木丛里，挖出了一块拳头大小、外形类似野山药的肥大植物块根。

我把它带回了营地的石台上。

第一步：部位分离。

绝不能把植物的根、茎、叶、花混在一起测试。很多植物的果实甜美可口，但它们的叶子和根部却含有致命的剧毒。一次只测一个部位。我切下了块根最白嫩的一片。

第二步：嗅觉检验。

我用手指把这片白根肉使劲碾碎，凑在鼻子底下深深吸了一口气。

如果有刺鼻的苦杏仁味（氢氰酸），或者刺鼻的腐臭酸味，立刻扔掉。这块根散发出来的是一股清淡的泥土和生淀粉香气。

第三步：皮肤过敏试验。

我把白色的块根汁液，厚厚地涂抹在自己左手手肘内侧最娇嫩、最薄的皮肤上。

我坐了下来，看着外面的海浪，耐心地等待了十五分钟。

没有红肿，没有发痒，也没有火灼般的刺痛感。

第四步：接触唇黏膜。

我切下一小块指甲盖大小的肉质，轻轻贴在自己的外嘴唇上，含住十五分钟。

嘴唇是人体神经末梢最敏感的区域之一。许多植物毒素在碰到嘴唇的瞬间，就会引发明显的麻木、肿胀或者麻刺感。

嘴唇依然正常。

第五步：舌尖味觉探测。

我把那小块植物放在舌尖上，不嚼，不咽，静静放了五分钟。

舌尖感受到了微弱的淀粉甜味，没有肥皂般的苦涩，没有针扎般的刺痛，舌头发麻的感觉也没有出现。

第六步：咀嚼含化。

我把这块根肉放进臼齿之间，慢慢咀嚼成糊状，用舌头把它裹住，含在口腔里整整十五分钟，依然没有咽下去。

口腔黏膜没有分泌异常的唾液，咽喉没有发紧。我把嚼烂的渣子吐了出来，用清水漱了漱口。

前奏全部通过了。现在，轮到了最关键的最后一搏：微量吞咽。

第七步：微量消化道测试。

我重新切下一小块像黄豆大小的熟块根，就着一口凉开水，硬生生咽进了胃里。

然后，我放下了手里的所有工具。

从这一分钟开始，在接下来的整整八个小时内，我不能吃任何其他东西，不能喝除白开水以外的任何液体。

我必须把自己变成一个最敏锐的生物传感器，全神贯注地监控这颗黄豆大小的植物碎片在胃肠道里的每一个微小反应。

八个小时，足够胃酸分解植物细胞，把可能存在的生物碱释放进血液。

我在门廊下的竹床上躺了下来，闭上眼睛，静静等待着体内器官的判决。

如果接下来的八个小时里，胃里出现绞痛、剧烈的恶心、腹泻、或者视线模糊、冷汗淋漓，我必须立刻用羽毛刺激咽喉催吐，并吞下大量的木炭粉吸附毒素。

如果八个小时风平浪静，那座山坡上的几十株块根，就是大自然赏赐给我的丰厚粮仓。

测试繁琐、漫长、折磨人。

但在荒野里，没有轻率的冒险，只有冰冷严谨的求证。

死神就在丛林里游荡，而这套八小时的科学步骤，就是我手里唯一的避雷针。
