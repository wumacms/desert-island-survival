# 附录F 常见伤病急救流程

在文明世界的医院里，急救是一整套由急救呼叫中心、救护车监护仪、无菌手术室、血库与外科专家团队构筑的现代神迹。

但在孤岛的绝壁下，没有救护车，没有无影灯，没有麻醉师。

当动脉破裂的鲜血如喷泉般冲上你的脸颊，当骨折断端刺破皮肤白森森地暴露在暴雨中，当高热与寒颤让你浑身颤抖如同筛糠时，你面对的是人类生理学最残酷的死亡倒计时。

在极度的剧痛与濒死恐惧中，交感神经系统会爆发海量的肾上腺素，导致幸存者出现致命的“认知隧道效应（Cognitive Tunneling）”——你的视野狭窄如管窥，双手颤抖不受控制，大脑失去逻辑推理能力，在无意义的嚎叫与抓狂中错失黄金抢救窗口，直至休克昏迷。

在野战医学中，战胜恐慌的唯一武器，是**固化为肌肉反射的临床决策算法（Clinical Algorithm）**。

本附录将野战战术伤员救治（TCCC）、世界卫生组织（WHO）急救指南与极端蛮荒环境外科手术经验，高度浓缩为五套逻辑清晰、步骤不可逆的“阶梯式急救流程图”。

把这些流程刻在你的潜意识深处。

当你身受重伤时，把你的左手当成巡回护士，右手当成主刀医师，用你的前额叶彻底压制边缘系统的恐惧，按照流程，一步一步，亲手把自己的命从阎王殿里生生夺回来！

## 流程一：急性外伤大出血阶梯止血流程（Catastrophic Hemorrhage Control）

失血性休克是创伤致死的第一死因。股动脉或肱动脉完全断裂，人体三分之一的有效循环血量会在**两分钟内**喷洒殆尽，随后脑缺血昏迷死亡。

## 流程二：重度脱水、热射病与低血容量休克复苏流程（Shock & Rehydration）

无论是严重烧伤导致的大量体液渗出、热带丛林急性菌痢引发的水样暴泻，还是正午无遮蔽重体力劳作引发的体温调节衰竭，体液平衡崩溃都会在几小时内诱发周围循环衰竭。

### 1. 现场休克状态三秒速查指征
- **毛细血管再充盈时间（CRT）**：用力按压大拇指甲床三秒使其变白，松开后若甲床恢复粉红色的时间**大于两秒**，表明外周微循环严重缺血虚脱！
- **颈动脉搏动与神志**：桡动脉（手腕）搏动消失仅能扪及颈动脉，心率 $>120$ 次/分，伴随直立性眩晕与谵妄。

### 2. 世界卫生组织（WHO）生存标准口服补液盐（ORS）自制与滴定补液法

```
               【 极度脱水与失血休克初期（意识尚清醒）】
                                   |
                  【 严禁一次性狂饮大量纯淡水！】
            ( 胃内低渗膨胀会诱发反射性剧烈呕吐，并引发致命水中毒脑水肿！)
                                   |
            ================================================
            【 科学配制荒野 ORS 液体（肠道水钠协同转运配方）】
            ================================================
            在 1000 ml 煮沸放凉的纯净水中精确加入：
            1. 氯化钠（纯海盐）：3.5 克（约半个矿泉水瓶盖，或微平一小竹勺）
            2. 碳酸氢钠/氯化钾替代源：新鲜嫩椰子水 200 ml（提供钾离子缓冲酸中毒）
            3. 葡萄糖/糊精碳水：熟米汤/烤熟红薯捣烂过滤汁 20 克（提供钠泵吸收能量）
                                   |
            ================================================
            【 节律性滴定式补充流程 】
            ================================================
            • 每 5–10 分钟极其缓慢地啜饮 50–100 ml；
            • 连续补充两小时，直至排尿恢复、尿色转为淡黄色；
            • 伤员平卧，双腿抬高三十度（下肢自体自体输血位），头部放平侧偏。
```

### 3. 热射病（经典型劳力性热中暑）秒级降温动作
- **诊断标志**：暴露在烈日下突然倒地，**高热（核心体温 $>40^\circ\text{C}$）、皮肤滚烫、干热无汗、陷入昏迷抽搐**。
- **降温死命令（抢救目标：30分钟内将体温降至38.5℃以下）**：
  1. 立即将患者拖入阴凉通风处，彻底扒光所有衣物；
  2. **蒸发对流冷风降温**：用温水或凉水不断泼洒喷淋患者全身，同时用宽大芭蕉叶全力扇风，利用水分剧烈蒸发带走相变潜热；
  3. **大血管物理冰敷点**：将浸透冰冷溪水的湿布或冷卵石，死死压在**双侧颈动脉三角、双侧腋窝与双侧腹股沟大腿根部**（直接冷却全身主干血液循环）。

## 流程三：骨折与严重关节脱位复位固定流程（Fracture & Splinting）

野外跌落导致四肢长骨骨折，断骨痉挛错位会持续刺穿肌肉大血管，带来无法忍受的剧痛与内出血休克。

```
                     【 肢体遭受重击畸形 / 听见骨擦音 】
                                     |
                         判断骨折类型与神经血管状态？
                         /                            \
               [ 闭合性骨折 ]                      [ 开放性骨折 ]
             ( 皮肤完整未破裂 )                 ( 骨折端刺破皮肤外露 )
                    |                                  |
         检查远端足背/桡动脉搏动？             【 绝 对 禁 忌 】
                    |                     **严禁将外露骨端推回体内！**
          脉搏消失且肢体苍白？            ( 会将外界泥沙破伤风菌直接带入骨髓！)
                    |                                  |
       ============================       用浓盐水冲洗创口周围泥土，
       【 紧急手法轴向牵引复位 】          用煮沸消毒干布轻柔覆盖创面，
       ============================       严密包扎止血，再行下述固定。
       • 一人死死抱住伤员近端躯干反抗牵引
       • 术者握住伤肢远端（足踝或手腕），
         沿着肢体纵轴方向，**缓慢、平稳、坚定地持续拉伸牵引！**
       • 持续牵拉两分钟，对抗肌肉顽固性痉挛；
       • 感觉断骨对中回位，远端动脉搏动重新搏动跳动，维持轻柔牵引。
                    |
       ====================================================
       【 刚性夹板超关节外固定规范（Rigid Splinting Rules）】
       ====================================================
       1. **双关节固定准则**：固定夹板长度必须**同时越过骨折处的上方关节与下方关节**！
          （例如：小腿胫腓骨骨折，夹板必须向上超过膝关节、向下超过踝关节！）
       2. **材料准备**：选用三至四根笔直坚固的青楠竹板或硬木条；
       3. **骨隆突软衬垫保护**：在踝骨内外踝、膝关节内外侧、骨折尖锐处，垫上厚软苔藓或软布，
          防止硬夹板长期压迫导致皮肤大面积压疮缺血坏死；
       4. **阶梯绑扎力学**：用布带牢固捆扎四道：骨折近端一道、远端一道、上关节一道、下关节一道；
       5. **松紧度核验**：绑扎后手指应能勉强伸入绑带一指，严密监测远端脚趾/手指血运（色泽红润且温暖）。
```

## 四、 严重深层感染、创伤弧菌坏死性筋膜炎与败血症阻断流程

在高温高湿的热带海岛，海洋水体与土壤中充斥着致命的嗜盐致病菌——**创伤弧菌（*Vibrio vulnificus*）**与产气荚膜梭菌。珊瑚礁刮伤后如果不加干预，四十八小时内即可演变为烂肉剥脱的致死性坏死性筋膜炎。

### 1. 创伤弧菌感染早期三联恶化警报
- **疼痛不成比例**：一个小小的贝壳划伤，局部爆发撕心裂肺、与外观伤口极不相称的剧烈爆裂痛；
- **血性大疱与皮肤变色**：伤口周围皮肤在十二小时内由红转为紫黑坏死，表面浮现出充满黑血与脓液的巨大血疱；
- **全身中毒症状**：高热四百度、寒战、谵妄、血压急剧下降。

### 2. 荒野终极外科清创与排脓引流手术规程（Incision & Drainage）

```
               【 伤口出现波动感深层脓肿 / 坏死扩散 】
                                   |
                  【 术前严苛物理器械灭菌准备 】
            • 将手术直刀或高碳钢小刀置于白炭火上反复灼烧至通红冷却；
            • 术者双手用高浓度草木灰强碱皂液与75%纯乙醇反复搓洗五分钟；
            • 准备一陶锅刚煮沸冷却至温热的 3% 高渗灭菌浓盐水（或野番石榴浓单宁水）。
                                   |
            ================================================
            【 第一步：切开与彻底机械减压（Fasciotomy）】
            ================================================
            • 咬紧木棒，忍受剧痛；
            • 顺着皮纹与肌肉走向，在红肿波动感最明显的核心区域，
              果断纵向切开一条长约 3–5cm 的切口，深度贯穿全层皮肤直达脓腔深处！
            • 积压的恶臭黄黑脓液与坏死血性液体瞬间喷出，筋膜间隙内高压瞬间释放！
                                   |
            ================================================
            【 第二步：坏死组织钝性剥离清创（Debridement）】
            ================================================
            • 用无菌骨匙或刀背，耐心地刮除脓腔内壁所有呈灰白色、无血运、失去弹性的腐肉；
            • 直到露出新鲜渗血、呈鲜红色的健康肉芽组织为止！（腐肉不除，厌氧菌永不灭绝！）
                                   |
            ================================================
            【 第三步：高压冲洗与开放引流（Open Drainage）】
            ================================================
            • 用自制竹筒注射器抽取大量温热无菌盐水，对准深部创底进行强力连续冲洗；
            • **【外科铁律：严禁缝合感染化脓创口！】**
            • 将一条浸透了纯天然蜂蜜与捣碎大蒜汁（大蒜素杀菌）的无菌引流亚麻布条，
              轻轻塞入切口深部，使脓液顺着布条持续向外引流；
            • 每日更换引流条两次，直至创底新鲜肉芽平整长出。
```

## 五、 海水淹溺窒息心搏骤停复苏流程（Near-Drowning CPR）

海洋溺水机制与陆地猝死截然不同：海水进入呼吸道后，高渗海水会剧烈吸出肺泡毛细血管内的水分，诱发暴发性急性肺水肿，并导致反射性喉头痉挛严重内窒息。

```
                     【 将溺水者拖上海滩平整沙地 】
                                    |
                        评估意识与自主呼吸状况？
                        /                        \
           [ 有微弱呼吸与咳嗽 ]             [ 呼之不应，无呼吸或仅濒死叹气 ]
                    |                                    |
          侧卧位（稳定恢复体位），             ====================================
          头偏向一侧拍背，                     【 溺水急救第一步：立即开放气道 】
          清除口鼻海藻与泥沙呕吐物。            ====================================
                                               • 跪于伤员肩侧，仰头抬颏法开放气道；
                                               • 迅速掏出咽喉部的烂泥、碎贝壳与假牙；
                                               • **【严禁倒挂控水！】**控水耽误黄金心肺复苏！
                                                         |
                                               ====================================
                                               【 溺水复苏黄金法则：首给5次人工吹气 】
                                               ====================================
                                               • 捏闭鼻翼，口对口严密包闭患者嘴唇；
                                               • 连续吹入五次深长、平稳的人工吹气（每次1秒）；
                                               • 观察胸廓是否明显起伏（克服肺水肿阻力）。
                                                         |
                                               检查颈动脉搏动（判定时间 $\le 10$ 秒）？
                                               /                                  \
                                       [ 仍无任何脉搏 ]                      [ 脉搏恢复 ]
                                              |                                    |
                                  ========================             维持每分钟12次人工呼吸，
                                  【 持续胸外按压与循环通气 】          直至自主呼吸平稳恢复。
                                  ========================
                                  • 双手掌根重叠紧扣，置于两乳头连线中点胸骨下段；
                                  • 双臂垂直伸直，借助上半身重力全力垂直下压！
                                  • 按压深度：**至少 5 厘米（但不超过 6 厘米）**；
                                  • 按压频率：**严格维持在每分钟 100 至 120 次！**；
                                  • 每次按压后让胸廓完全回弹，中途停顿不可超过10秒！
                                  • 严格按 **【30 次胸外按压 ：2 次人工吹气】** 循环交替推进！
                                  • 持续实施复苏抢救至少三十分钟以上，决不可轻言放弃！
```
