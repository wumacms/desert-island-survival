# 附录D 求救信号与国际通用代码

在无垠的南太平洋波涛之上，一座直径三海里的孤岛在万米高空的客机舷窗里，不过是浩瀚蓝布上的一粒微小灰尘。

现代搜索与救援（SAR）体系不是靠盲目的人眼扫视，而是由高空轨道卫星红外传感器、合成孔径雷达（SAR）、多光谱航空侦察吊舱与搜救飞行员严格的扫描视线构成的机器化网络。如果你只是坐在沙滩上挥舞手臂，对于以每小时四百公里低空掠过的搜救机而言，你的角运动速度太慢、反射截面积太小，在几秒钟的视界窗口内，肉眼根本无法将一个挥手的人与一根风中摇摆的枯树桩区分开来。

求救信号不是原始人的呼天抢地，而是一门基于**光学反差力学、射频编码节律与视觉拓扑几何**的精密通信科学。

当救援力量出现时，留给你的通信窗口往往只有极度短暂的数十秒。如果你发出的信号不符合国际通用航空规范，飞行员会将其误判为普通的地质反光或地面土著营火，从而呼啸掠过，将你彻底抛弃在无尽的等待中。

本附录将国际民航组织（ICAO）、国际海事组织（IMO）与国际红十字会的最高标准通信代码与物理发射规程系统整理成表，作为荒岛求生者架设地空天线与光波信标的绝对标准规范。

## 一、 国际摩尔斯电码（International Morse Code）全矩阵与发报时序

摩尔斯电码是全宇宙容错率最高的数字通信协议。无论你手中握着的是一台能够产生通断电弧的高压电池组、一面能在阳光下闪烁刺目脉冲的反光镜、一具穿透力极强的号角，还是一堆用树枝反复遮挡明火的火塘，只要能产生“亮/暗”或“声/静”的二进制状态，你就能向文明世界倾泻你的意志。

### 1. 严格时序物理公理（Timing Rules）
- **基准时间单位（1 Unit, “滴” / Dit / $\cdot$）**：最短的脉冲持续时间（推荐值：0.2秒）。
- **长划（Dash / $-$）**：长度恒等于 **3 个基准单位**（即 $1 - = 3 \cdot$）。
- **字符内部间隔**：同一个字母内相邻的“点”与“划”之间，静默持续 **1 个基准单位**。
- **字母与字母间隔**：同一个单词内相邻两个字母之间，静默持续 **3 个基准单位**。
- **单词与单词间隔**：两个独立单词之间，静默持续 **7 个基准单位**。

当空中出现固定翼搜救机或直升机时，发动机的巨大轰鸣声彻底抹杀了任何声学通信的可能。地面求生者必须在开阔地形上，利用高几何反差的物理地标，直接向飞行员视网膜投射标准的“地对空单字母象形符号”。

### 2. 地面地标工程力学建造铁律
- **几何尺度红线**：每个字母的长度**不得小于三米（极限推荐值为八至十米长）**，笔画宽度不得小于五十厘米，字母长宽比严格控制在六比一左右；尺寸小于三米的地标在千米高空将被大气散射彻底滤除。
- **高对比度阴影沟槽工程（Shadow-trench Method）**：在平整白色沙滩上，单纯平铺黑木头极易被风吹散；必须在沙地上挖掘深达四十厘米的陡峭垂直沟槽，将深色湿泥与焦黑木炭填入沟底。当太阳以斜角照射时，沟槽迎光面产生深邃的高反差刀削阴影，在地表上形成如同黑色墨水书写般的强烈视觉锐度。
- **基质反差对撞原则**：
  - **在深黑火山玄武岩岩盘上**：使用打碎的高反光雪白死珊瑚块与石灰贝壳严密排布出白色符号；
  - **在浅色沙滩或干枯黄草地上**：用火塘浓烟彻底熏黑的粗大树干，或直接用火定向烧焦地表泥土，构建深黑焦炭符号。

## 三、 日光信号反射镜（Heliograph）瞄准操作规程与几何光度学

日光反射镜是所有野外信号工具中**功率密度最恐怖的能量发射机**。

在晴朗正午，一面仅有掌心大小（十厘米见方）的高反射率平面镜，能够将大约十瓦特的平行太阳光束射向目标。由于太阳光的自然发散角仅有零点五度左右，其能量在数十公里内高度集中，在视线尽头产生的等效光强能够达到**数百万坎德拉（Candela）**，足以刺穿三十海里外的海面薄雾，直接触发客机机长的第一视野防空撞光敏警报！

### 1. 双孔十字光斑瞄准法四步操作规程
如果只是拿着镜子对着太阳乱晃，光束打中远方飞机驾驶舱的概率小于十万分之一。必须依靠“双孔光学十字线合眸法则”实现微米级精确锁定：

```
                 [ 太阳光线 ]
                      \
                       \
                        v
[ 幸存者眼睛 ] ----> ( 镜中心观察孔 ) ===== [ 瞄准手指/目标 ] ====> [ 远方搜救机/船只 ]
                        |
              [ 产生的极亮小光斑 ]
```

1. **构筑基准瞄准线**：将镜子紧贴在单眼眼窝前，透过镜子正中央的微小透明未镀银圆形观察孔（或十字瞄准网格），死死凝视远方地平线上的救援船只或低空盘旋的飞机。
2. **建立前准星**：伸出另一条手臂，将食指拇指比成“V”字形（或举起一根垂直的小木棍），将手指尖端正好垫在视野中飞机机身的正下方。
3. **捕捉二次反射光斑**：用余光微调反光镜的倾斜角，直到太阳反射在镜面背面的光线，在你的面颊或手指背面上，投射出一个极其明亮、刺眼的微小虚拟光斑。
4. **两点归一锁定击发**：缓慢微动手腕，将面颊或手指上的明亮光斑，在视野中与镜中央的观察孔重合，并精准推移覆盖到远方的目标机身之上！一旦重合，意味着你的镜面法线已经精准平分了太阳入射角与目标反射角，数百万烛光的强光柱已经如激光一般狠狠轰击在飞行员的挡风玻璃上！
5. **脉冲调制**：一旦锁定目标，以食指在镜面前快速上下遮挡，按照“三短、三长、三短”的节奏发送闪光 SOS 摩尔斯电码；若目标正在快速横向移动，则以手腕微幅晃动，使光斑在目标航线上进行锯齿状横向扫射。

- **飞机在头顶进行完整的三百六十度顺时针低空水平盘旋盘旋**：
  - **法定含义**：“已确认你的生存状态，正在建立空中通信中继，请在原地等待救援力量抵达！”

  - **法定含义**：“未理解你的信号，你的地面代码有歧义或无法降落，请重新变换信号！”

## 五、 声光烟“三位一体”遇险法宝定律

国际海事求救公约中确立了一条铁打的黄金法则——**三联定律（Rule of Threes）**。在自然界中，任何孤立发生的事物都可以归咎于偶然；但凡以完全相等的间隔、完全对称的三角形或等距直线连续出现“三次”的物理现象，在人类文明的搜救雷达中，就是无可争议的智慧生命遇险宣言。

1. **三堆烈火三堆浓烟（Triangle / Line of Fire）**：
   - 在海滩开阔地上，将三座庞大的木柴堆垒砌成边长三十米的正三角形，或间隔五十米的笔直直线；
   - 随时储备引火物与大量富含油脂的绿阔叶；白昼见机立刻添加绿叶制造三股通天白浓烟，黑夜见机引燃纯干柴制造三道冲天赤红火柱。
2. **三声爆响三声长哨**：
   - 任何声学信号，以每吹响三次为一组，每声长达两秒，每组之间精确静默三秒，随后重复。
3. **三道闪光（Three Flashes）**：
   - 用火把或反光镜，向同一个方位连续急速闪射三次，停顿五秒，再次闪射三次。
