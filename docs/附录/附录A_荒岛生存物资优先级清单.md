# 附录A 荒岛生存物资优先级清单

在荒野中，多余的重量是死神的裹尸布，而物资的错配则是文明人最容易犯下的自杀性错误。

初临绝境的人往往把注意力浪费在虚无缥缈的物品上：他们紧紧抱着毫无用处的湿纸币、损坏的笔记本电脑、或者沉重却无法作为工具的金属装饰品；而在真正的荒野力学中，物资的价值只有一个冷酷的评判标准——**能量回报率（Energy Return on Investment, EROI）与生理维生权重**。

任何一件装备，如果它消耗的搬运体能、维护时间，超过了它在维持核心体温、提供洁净水源、制造火种与获取热量上所创造的边际效益，它就是有害的负资产。

这份清单是基于热力学第二定律、人体代谢生理学与热带岛屿材料学构建的严苛物资评估矩阵。从你睁开眼睛的第一秒起，无论是在搜寻海滩残骸，还是在整理随身口袋，请严格遵照本矩阵进行物资分类、取舍与战术配置。

## 一、 物资评估四维指标体系

在决定保留、改造或丢弃任何一件物品之前，大脑必须在三秒内完成以下四个物理维度的量化运算：

1. **维生临界度（Criticality Index, CI）**：该物品缺失时，人体生理机能走向不可逆损伤或死亡的时间窗口。
   - 等级 4（即时致命）：缺失在 3 小时至 72 小时内致死（如保暖、水源、止血带）。
   - 等级 3（亚急性致命）：缺失在 3 周内致死（如火种、基础碳水与蛋白质获取工具）。
   - 等级 2（机能退化）：长期缺失导致免疫崩溃、骨骼肌肉损伤（如盐分、维生素、制鞋材料）。
   - 等级 1（舒适与效率）：提升热量利用率与心理秩序（如桌椅、精制陶器、墨水）。

2. **不可替代指数（Irreplaceability Index, II）**：在不具备现代工业母机的前提下，利用岛屿天然材料从零制造该物品的难度与热量成本（1分最低，5分最高）。
   - 5分：极难自制，需消耗数百小时且依赖极端偶发条件（如高碳钢刀刃、聚酯防水雨衣、抗生素）。
   - 1分：极易就地取材，可在两小时内找到天然替代品（如木棍、普通绳索、叶片遮盖物）。

3. **重量能耗比（Weight-to-Energy Cost, WEC）**：携带该物品行军或作业时，每小时额外消耗的卡路里与该物品所能创造的热量乘积之比。

4. **拓扑多功能性（Topological Versatility, TV）**：该物理结构是否能跨越学科界限，同时在水、火、庇护、捕猎、信号等多个系统中复用（如一只不锈钢饭盒既是水容器、也是煮锅、蒸馏釜、挖掘铲、信号反光镜）。

## 三、 海滩废弃残骸“点石成金”甄别淘汰红线表

海难发生后，沙滩上会散落大量现代工业垃圾。愚蠢的人会把真正的黄金当垃圾丢弃，却把毫无价值的垃圾当宝贝搬回营地。请牢记以下鉴别准则：

### 【必须全力抢救运回的“黄金废料”】
1. **废弃汽车/摩托车内胎（丁基橡胶）**：剪裁后是全世界最强的弹性弹力发射带、高压密封水管接头垫圈、顶级防水靴鞋底。
2. **废旧火花塞（高纯氧化铝陶瓷柱）**：用石头敲碎后，陶瓷碎片硬度高达莫氏 9 度，是比燧石快十倍的战术级割划玻璃与削铁刀片。
3. **报废碱性干电池**：破拆后内部可获得高纯度天然二氧化锰（优质氧化剂与化学脱色剂）与中央导电碳棒（电解水惰性电极）。
4. **废旧渔网浮标（硬质高密度聚乙烯 HDPE 塑料球）**：切开是现成的无菌大口水碗，完好时是出海木筏绝对不沉的侧翼浮筒。
5. **不锈钢钢丝绳与刹车线**：解股后可获得数十根高弹性、抗海水腐蚀的超细钢丝，是制作捕兽套索陷阱（Snare）最致命的无形绞索。

### 【坚决就地丢弃抛弃的“虚假负资产”】
1. **浸泡海水的湿木质家具与刨花板**：吸饱了盐水，重量暴增三倍，既不能当建材（内部全脱胶脆化），也无法点燃（燃烧散发剧毒甲醛白烟）。
2. **大型金属发动机铝合金缸体**：在没有三千度熔炉的前提下，几十公斤的铝块纯粹是无法加工的死重，耗费体能搬运等同于自杀。
3. **湿透的棉花被褥与毛毯**：在热带高湿环境下，吸收上百斤海水后无法拧干，且会在三天内爆发密集黑霉菌与尘螨，引发致死性吸入性肺炎。
4. **所有带集成电路板的数码产品与显示屏**：芯片与精密元件在海水离子渗透后彻底短路烧毁，除了极少数镜面可用作反光镜外，没有任何力学与化学复用价值。

## 四、 物资维护、仓储配比与“三三制”冗余法则

任何依赖单一装备的生存系统，在统计学上其长期存活概率无限趋近于零。在营地资源管理中，必须无条件推行**“三三制”空间与功能冗余原则**：

1. **三处分散物理存储**：
   - **随身装具包（40% 核心轻量化资产）**：保障随时被迫撤离时的独立生存。
   - **主生活营地石屋仓（40% 重型耐用品与粮食库存）**：保障日常生活与扩大再生产。
   - **高位绝壁干燥海蚀洞（20% 战略冷储备）**：防范特大海啸、山体滑坡或营地大火的终极保底备份（包含一套完整的打火工具、备用高碳钢小刀、密封盐罐与一卷防水蜡纸海图）。

2. **三种独立热力学取火备份**：
   - 物理火种：镁棒打火石或火柴（即时秒级点火）。
   - 光学火种：抛物面反光镜或研磨凸透镜（只要晴天永不消耗介质）。
   - 机械摩擦火种：硬木弓钻套件与燧石打击火镰（无限循环的植物力学后备）。

3. **每周周期性物理探伤与除湿维护日**：
   - 每周日正午，所有碳钢刀具必须重新用火塘余热彻底烘烤驱除微观孔隙水分，涂抹热椰油闭孔隔绝空气；
   - 检查所有绳索接口与陶罐釉面，将受潮物品放入太阳能对流干燥塔内进行强制脱水。
