# 7.4 脚部保护：草鞋、树皮鞋的制作

一个失去双脚的求生者，已经是一具死尸了。

第九天的下午，我坐在岩石台地上，脱下了脚上那双早就被海水泡得变形裂口的皮鞋。

鞋底已经被锋利的玄武岩碎石磨穿了一个大洞，脚掌心踩得通红，被碎石子硌出了两个发青的血泡。

在荒岛上，哪怕你有一颗最聪明的大脑，只要脚底板被一根带毒的黑海胆刺穿透，或者被暗礁切开深达骨头的口子，整场求生就会在这个瞬间戛然而止。

你无法再走四百米去山谷打水，无法弯腰拾柴，甚至无法在涨潮时逃离海浪。

两天之内，感染化脓和剧痛会把你死死钉在草棚里，等待你的只有脱水和死亡。

脚是这台机器唯一的轮子。

必须在鞋底彻底散架之前，给这双脚装上新的装甲。

造一双能在锋利礁石上行走的荒野草鞋，靠的不是普通的稻草，而是力学结构的精巧编织。

我准备了两种材料。

一种是剥去硬皮、撕成条状的露兜树叶。这种叶子纤维极长，带有天然的蜡质层，耐磨且不怕海水浸泡；

另一种，是一大捆粗糙、富有绝佳弹性的干椰棕纤维。

我脱下袜子，光着脚坐在地上。

我把早先搓好的一根三米长、结实的黄槿双股麻绳对折，将套头死死套在自己的大脚趾上。

大脚趾成了最天然的织布机张力桩。

拉紧两根平行的长绳，两脚自然分开，绳子在脚掌下方拉出了两根平行的受力经线。

编织开始了。

我抓起一把富有弹性的干椰棕，垫在脚跟位置充当减震的基底；然后抽出处理平整的露兜树叶条作为纬线。

手里的叶条以“8”字形的轨迹，在两根平行的经线之间来回穿梭、缠绕。

左边绕过去，右边穿回来。

每穿过一趟，我都用一根坚硬的小木锥，把编好的叶条用力向脚后跟方向狠狠挤压、夯实。

密实度决定了寿命。

如果编得松垮，碎石子会轻易钻进缝隙磨破脚底；只有打得像实木板一样致密，鞋底才能抵挡尖锐石块的刺扎。

在前掌最容易磨损的部位，我足足编了三层厚厚的交叉网，并在底层夹进了一块切成脚掌形状的坚韧生树皮。

厚度达到了一点五公分。

高回弹的椰棕吸收了人体行走的冲击重力，致密的露兜树叶抵挡了地表的摩擦撕扯，坚硬的树皮夹层则如同一块防弹钢板，挡住了朝天竖立的锋利断石。

当鞋底编到脚趾根部时，我收紧了挂在大脚趾上的绳套。

接下来，是决定草鞋能不能跑跳的关键：脚踝锁定系统。

一双不跟脚的鞋子，走不了半里路就会在脚后跟磨出一片巨大的水泡。

我在鞋底的两侧各留出了两个结实的受力小耳环，后跟处留下了一个高高的后跟绊。

长长的麻绳从鞋头引出，穿过大脚趾与二脚趾之间的缝隙，向后交叉越过脚面；穿过两侧的小耳环，在脚踝后方的跟腱部位打出一个十字交叉，最后牢牢绑死在外脚踝上方两公分处。

“拉紧它。”我对自己的手指说。

绳结打死。

整只草鞋紧紧咬住了脚掌的每一道轮廓。前掌受力时，后跟的提绊会自动向内收紧；抬脚时，整只鞋底像一层厚厚的硬皮一样贴在脚底板上，没有半毫米的虚位和滑动。

我站起身来。

左脚穿旧皮鞋，右脚踩新草鞋。

我迈开步子，狠狠踩在门廊前一片布满锋利玄武岩棱角的碎石坡上。

脚底传来的是沉稳、踏实、富有弹性的支撑感。碎石的尖角被一点五公分的致密纤维彻底化解，没有一丝刺痛，没有半点打滑。

我甚至用力跳动了两下。

草鞋在脚上纹丝不动，抓地力比那双开胶的旧皮鞋还要强劲得多。

我坐回石阶上，毫不犹豫地把另一只旧皮鞋也脱了下来，扔进了火塘旁边的杂物堆里。

花了一个半小时，我给左脚也编好了同样坚固的战靴。

文明社会留给我的工业鞋靴，在这一刻正式退役了。

我站起身，两只脚稳稳地踏在大地的碎石上。每一步落下，都带着纤维挤压的轻微回弹。

轮子修好了，护甲装上了。

这具躯体不再惧怕山崖上的荆棘，不再惧怕退潮礁盘上的碎贝。这座岛屿的每一寸土地，现在都在我的脚步测量范围之内。
