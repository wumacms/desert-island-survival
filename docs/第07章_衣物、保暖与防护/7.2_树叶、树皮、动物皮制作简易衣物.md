# 7.2 树叶、树皮、动物皮制作简易衣物

身上的衣服已经快要变成破布条了。

衬衫的下摆早在第一天就被撕去包扎了伤口，后背被荆棘划开了几道大口子，牛仔裤的两个膝盖完全磨穿，露出了结着血痂的膝盖骨。

赤道灼热的紫外线，顺着破损的衣料狠毒地咬在皮肉上。后颈和肩膀已经晒脱了皮，火辣辣地疼，只要轻轻一碰，就像是被开水烫过一样。

在自然界里，没有一层皮毛或者护甲，人是走不远的。

灌木丛里的倒刺会切开你的表皮，海滩上的风沙会磨烂你的关节，而夜间的寒风会顺着破洞把仅剩的热量全部偷走。

我不能等到衣服彻底化成飞灰才想办法。

我必须为自己做一套真正的荒野防护服。

在太平洋群岛上，古代的波利尼西亚人早在金属和织布机出现之前，就已经掌握了一门登峰造极的手艺：树皮布。

他们不需要纺线，不需要织机，靠着一把木槌，就能把一棵活树的皮变成柔软坚韧的布匹。

我沿着溪流旁湿润的山坡，砍下了四根碗口粗的野桑科构树幼树。

这种树的内皮具有极长的植物蛋白和纤维素微原纤维，纤维排列致密，延展性极佳。

我用黑曜石刀刃在树干上划开长长的直线，小心翼翼地把整张树皮完整地剥了下来。

第一步，剥离粗糙死皮。

黑色的外表皮是死细胞，硬而发脆，必须用石片一点一点刮掉，只留下里面那层奶白色、柔韧如羊皮的内韧皮。

内皮只有手掌那么宽，厚度大约三四毫米。

如果直接拿它来穿，它干了之后会卷曲硬化得像一块铁皮。

必须进行机械毡化。

我找来了一根被海水磨得极其圆润、致密沉重的铁木粗树干，平放在地上当作铁砧；又用最坚硬的玄武岩石条，在一段短粗木上刻出密密麻麻的平行细槽，做成了一柄带有棱齿的木槌。

把湿润的树皮平铺在砧木上。

我跪在地上，握紧木槌，开始有节奏地向下捶打。

“咚……咚……咚……”

沉闷有力的捶击声在安静的山脚下回荡。

这绝不是胡乱砸碎，这是一种精密的高分子物理重组。

木槌上的细槽带着强大的高频剪切力。每一次沉重的砸击，都在粉碎多余的薄壁细胞，迫使原本紧紧束缚在一起的纤维素微原纤维横向延展、松散、相互交织重叠。

在连续捶打了半个小时之后，奇迹在砧木上发生了。

原本只有巴掌宽、厚实坚硬的生树皮，被硬生生打宽了三倍，厚度降到了只有一毫米左右。

它不再是一块硬树皮，它变成了一大张柔软、细腻、富有弹性、摸上去像麂皮一样的雪白布匹。

如果单张布不够宽，办法更简单。

把两张树皮的边缘重叠两公分，举起木槌沿着重叠线反复砸击。在纤维断裂重组的微观力学作用下，两张树皮的微原纤维会自动相互勾连、毡合在一起，不留下一道缝线，浑然一体。

我打了整整一个下午。

最后，我在溪水里洗净了这块长两米、宽一米的大树皮布，把它浸泡在一锅用捣碎的红树皮煮出来的滚水里。

红树皮里富含高浓度的单宁酸。

单宁分子会与树皮布上的植物蛋白和纤维素紧密结合，发生天然的化学鞣制反应。

一个小时后捞出来，原本雪白的树皮布变成了坚固的深红褐色。单宁酸让布料变得彻底防霉、防虫、并且具备了极其出色的疏水性，雨水打在上面，会像荷叶上的露珠一样滚落。

我把这块大布摊开。

在正中央用刀切出一个刚好能穿过头部的菱形孔洞，套在脖子上，做成了一件前后垂落的无袖斗篷；

腰间用早上搓好的黄槿麻绳紧紧系死，下半身垂到膝盖上方，变成了一条结实的战裙。

站在小溪边的水潭旁，我看着水面上倒映出的影子。

肩膀被柔软坚韧的树皮斗篷严密遮蔽，深红色的布料把紫外线和恶风挡在外面，腰身扎得干脆利索，两只手臂在外面活动自如。

虽然简陋，虽然粗粝，但这件由大地亲手纺织出来的铠甲，沉稳、干燥，散发着天然植物与单宁的微苦香气。

我转了转肩膀，树皮布在关节处柔和地折叠、舒展，没有一丝滞涩。

大自然剥夺了现代文明施舍给我的衬衫和毛料，但只要智慧还在，它就不得不亲手脱下它自己的皮，为它的征服者重新披上坚不可摧的战袍。
