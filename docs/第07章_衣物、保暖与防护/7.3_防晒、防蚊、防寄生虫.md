# 7.3 防晒、防蚊、防寄生虫

在热带荒岛上，杀死一个人的，往往不是大白鲨或者狂风暴雨。

大自然最致命的武器，是那些肉眼几乎看不见的微小敌人。

无处不在的紫外线、吸血的蚊子、比针尖还小的沙蝇，还有潜伏在草尖上的硬蜱虫。

这些东西不会一口咬断你的脖子，它们像成千上万根淬毒的细针，一分一秒不停歇地消耗你的免疫系统，直到把你的防线彻底击穿。

我坐在小溪边的一块平整大石上，把双手插进水底细腻的红色泥浆里。

第一道死线，是天上的太阳。

在赤道附近，阳光里的中波紫外线UVB是一种绝对的细胞毒素。它能轻易穿透表皮，直接打断皮肤细胞DNA里的嘧啶双键。

如果不加防护，在烈日下暴晒四个小时，大面积的二度日晒伤就会导致全身皮肤起水疱、表皮坏死脱落；体液大量渗出，高烧和脱水会紧随其后。

在没有现代防晒霜的荒岛上，最好的防晒盾牌，就沉在脚底下的泥浆里。

我从溪流转弯的深处，淘出了一大捧极其细腻、毫无沙砾的纯净红粘土。

这种粘土富含硅酸盐和细微的氧化铁矿物微粒。

我摘下一颗成熟的大死椰子，用石片凿开，刮出一小勺油汪汪的天然椰子油，和红粘土混合在一起，在手心揉成均匀细腻的暗红色泥膏。

我把泥膏厚厚地抹在额头、鼻梁、颧骨、后颈以及整个裸露的手臂上。

物理防晒的原理极其简单粗暴。

化学防晒剂靠吸收紫外线，而这种由微观矿物晶体组成的泥膜，是一层密不透风的微型反光镜。

成亿上万颗细小的粘土晶体紧紧贴在皮肤表面，把入射进来的紫外线光子，百分之九十九直接反射、散射回空气中。椰子油锁住了皮肤水分，哪怕在烈日下劳作大汗淋漓，这层红色的泥甲也绝不会被汗水冲刷脱落。

第二道死线，是吸血的飞虫。

黄昏降临的时候，海滩上的沙蝇和树林里的按蚊开始像乌云一样压过来。

沙蝇比芝麻还小，无声无息，被咬上一口就会肿起奇痒无比的硬块，抓破之后极易引发大面积细菌性溃疡；而按蚊则是疟疾和登革热的原配刺客。

蚊虫在黑暗中追踪猎物，靠的是头顶触角对哺乳动物呼出的二氧化碳、乳酸和体温羽流的化学趋向性。

要防蚊，就必须打烂它们的嗅觉传感器。

我从林缘扯来了大把大把的野生香茅草和气味辛辣的野山姜叶子。

用两块石头把这些叶子砸得稀烂，浓烈的香茅醛和桉叶素精油立刻顺着叶脉迸发出来。

我把这些黏稠发绿的芳香汁液，狠狠涂抹在耳后、手腕和脚踝处。

高浓度的天然单萜烯化合物，在皮肤周围形成了一道强烈的化学迷雾，彻底瘫痪了蚊虫的触角化感感受器。在它们的感知世界里，我不再是一个散发着诱人乳酸的热血猎物，而只是一株散发着辛辣气味的不可食用的毒草。

在营地的门廊前，我还点起了一盆用香茅干叶和干海草混合压实的阴燃冷烟。

微弱的青烟笼罩在小小的露台周围，所有的飞虫在两米开外就被浓烟呛得纷纷绕道飞走。

第三道死线，是蜱虫与寄生虫。

每天黄昏钻进窝棚睡觉前，我立下了一条绝对不可废止的纪律：全身体检。

脱光衣服，借着火光，用两只手寸寸摸索自己的腋下、腹股沟、膝盖窝和头皮发根。

那些芝麻粒大小的硬蜱虫最喜欢潜伏在这些皮肤最薄、血管最密的地方。

它们会把整个带有倒钩的口器深深扎进真皮层，一边吸血，一边往血管里注入神经毒素和森林脑炎病毒。

如果摸到了一个小小的硬疙瘩，绝不能用手指生拉硬拽。

一旦把蜱虫圆滚滚的肚子捏爆，它肠道里的剧毒体液会被反向加压注射进你的血管；如果用力过猛，断在肉里的倒钩口器会引发长达几个月的顽固脓肿。

对付硬蜱，必须用火塘里烧得微红的细干枝，小心翼翼地靠近它的屁股。

感受到滚烫的热辐射，这只贪婪的虫子会自动把倒钩从肉里慢慢退出来，翻滚着掉在地上。

体检完毕，用温热的草木灰水把脚底和全身擦拭一遍。

我坐在火堆旁，脸上涂着红色的粘土，身上散发着浓郁的香茅草辛香。

看着水洼里自己那副如同远古印第安武士一般的面孔，我往火堆里扔了一截干柴。

在文明人的眼里，满身泥浆是肮脏和狼狈；

但在这片蛮荒的天地里，这身红泥和草汁，是最高明的生化防护服，是人类用科学解构了寄生虫与光线之后，为这具脆弱肉体披上的最骄傲的铠甲。
