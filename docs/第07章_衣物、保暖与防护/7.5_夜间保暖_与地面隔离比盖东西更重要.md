# 7.5 夜间保暖：与地面隔离比盖东西更重要

后半夜两点钟，温度跌到了整整二十四小时里的最低点。

山顶上的冷空气在重力的牵引下，像一道无形的冰冷瀑布，顺着山脊的斜坡呼啸着灌向海滩。

树叶在风里发出尖锐的呼啸，外面漆黑得伸手不见五指。

在任何野外求生的第一课里，最容易被人们忽视、却夺走最多人命的误区，就是把所有的保暖精力，全放在“盖在身上的东西”上。

人在感到寒冷的时候，本能反应是去抓点什么盖在肚皮上。

哪怕找到了十层厚厚的阔树叶，只要你躺在冰冷的地面上，你依然会在半夜里被冻得浑身发抖，牙齿打战。

在热力学的能量守恒定律面前，大自然是绝对公正的。

人体热量的散失有四个通道：空气对流、呼吸蒸发、红外辐射，以及固体接触传导。

在这四个通道里，最凶残、最贪婪、流失速度最快的，就是后背与地面之间的直接传导。

空气是极差的热导体，导热系数只有零点零二六；而潮湿的泥土和冰冷的岩石，导热系数是空气的六十倍到上百倍。

更致命的是压力。

当你把几片树叶盖在胸口时，叶片之间蓬松地包裹着厚厚的静止空气，那是极好的绝热层；

但当你把树叶垫在身下，你六七十公斤的体重压上去，重力会在一瞬间把所有的空气囊挤压殆尽。

原本蓬松的绝热垫被压成了一层致密的薄皮，厚度趋近于零。

温差直接跨过这层被压扁的死树叶，在你的后背皮肤与坚硬冰冷的地壳之间，建立起了一条毫无阻挡的热量高速公路。

它会像一台开足了马力的工业冷冻机，在两三个小时之内，把你体内的热量全部抽吸得一干二净。

“两层在下，一层在上。”

这是所有真正荒野大师死守的黄金热工法则。

如果手头只有三份干草，宁可两份死死压在身下垫实，只留一份盖在胸前；也绝不能把两份盖在身上，身下只留一层薄草。

我躺在离地四十公分的高架竹排床上。

身下是整整十五公分厚、用干树皮和坚韧山蕨层层交错堆砌出来的硬质床垫。

高弹性竹排吸收了重力，让蕨草层即使在体重压迫下，依然保留了足够的微观厚度和死空气结构；悬空的床底阻断了任何与地面的分子级热传导。

而在我的脚底下，还躺着一块大自然的天然暖炉。

那是一块在晚上的火塘余烬里，被烤得滚烫的扁平玄武岩小石板。

玄武岩的比热容极高。睡前，我把它从火堆里夹了出来，在地上放了五分钟，等表面的暴烈火气退去，用干燥的树皮布层层包裹好，塞在床尾的被头里。

这块散发着温热的“地热电池”，紧紧挨着我的双脚。

温热的温度透过树皮布传递到脚底的涌泉穴，通过股动脉的大血管循环，把微热的血液缓缓泵向全身每一个末梢。

身上只披着那件刚缝好的深红褐色树皮斗篷。

斗篷很轻，但阻挡了室内微弱的空气对流。

没有现代的鹅绒被，没有电热毯。

但在狂风呼啸的深夜里，这间小小的A字棚深处，形成了一个极其完美的封闭绝热系统。

身下是无法穿透的空气绝热垫，脚下是平稳放热的玄武岩火核，身上是防风疏水的鞣制树皮，四周是坚不可摧的抹泥硬墙。

我的胸口很热，脚底很暖，心跳沉稳而缓慢。

第三部分，在这一夜彻底完成了。

在最初的九天里，我从沙滩上一无所有的落难者，变成了这间温暖坚固堡垒的主人。

风雨被挡在屋外，寒气被阻在床下，毒虫被截在灰外，皮肤被裹在布里。

生存的防线彻底稳固了。

而当明天早晨的第一缕阳光洒进门廊的时候，我将不再仅仅满足于守住这条性命。

我的目光，将越过这片温暖的营地，投向岛屿深处的森林、暗礁深处的潮池、以及高空飞过的野禽。

人类的身体已经安全了，接下来，该是去夺取真正的生存力量——高热量的蛋白质与脂肪的时候了。

我合上双眼，在松涛与海浪的低吟声中，沉沉睡去。
