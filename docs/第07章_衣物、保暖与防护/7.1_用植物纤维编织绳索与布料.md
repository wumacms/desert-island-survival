# 7.1 用植物纤维编织绳索与布料

第八天的清晨，我低头看了看脚上的鞋带。

那两根宝贵的尼龙鞋带，已经被我磨得起了毛边。一根用来做了弓钻的拉弦，另一根用来固定了手表的反光镜。

现代工业制造的绳索是有限的，用一寸就少一寸。

在荒野里，绳索是人类文明的肌腱。没有绳子，你无法捆扎坚固的石斧，无法编织捕鱼的鱼篓，无法搭建抗击大风的棚屋，更无法给破烂的身体套上一层像样的甲胄。

而大自然最不吝啬的，就是植物纤维。

整座森林的树皮和叶片里，到处都锁着长链高分子纤维素。只要懂得把它们剥离出来，大地就能吐出无穷无尽的坚韧麻绳。

我钻进了山脚下的向阳灌木林里。

寻找纤维是一门关于植物生理学的筛选。不是所有的树皮都能用，很多树皮太脆，一折就断；有的树皮含胶质太多，干了之后硬得像铁片。

我在溪流边停下，挑选了几株手臂粗细的野生海滨黄槿。

这种树生长在咸淡水交界的地方，树皮具有极高的抗盐碱腐蚀能力，木质部的韧皮纤维又长又柔韧。

我用黑曜石在树干基部切开一道环形切口，再纵向向上拉出一道两米长的大缝子。

两手捏住树皮边缘，全身发力，往下一扯。

“嘶啦——”

一大张完整的长条树皮，带着潮湿的草木香气，被整整齐齐地剥了下来。

但生树皮不能直接搓绳子。

生树皮里含有大量的果胶、半纤维素和糖分。如果直接编织，水分一旦蒸发，树皮就会萎缩变脆；而且一旦泡了水，微生物会迅速发酵，两周之内就会让绳子彻底烂断。

必须进行生物脱胶。

我把剥下来的大捆树皮抱到泉水汇聚的清浅石坑里，用几块大石头压在水底。

水浸脱胶法。

在水流和厌氧菌的作用下，水中的微生物会把容易腐烂的果胶和多糖当成食物吞噬殆尽，而高结晶度的纯纤维素长链，细菌根本啃不动。

浸泡了整整二十四小时后，我把树皮捞了出来。

黑色的粗糙外皮已经软烂如泥，我用指甲刀的小铁挫轻轻一刮，黑皮就化作泥浆脱落了，露出了里面一层奶白色、发亮、像生丝一样的纯净内韧皮。

我把这些长长的白色纤维撕成火柴棍粗细的均匀细条，在阳光下晒到半干。

接下来，是物理力学的奇迹：反向加捻搓绳法。

很多人搓绳子，只会把两根草顺着同一个方向死命拧。那种绳子一松手就会自动散开。

真正的绳索力学，靠的是自锁。

我挑出两股粗细均匀的黄槿纤维，并排捏在左手的拇指和食指之间。

右手捏住其中一股，顺时针方向快速搓捻，直到纤维自身由于扭矩剧烈扭紧、绷直；

接着，右手顺势把这根扭紧的纤维，逆时针方向跨过另一根纤维，两者相互绞缠。

顺时针自转，逆时针公转。

两种完全相反的扭矩，在相交的节点上形成了极强的内应力。摩擦力让两股纤维像两把钳子一样死死咬合在一起，无论你怎么拉扯，它们都不会自发散开，拉力越猛，两股纤维相互咬合得就越死。

当一根纤维快要用尽的时候，我绝不把接头留在同一个位置。

错位接头法。

让两根纤维的接头相差十公分，把新的纤维并进即将耗尽的一端，继续顺时针扭紧、逆时针绞缠。

新旧纤维在摩擦力下融为一体，整根绳子粗细均匀，表面光洁，看不出任何明显的节疤。

我坐在火堆旁，双手不停歇地搓动着。

粗粝的植物纤维在掌心摩擦，带起一阵阵微热的痛感。

三个小时后，一根足足有八米长、筷子粗细、由双股紧密绞合而成的纯天然黄槿麻绳，整整齐齐地盘在了我的脚边。

我把绳子的一头拴在门廊的粗木桩上，双手抓住另一头，双脚蹬住石头，整个人后仰，用全部体重猛力向后拉拽。

绳子绷得笔直，发出一声坚韧的嗡鸣。

纹丝不动，连一根纤维都没有崩断。

这根绳子的极限抗拉强度，至少在五十公斤以上。

我抚摸着绳索上均匀细密的螺旋纹路，掌心发烫，心里却一片通透。

人类文明正是从这根粗糙的绳索开始结网、造舟、捆绑穹顶的。

只要这双手还能搓捻，我就能把整座森林散落的纤维，重新编织成坚固的工具，编织成遮风挡雨的衣裳。
