# 2.5 绘制简易地图：从海岸线到内陆的侦察路线

在真正迈步钻进密林之前，我停下了脚步。

眼前的丛林像是一堵墨绿色的活墙。高大的乔木把阳光遮得严严实实，林下全是一人多高的野蕨类和带刺的藤条。潮湿的热气从地面蒸腾上来，里面带着一股浓重的腐叶泥腥味。

只要一脚踏进去，海浪的声音就会被厚重的树冠吸收，视线超不过十米。

在热带雨林里，所有的树木长得都差不多。没有地标，没有开阔的视野，人类大脑的内耳前庭系统会迅速失去方向感。

由于左右腿肌肉力量和步幅的微小不对称，迷路的人在失去视觉参照时，几乎无一例外都会在方圆几百米的林子里无意识地兜圈子。你以为自己在笔直往前走，其实只是在画一个个绝望的同心圆，直到把最后的体力耗尽，死在距离海滩不到两百米的地方。

我退回林缘开阔的碎石坡上，坐在一块平整的大石头前。

我从怀里掏出一块早已晒干的大树皮。那是从一根倒伏的枯树干上剥下来的，内侧很平整，颜色是淡淡的灰白色。

我又捡起一截烧焦了一头的干硬树枝。焦炭在坚硬的木头上形成了一层纯碳的笔尖。

“把眼睛看到的，记在树皮上。”我对自己的手说。

第一笔，画一条横线。那是海岸线，是我现在站着的地方。

我在横线的正中点了一个圆点，标为“大漂木避风棚”。这是我的基地，也是所有行动的原点。

第二笔，确定基线和地标。

我回头望向海面上那座孤独矗立的黑色海蚀柱。它距离海岸大约五百米，高耸如塔，无论从哪个角度看都极其显眼。我把它画在地图的右下方。

接着抬头，正前方是那座像折断兽齿一样的黑色火山峰。那是整座岛的最高点，无论在林子的哪个缝隙里，只要一抬头，只要能看到那个山尖，我就能知道自己的方位。

两个显眼的地标，加上脚下的原点，构成了一个稳定的三角定位基准。

第三步，标出侦察路线和撤退后路。

我用脚步量算距离。两步为一个“复步”，一个复步大约是一点五米长。从避风棚走到现在的林缘入口，一共走了一百八十个复步，也就是两百七十米。

我把这条路用细线画在树皮上，然后在林子入口的大石头上，用玄武岩碎块刻下了一个深深的“X”形印记。

顺着入口往内陆，那条通往淡水深谷的干冲沟被我画成了一条蜿蜒向西北的虚线。

“记住这个方位角，林克，”我用黑炭在树皮的边缘重重画了一个向后的箭头，“南偏东，一百五十度。”

这是我的紧急撤退方位。

如果在密林深处遭遇山洪、野兽，或者天色突然黑透迷失了路径，我根本不需要费力去寻找来时的脚印。只要背对着火山尖，朝着南偏东的方向走，哪怕是闭着眼睛翻越荆棘，最多走八百米，我也必定会迎头撞上这条宽阔平整的海岸线。

大洋是走不丢的，只要往南走，我就能回到大海的怀抱。

一张简陋的树皮地图完成了。炭黑的线条粗糙，但上面的每一个点都代表着一段实打实的距离和一个可以依赖的物理地标。

我把树皮小心地折叠好，塞进紧贴胸膛的内衬兜里，让体温焐着它。

在荒野里，一张粗糙的地图，比十把上了膛的猎枪还要可靠。它把未知变成已知，把恐惧变成了纸面上的坐标。

我抓紧手里的木棍，深吸了一口气，迎着幽暗的树荫，迈出了踏入内陆的第一步。
