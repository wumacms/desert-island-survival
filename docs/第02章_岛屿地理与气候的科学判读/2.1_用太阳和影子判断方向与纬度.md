# 2.1 用太阳和影子判断方向与纬度

下午三点过后，最要命的那阵毒日头终于开始偏西了。

空气里的闷热散去了一些，海风重新变得干爽。我从小树林的深荫里钻了出来，膝盖上的破皮处结了一层暗黄色的硬痂，但只要一弯曲，还是拉扯着生疼。

我得知道自己在地球上的什么地方。

在大海里落难的人，最大的恐惧往往不是饥饿，而是不知道自己在哪里。你不知道哪边是大陆，不知道哪边是深海，更不知道头顶上的太阳为什么老是悬在正上方。

没有罗盘，也没有GPS。但我有一根木棍，还有天上的太阳。

在自然界里，太阳是最大的指路罗盘，也是最准的挂钟。它每天划过天空的轨迹，都是严格按照天体力学的规矩在运行。

我在平整干燥的高潮沙地上挑了一块平坦的地方。

我找来一根一米来长、笔直的死树枝，把它垂直插进沙子里。木棍立得很直，影子在沙地上拖出一条细长的黑线。

我弯下腰，捡起一块被海水冲得雪白的小珊瑚碎块，轻轻放在影子最顶端的位置。

“坐下等着，老伙计，”我对自己说，“让大地转一会儿。”

我在旁边坐了下来，看着远处的浪花。沙滩上的影子在极慢地移动。地球在自西向东自转，太阳在天上向西落，地上的影子就悄无声息地向东偏转。

大概过了十五分钟，影子的顶端已经从原来的位置挪开了大约五六公分。

我又捡起一块黑色的玄武岩小石子，放在了现在的影子顶端。

两块石头，一白一黑，在沙地上连成了一条线。

我折断一截枯树枝，把两块石头的中心连起来，划出一条笔直的直线。

这就是最古老的影子测向法。无论你在地球的哪个角落，第一块石头的影子代表偏西的方向，第二块石头的影子代表偏东的方向。这根连线，就是一条极其精确的绝对东西线。

我站起身，左脚踩在白石头上，右脚踩在黑石头上。

我的背正对着大海，面朝向那座巍峨的火山峰。如果左边是西，右边是东，那么我的鼻尖正对着的方向，就是正北方。

“正北方在山脊后面，”我默默记下这个方位，“大洋在我的正南方。”

知道了方向，接着是纬度。

正午十二点半的时候，也就是太阳升到最高点的那一刻，我特意观察过那根木棍的影子。影子的长度很短，甚至不足木棍本身长度的五分之一，而且影子的朝向明显偏向南方。

在北回归线以北的地方，正午的太阳永远在南边，影子永远朝北。只有在赤道以南、南回归线以北的热带海域，正午的太阳才会偏向北方，把影子投向南方。

“在南半球，”我在沙地上写下几个数字，“南纬大概在十度到十五度之间。”

这意味着这里没有严酷的寒冬，但会有漫长而凶猛的雨季和热带气旋。

方向清楚了，大致的纬度也有了数。这座岛在我的脑海里，不再是一片漂浮在虚空中的孤立黑点，它被两根无形的经纬线死死钉在了南太平洋或者南印度洋的温热海图上。

风吹过木棍，发出一阵轻微的嗡嗡声。

我拔出木棍，抹平了沙地上的石头印记。天色正在慢慢变暗，接下来，我该等待夜空里的另一群老相识了。
