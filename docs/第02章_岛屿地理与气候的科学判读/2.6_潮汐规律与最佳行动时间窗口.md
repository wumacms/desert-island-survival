# 2.6 潮汐规律与最佳行动时间窗口

下午四点半，大洋开始向后退去。

海水退得很慢，但很坚决。原本被汹涌白浪淹没的暗色礁盘，像是一头头从深渊里浮出水面的黑色巨鲸，一点一点露出了粗糙湿滑的脊背。

空气里弥漫着一股浓烈的海藻和贝壳的腥味。

大海每天都在呼吸。它呼气的时候，潮水漫过沙滩，淹没一切；它吸气的时候，则会大方地把海底的珍宝和秘密，毫不设防地留在湿漉漉的滩涂上。

这是月亮在大洋上刻下的钟表。

月球和太阳的引力，像两只无形的大手，在拉扯着地球表面的海水。一个太阴日是二十四小时又五十分钟，所以每天会有两次涨潮、两次落潮。每一次退潮，都会比前一天推迟大约五十分钟。

而现在，天上的月亮已经是一轮接近浑圆的凸月。

当下弦月走向满月的时候，太阳、月球和地球的引力即将排成一条直线。引潮力叠加在一起，造就了每个月最凶猛的大潮。

大潮意味着两件事：涨潮时它能淹没整片沙滩，带来吞噬一切的风暴潮；但在落潮时，它也会退得比平时远得多，露出平时深藏在水下两三米深的深水礁盘。

对于一个饥肠辘辘的求生者来说，干潮是荒岛上唯一一顿不需要耗费力气打猎的免费盛宴。

我手里握着削尖的木棍，腰里别着那个用塑料布和藤条扎成的简易小背篓，顺着湿滑的玄武岩石阶一步步朝退干的礁盘走去。

露出来的潮池里全是大自然的馈赠。

石缝里吸附着密密麻麻的笠螺和藤壶；水洼深处的石缝下，几只巴掌大的深色岩蟹正挥舞着大钳子往石缝里钻；在一些浅浅的积水坑里，甚至能看到几条来不及跟着退潮溜回深海的小海鲈在惊慌失措地打转。

但我没有立刻扑上去抓。

我蹲在一块凸起的礁石上，先抬头看了一眼远处的外海，又低头看了一眼自己的脚腕。

“记住时间窗口，老伙计，”我对自己警告道，“贪心会淹死你。”

潮汐的规律是严格按照余弦曲线变动的。在退潮的中间两个小时，水流退得最快；到了最低点，水面会有大约半个小时几乎完全不动的“平潮期”。

这是黄金的三十分钟。

一旦平潮期过去，涨潮的力量就会像决堤的洪水一样倒灌回来。如果沉迷于在远处的深池里抓鱼，忽略了身后通往海滩的低洼退路，只要涨上半潮，深达一米半的汹涌涌浪就会彻底切断你回家的路。

在乱石嶙峋、满是海胆和藤壶的暗礁上，逆着涨潮的巨浪游回来，即使是最好的铁人三项运动员也会被砸在礁石上粉身碎骨。

我的规矩很简单：只在干潮前四十分钟开始搜集，在干潮后二十分钟无论手里抓到了多少东西，必须立刻拔腿回撤。

宁可肚子挨饿，也绝不拿性命去赌那最后五分钟的贪婪。

我跳下礁石，踩在冰凉刺骨的潮水里。

用木棍撬开紧贴在石壁上的笠螺，用手指精准地掐住大岩蟹背甲后缘的软肉，把它们一只只丢进腰间的篓子里。手被锋利的牡蛎壳割破了两处细小的口子，海水浸得发蛰，但我动作很稳、很快。

二十分钟后，小篓子里已经堆了十几个肥厚的贝类和三只活蹦乱跳的螃蟹。

远处的暗礁外缘突然传来了一声沉闷的轰鸣。

第一道白色的翻花浪越过了外礁的顶峰，原本平静的潮池水面猛地晃动了一下，水位开始以肉眼可见的速度往上浮动。

涨潮了。

我没有任何犹豫，甚至没有多看一眼旁边那个水坑里正在摆尾的小海鱼。我转过身，踩着湿滑的黑礁石，迈开大步，头也不回地朝高处的沙滩撤退。

当我刚刚跨上那片干热的黑色沙地时，身后几分钟前还能行走的礁石小路，已经被深绿色的海水彻底淹没了。

大自然把潮汐的钟摆按时摆了回去。

我拎着沉甸甸的篓子，回到了干燥的背风棚前。

天边泛起了橘红色的晚霞。方向明确了，气候算清了，地图画好了，大洋的作息也摸透了。

我坐了下来，把贝类和螃蟹倒在平整的玄武岩上。接下来，是时候为最现实的生存选择做决定了——是想尽办法发出信号等待搜救，还是准备好在这座岛上长期扎根？

海风吹在脸上，我感到了一股踏实的平静。
