# 2.3 观察云、风、潮汐判断天气变化

第三天清晨，大洋的气息变了。

天光亮起来的时候，原本明净得像玻璃一样的天顶，悄悄爬上了一层极细、极高的白丝。

那些白丝像是一根根被风扯散的白色马尾，从东北方的天际线斜斜地拉扯过来。那是万米高空上的钩卷云，全部由细小的六棱冰晶组成。

上午九点多，太阳升上来了，但光线不再刺眼，变得苍白、发虚。

在太阳周围，出现了一道模糊的光圈。光圈很大，内红外紫，把苍白的日头死死圈在正中间。

“日晕。”我靠在一棵露兜树下，看着那道光环。

古老的气象谚语从来不是迷信。在两万英尺的高空，卷层云正像一层厚厚的纱帐一样自东向西铺展开来。太阳光穿透那些微小的冰晶，折射出二十二度的偏向角。这道光圈的出现，意味着远方的洋面上有一个巨大的低压系统正在隆隆形成。

暖湿气流在被疯狂抽向高空，高空的冰云跑得比地面的风暴快得多。

接着是风。

前两天一直很稳定的东南信风，在十点钟左右突然完全停了。

整座海滩闷得让人透不过气来，海面上平得像一块打磨过的青石板，连一丝褶皱都没有。树林里的野鸟停止了鸣叫，几只原本在低空觅食的海燕，开始不安地贴着悬崖缝隙盘旋，钻进岩洞里不再出来。

突然，一阵冷风从东北方向贴着海面刮了过来。

风向转了。

在南半球，逆时针偏转的风向和骤然跌落的气压，是热带气旋逼近的铁证。那个看不见的巨大风暴漩涡，正在几百海里外的大洋深处缓缓旋转，像磨盘一样向这片海域碾压过来。

最先报信的，是大海自己。

虽然岸边还没有刮起大风，但外海的浪头变了。

原本七八秒一次的短浪不见了，取而代之的是漫长、深沉、如同闷雷一样的远海长涌。十五秒，甚至二十秒才有一道波峰砸在外礁上。两米多高的巨浪把白色的海水抛起十几米高，震得脚底下的玄武岩都在隐隐发颤。

风暴在几百里外掀起的重水，以每小时几十海里的速度越过了大洋，提前跑到了风暴的前头。

海浪的周期拉得越长，说明制造它的风暴规模越大，距离越远。

“二十四小时，”我看着脚下越来越高的潮线，在心里对自己说，“顶多三十六小时。”

三十六小时之内，暴风雨就会像倾盆大雨一样砸在这座岛上。狂风会把未加固的树木像杂草一样拔起，暴雨会把干涸的沟渠变成狂暴的山洪，而风暴潮则会轻易淹没低矮的海滩。

原本定下的搜寻计划必须加快。

在风暴关上大门之前，我不仅要找到能饮用的淡水，还必须把那个摇摇欲坠的简易单坡棚子，加固成一个能抵挡十级大风和暴雨的坚固掩体。

大洋给出了警告，它从不偷袭有准备的人。

我抓起昨天绑好的那根趁手木棍，迈开大步，迎着越来越冷的东北风，朝内陆的山谷扎了进去。
