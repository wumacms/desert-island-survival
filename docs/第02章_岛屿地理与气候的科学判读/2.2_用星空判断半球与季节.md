# 2.2 用星空判断半球与季节

夜里没有风。

天黑得像一口倒扣过来的大铁锅，上面连一丝云彩都没有。

在城市里，人们已经很久没有真正见过夜空了。车灯、霓虹灯和高楼上的探照灯，把天空染成一种浑浊的橘红色。但在大洋深处，没有任何人造的光亮，夜空深邃得像是一片黑色的天鹅绒，上面的星星多得让人眩晕。

银河像是一条被泼洒在天顶上的碎银子，清清楚楚地斜跨过半个天空。

我坐在避风窝棚前平整的干石头上，两只手抱在膝盖上，仰起脖子看着那片光芒。

夜风有点冷，但空气干燥、透明，连最暗弱的六等星都在视野里清晰地闪烁。

我先朝正北方看。

那是北极星所在的地方。小时候在北半球，父亲曾经教我用大熊座的勺子去指认那颗孤单的亮星。但现在，北方的地平线上空空荡荡，只有黑沉沉的山脊轮廓。

没有大熊座，也没有北极星。

地球是圆的。弧形的地表像一堵厚厚的墙，把北半球的星空彻底挡在了我的脚底板下方。

我转过身，面向大洋的正南方。

它就在那里。

在南方海平线上方大约三十度的地方，挂着四个极亮的小火点。它们排列成一个倾斜的菱形十字架，一长一短，像是一只在夜空深处静静滑翔的黑色风筝。

南十字星座。

在大航海时代，那些驾驶着木帆船穿越大洋的水手，全靠它来保住性命。

在十字架的左边不远处，还有两颗极其夺目的亮星并排闪烁，那是半人马座的“两颗指路星”。

“好久不见，老朋友。”我轻声自言自语。

我伸出右手，将手臂伸直，用拇指和食指卡住南十字架那根较长的纵轴。

顺着长轴的顶端向下方延伸，在心里把它拉长四点五倍。然后再从半人马座两颗指路星的连线中间，画一条垂直的平分线。两条看不见的虚线在天空中相交的那一点，就是南天极。

南天极没有亮星，它只是黑暗中的一个虚点。

但我把目光从那个点垂直向下引向海面，水天相接的那道黑线所在的位置，就是正南方。

它和白天用木棍测出来的影子方向，吻合得严丝合缝。

接着是季节。

在天顶正中间，一条巨大的银色蝎子正舒展着它弯曲的尾钩。那是天蝎座。蝎子胸膛上那颗火红色的心宿二，像是一滴悬在夜空深处的血珠，红得发亮。

天蝎座高悬在正天顶，而猎户座的三颗腰带星还沉睡在东方的海面之下。

“现在是南半球的冬天。”我心里有底了。

南半球的冬季，对热带海岛来说，通常意味着干季的尾声。来自大陆内部的高压系统会让信风保持相对稳定，暴烈的大型热带气旋相对较少。但如果到了雨季，当猎户座升上天顶的时候，大洋上的风暴就会像磨盘一样碾碎整座海滩。

我还有几个月相对稳定的天气窗口。

星星不说话，但它们跨越了几十甚至上百光年，把古老的几何学和季节密码写在了我的眼球上。

四周的潮水在黑暗中哗哗作响。

我搓了搓有些冻僵的双手，钻回了低矮的单坡草棚里。夜空是浩瀚的，宇宙是冷漠的，但只要人类还掌握着解读它们的钥匙，我们在这片无情的大自然面前，就绝不是一无所知的孤儿。
