# 2.4 岛屿类型：火山岛、珊瑚岛、大陆岛的特征与资源差异

脚底下的石头越来越硬，颜色也越来越深。

离开白色的珊瑚沙滩几十米后，地表完全被一种黑灰色的岩石接管了。我蹲下身，从碎石堆里捡起一块巴掌大小的黑色石头。

石头很沉，手感扎实，表面布满了像蜂窝一样细密的气孔。

那是几万年前从地幔深处喷涌而出的滚烫岩浆，遇到冰冷的海水瞬间冷却凝固留下的痕迹。那些气孔，是当年被困在熔岩里的气体逃逸后留下的空穴。

玄武岩。大洋地壳最地道的骨架。

在漫长的大海求生中，一个人被冲上什么样的岛，几乎在最初的一秒钟就注定了他的生存概率。

如果是珊瑚环礁，那是一场残酷的慢死。

那些低矮的环礁平均海拔只有两三米，全是由死去的珊瑚虫碎屑和碳酸钙沙粒堆积起来的。地层像海绵一样千疮百孔，雨水落下来，立刻就会渗得干干净净。在环礁上，没有地表溪流，没有坚硬的石块，唯一获取淡水的办法，就是在沙地中央小心翼翼地挖一口浅井，去偷取那一层漂浮在重海水上方的极薄的“淡水透镜体”。稍微挖深一寸，打出来的就是苦咸的海水。一旦遇上十几米高的风暴潮，整座小岛就会被大洋从头到脚洗刷一遍，人连一处可以攀爬避险的高地都没有。

如果是大陆岛，情况就会好得多。

那些从远古大陆架上分裂出去的碎块，拥有几亿年积累下来的花岗岩、页岩和粘土层。那里有真正的矿藏，有奔流不息的大河，有丰富的陆生哺乳动物和厚重的土壤。在那样的大岛上求生，就像是在一个缩小版的文明边缘开荒。

而我现在脚下的，是一座典型的高火山岛。

它是最凶险的，但也往往是生机最旺盛的。

我把手里的玄武岩在身旁的一块大石头上狠狠砸了一下。石头应声断裂，露出了里面致密、灰黑色的断口。这种岩石硬度极高，韧性十足，是远古先民打制石斧、刮削器和石锤的最佳原料。

不仅如此，在几步之外的一道干涸冲沟里，我还看到了一抹异样的反光。

我走过去，拨开纠缠的草根，从泥土里抠出了一块黑得发亮、像碎玻璃一样的石头。

黑曜石。

二氧化硅含量超过百分之七十的酸性熔岩急剧冷凝形成的天然玻璃。我用手指轻轻蹭了蹭它的边缘，锋利得像是一把刚开刃的手术刀。

在贝壳状断口的作用下，黑曜石崩落的边缘只有几个分子的厚度，比现代最精密的钢质解剖刀还要锐利。只要稍加剥落加工，它就能变成锋利的箭头、割断藤条的砍刀，以及剥皮剔骨的刮刀。

火山岛的高耸山体阻截了高空的云雾，带来了淡水；深厚的火山灰风化成了肥沃的黑土，孕育了密不透风的丛林与飞禽；而这片黑色的地壳，又慷慨地抛出了黑曜石与玄武岩这样顶级的手工工具。

“运气不算坏，林克。”我用手指摩挲着那块冰冷坚硬的黑曜石。

这是一座严酷的岛，它到处是断崖、毒虫和滑坡，但它不是贫瘠的荒漠。它像一个脾气暴烈但兜里装满宝藏的老铁匠，把生存需要的一切原料都摆在了地表上。

只要你懂得认出它们，懂得利用它们，大山就不会让你饿死。

我把黑曜石和那块趁手的玄武岩收进口袋，沉甸甸的重量撞击着大腿。

有了石头，人类才真正开始成为人类。
