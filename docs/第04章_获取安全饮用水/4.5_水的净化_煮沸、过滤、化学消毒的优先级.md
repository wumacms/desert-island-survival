# 4.5 水的净化：煮沸、过滤、化学消毒的优先级

在荒野里，最肮脏的谎言，莫过于“纯天然的溪水可以直接喝”。

很多遇难者在山沟里看到一条看似清澈的小溪，或者一片清亮的水洼，会忍不住跪下来痛饮。

那往往是他们人生中做的最后一个决定。

在热带丛林的高温高湿环境下，任何一洼地表水，都是微生物的温床。水面上漂浮着肉眼看不见的腐殖质，水底沉淀着腐烂的鸟兽粪便和死青蛙。

更可怕的是寄生虫包囊和细菌。贾第鞭毛虫、隐孢子虫、致病性大肠杆菌，还有随老鼠尿液污染水体的钩端螺旋体。

这些微小的恶魔有一层坚硬的几丁质外壳，胃酸根本杀不死它们。

只要咽下几口带菌的生水，二十四小时内，急性阿米巴痢疾或者严重的肠道感染就会像火山爆发一样席卷你的消化道。剧烈的喷射状呕吐、水样腹泻，会在两天内抽空你身体里全部的电解质和水分。

在没有静脉输液和广谱抗生素的荒岛上，脱水性休克和酸中毒会在三天内夺走一个壮汉的命。

“宁可多忍半天渴，绝不喝一口生水。”我蹲在一条泛着浑浊黄色泥沫的山涧旁，在心里把这句话念了三遍。

净化水是一套不可跳级的严密工序。

第一步，是物理过滤。

光靠煮沸是不能解决泥沙和异味的。水里的腐殖酸和悬浮微粒必须先被剥离出去。

我砍下一节长约半米、碗口粗的青竹，打通中间的竹节，只在最底部的竹节正中央钻开一个筷子粗细的小孔。

我开始往竹筒里填装自然界里最好的层级过滤柱。

最底层，我塞进了一团从破衬衫内侧撕下来的干净纯棉碎布，压得实实的；

布团上方，是一层十公分厚、洗去盐分的细白海沙；

海沙上方，是整套过滤柱的核心：一层十五公分厚的碎木炭。

这些木炭是我从昨夜的火堆里扒出来的硬木炭块。我用石头把它们砸成黄豆大小的细颗粒。木炭在微观结构上充满了无数纳米级的曲折孔隙，这是最天然的活性炭。它依靠范德华力，能疯狂吸附水里发臭的有机大分子、植物色素和苦涩的单宁酸；

在碎木炭上方，我又铺了一层粗砂，最顶层则是几十颗洗净的大鹅卵石，用来阻挡大块的树叶和泥块。

我把浑浊发黄的山涧泥水，缓缓倒进了竹筒的顶端。

水流在重力的拉扯下，一步一步穿过鹅卵石、粗砂、活性木炭和细沙。

两分钟后，底部的出水孔发出了清脆的声响。

一滴滴水珠落进底下的椰壳里。水里的黄泥不见了，腐叶的腥臭味被木炭彻底吸干，水质变得透明、明澈，像玻璃一样透亮。

但别急着喝。

过滤只能滤掉悬浮颗粒和大部分寄生虫卵，那些小到微米甚至纳米级的病毒和细菌，依然像游鱼一样在水分子间穿梭。

最后一步，也是绝对不可动摇的黄金法则：热力煮沸。

在所有野外净水手段里，任何紫外线曝晒或者化学消毒，都比不上热力学的绝对暴力。

我把滤好的清水倒进一只新鲜的粗竹筒里，架在红热的火炭上。

水温在上升。六十度，嗜热菌开始失活；八十度，绝大多数细菌的蛋白质开始不可逆地变性、凝固；一百度，沸腾的气泡在水底狂暴地炸开。

我死死盯着竹筒，看着那滚沸的水泡在蒸汽里翻滚。

必须保持大火滚沸整整三分钟。

三分钟的剧烈沸腾，能彻底撕碎最顽固的隐孢子虫包囊，把所有病毒的核酸链彻底烧断。

取下竹筒，水在空气中慢慢冷却。

倒在洗净的椰壳里，水温变得温热。我端起椰壳，大口大口地喝了下去。

没有任何杂味，只有一股让人安心的沸水甜香。

科学的步骤繁琐，甚至有些折磨人。在渴得嗓子冒烟的时候，强忍着欲望去砸木炭、填沙子、生火、等待沸腾，是一场对意志力的残酷拷问。

但正是这种死板、苛刻、绝不妥协的理性，才把人和野兽真正区分开来。

野兽在水洼边暴毙，而人类靠着火与沙，把污水变成了生命的源泉。
