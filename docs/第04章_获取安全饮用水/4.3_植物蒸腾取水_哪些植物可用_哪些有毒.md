# 4.3 植物蒸腾取水：哪些植物可用，哪些有毒

走在密林深处的时候，你其实走在一条流淌在半空中的大河里。

每一棵高大的热带乔木，都是一台巨大的抽水机。它们的根须深深扎进几十米深的地下岩缝，借着植物细胞的渗透压，把成百上千升的地下水硬生生抽向树梢。

那些水顺着树干的木质部导管一路向上，最终通过叶片背面成千上万个微小的气孔，悄无声息地蒸腾进空气里。

整座森林都在呼吸水。懂得这一点的人，在绿色的丛林里永远渴不死。

我攀上了一处被阳光直射的山坡。

手里握着一块用磨钝了的玄武岩石片做手柄、边缘锋利如刀的黑曜石刮刀。

在没有坑洼地表、无法挖掘蒸馏器的地方，利用植物的蒸腾作用取水，是最干净也最隐蔽的手段。

只要把一个结实的透明塑料袋套在一根向阳、生长茂盛的阔叶树枝条上，把袋口用细藤条扎得严丝合缝，再在袋子的最低角坠一块小石头。

树叶被太阳晒热，气孔全开，蒸腾出来的水蒸气无法逃逸，只能在塑料袋内壁凝聚成纯净的液态水，一滴滴滚落进那个下垂的尖角里。

一根向阳的好树枝，一个下午就能给你端出半升不带泥沙的纯净水。

但我今天不需要等那么久。

在两棵巨大的野榕树之间，垂挂着几根像手腕那么粗的深褐色老藤条。它们从高高的树冠上垂下来，粗糙的表皮像是一条条苍老的蟒蛇。

水藤。

在热带雨林里，这是流动的水壶。

但砍藤条是有严格物理讲究的。很多新手看到藤条，兴奋地一刀砍在底部，结果一滴水都见不着。

因为在植物活体内部，水分子之间靠着氢键连成一条条紧绷的“水柱”，树顶蒸腾作用产生的负压，像一只巨大的针筒在向上死命抽吸。

如果你先砍断底部，负压会瞬间把整根藤条里的水分吸向几十米高的高空树梢，你只能看着干瘪的木芯干瞪眼。

必须先砍上面。

我踩着一块凸起的巨石，伸手够到两米多高的地方，手里的黑曜石刀刃猛地一挥，利索地在藤条上方切开了一个深达木质部的大口子。

“嗤——”

一声极其微弱的吸气声响起。空气打破了藤管内部的负压，水柱被重力斩断了。

紧接着，我在靠近根部的下方，倾斜四十五度，一刀斩断了整根藤条。

大气压和重力在这个瞬间同时发力。

我刚把断口凑到嘴边，一股冰凉甘甜的清泉，就顺着藤条粗大的导管孔隙像拧开的水龙头一样喷涌而出。

我仰起头，大口吞咽着这股带着淡淡青草香气的活水。

水很清，没有异味，在舌尖上留下了一抹清爽的微甘。

这根一米半长的藤条，足足倒出了将近四百毫升的清甜树汁。

但树林也是个布满毒药的药房。在这里，有些植物的水能救你的命，有些植物的汁液一滴就能送你归西。

我走过一株开着洁白花朵、叶片像枇杷一样油亮的小灌木。

在断裂的枝杈处，渗出了一滴像牛奶一样浓稠的乳白色汁液。

我立刻退后了两步，甚至屏住了呼吸。

在野外，这是最铁的一条血色戒律：任何流出乳白色、浓稠黏液的植物，一概视作剧毒。

那是大戟科和夹竹桃科植物的典型特征。那些乳汁里充满了复杂的强心苷、生物碱和二萜类毒素，只要沾在皮肤上就会引发火灼般的溃烂；要是进了眼睛，几个小时内就能灼伤角膜致盲；要是吞进肚里，狂暴的心律失常会在半小时内让你的心脏彻底停跳。

还有那些散发着刺鼻苦杏仁味的汁水，里面藏着氰化物；那些长在海滩边、果实像小芒果一样的海杧果，一颗果核里的毒素就足够放倒三个成年壮汉。

辨别水藤的法则很简单，只有三条：

流出的汁液必须像水一样清澈透明，绝不能有奶白色或者浑浊的杂色；

凑在鼻子底下闻，不能有任何苦杏仁味或者刺激性的腐臭；

用手指沾一点抹在手腕内侧最娇嫩的皮肤上，等待十分钟，没有任何灼痛、发痒或红肿。

经过了这三道严密的物理和生理检验，大地的血管才算真正向你敞开。

我扔掉手中干瘪的空木藤，擦了擦嘴角的水渍。

头顶的阳光透过层层叠叠的绿叶，洒下一片斑驳的光斑。

在这片绿色的海洋里，危险与生机并存。只要你守住科学的界限，不被贪婪冲昏头脑，这片森林就是一座取之不尽的天然粮仓和水库。
