## 📖 作品概览

《孤岛求生：科学家的荒岛生存手册》（*Desert Island Survival: A Scientist's Field Survival Manual*）是一部**鲁滨逊式（Robinsonade）硬核科学小说**与**沉浸式生存技术手册**的跨界复合体。

作品以科研人员“林深”遭遇海难独自漂流至西太平洋未知无名荒岛为开端。全书摒弃市面常见网文的“金手指”、“系统抽奖”或玄幻虚构元素，严格遵循**经典热力学定律、生理生化代谢、物理机械力学与生态演替规律**，完整记录文明人类在极端蛮荒环境中仅凭理性思考与自然法则建立完整生存体系、重建技术树直至获救归来的全历程。

> 对标世界文学谱系：丹尼尔·笛福《鲁滨逊漂流记》、儒勒·凡尔纳《神秘岛》、安迪·威尔《火星救援》以及欧内斯特·海明威《老人与海》。

## 🌟 核心特色

- 🔬 **绝对硬核的科学机理**  
  从摩擦取火的炭化爆燃温度（260℃~300℃）、渗透压计算与脱水机理，到简易蒸馏器、伏打电堆、肥皂皂化反应与草木灰提钾，所有求生方案均具备真实物理与化学依据。
- 🌲 **工业级生存技术树**  
  全书技术演进严格依照文明发展逻辑：从前72小时应急避险、获取安全饮用水与庇护所，逐步攀升至植物辨识、海洋捕捞、绳索编织、制陶、冶金、航海天文定位与简易农业驯化。
- 🧊 **冷峻真实的独幕生存纪实**  
  全书无繁琐冗杂的人际纠纷与反派脸谱，主要冲突聚焦于**“单一个体生命与冷酷自然物理律之间的博弈”**。行文克制内敛，呈现纯正的硬汉文学质感与人类理性的尊严光辉。
- 📑 **手册与叙事实体双栖**  
  既具备小说跌宕起伏的生存悬念与心理刻画，又具备可按需查阅的工具手册结构，附带详尽的物资清单、急救流程、植物图鉴与求救编码。

## 💻 快速开始

本项目采用现代化静态文档引擎 **VitePress 1.6+** 驱动，具备极快的响应性能、本地全文检索与深浅色暗黑主题切换。

### 1. 环境准备

确保您的本地环境已安装：
- **Node.js**：`>= 18.0.0`
- **pnpm**：`>= 8.0.0`（推荐 pnpm 9+ / 10+）

### 2. 克隆与安装依赖

```bash
# 进入项目目录
cd desert-island-survival

# 安装依赖
pnpm install
```

### 3. 本地启动开发服务器

```bash
pnpm docs:dev
```
启动后在浏览器访问 [http://localhost:5173](http://localhost:5173) 即可实时热重载阅读文档。

### 4. 生产打包构建与预览

```bash
# 静态资源打包（输出至 docs/.vitepress/dist）
pnpm docs:build

# 本地预览打包产物
pnpm docs:preview
```
